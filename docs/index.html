PoMaS — Pocket Math Station

M5Stack Cardputer-Adv ESP32-S3 Multifunction Calculator v0.92

PoMaS is a pocket math station for M5Stack Cardputer-Adv, integrating a calculator, CAS, statistics, graphing, scientific reference, and a μLisp interpreter into a single handheld device.

✨ Features

  • Calculator — expression, history, memory, variables A–J, complex numbers, base conversion, bit ops, RPN
  • CAS — polynomial eval / diff / integrate, roots, Taylor, limit, substitute
  • Statistics — 9 regressions, 11 tests, multivariate, stratified, survival, meta-analysis, 17 graphs
  • SciRef — 386 constants, 300 laws, 532 units, 118 elements
  • Graph — y=f(x), parametric, polar, implicit, inequality, sequence, 3D, G-Solve
  • Tools — spreadsheet, μLisp, Wi-Fi, NVS settings

🚀 Quick Start

  1. Install esptool
  2. Download PoMaS_v0.92_Cardputer-Adv.bin from Releases
  3. Connect Cardputer-Adv via USB-C
  4. Flash: 
    esptool.py --chip esp32s3 --port COM3 --baud 921600 \
  write_flash --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x0 PoMaS_v0.92_Cardputer-Adv.bin

🐛 Known Limitations

  • No PSRAM → statistics lists limited to 200 entries each
  • Wi-Fi / Maxima requires a self-hosted proxy
  • μLisp cell pool = 2500; use Tools → uLisp → Run GC now after heavy use
  • 2.4 GHz Wi-Fi only
