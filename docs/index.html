PoMaS — Pocket Math Station

M5Stack Cardputer-Adv ESP32-S3 Multifunction Calculator

PoMaS is a pocket math station for M5Stack Cardputer-Adv, integrating a calculator, CAS, statistics, graphing, scientific reference, and a μLisp interpreter.

📖 Documentation

  • Manual (HTML) — Full operation manual. Use your browser's translate feature.
  • MANUAL.md — Markdown version
  • GitHub Repository
  • Releases / Firmware

✨ Features

  • Calculator — expression, history, memory, variables, complex, base conversion, bit ops, RPN
  • CAS — polynomial eval/diff/integrate, roots, Taylor, limit, substitute
  • Statistics — 9 regressions, 11 tests, multivariate, stratified, survival, meta-analysis, 17 graphs
  • SciRef — 386 constants, 300 laws, 532 units, 118 elements
  • Graph — y=f(x), parametric, polar, implicit, inequality, sequence, 3D
  • Tools — spreadsheet, μLisp, Wi-Fi, settings
