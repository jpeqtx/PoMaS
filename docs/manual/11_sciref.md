## 11.1 SciRef モードとは
**SciRef（Scientific Reference、科学資料）** は、
科学・数学・工学のデータを素早く参照するモードです。
### 搭載データ
| 種別 | 件数 | 内容 |
|---|---|---|
| **科学定数** | 386 件 | 物理・化学・天文・生物など |
| **科学法則** | 300 件 | 物理・化学・数学・地球科学など |
| **単位換算** | 532 単位 | 20 カテゴリ |
| **周期表** | 118 元素 | 全元素の原子量 |
| **記号検索** | 全定数対象 | シンボル/名前で検索 |
---

### 操作フロー
```
[1] Constants
[2] カテゴリ選択（例: Physical）
[3] 定数一覧から選択
[4] 詳細画面表示
```
### 詳細画面
**例: 光速 c**
```
┌─────────────────────────────────┐
│▌c                               │
├─────────────────────────────────┤
│Speed of light in vacuum         │
│                                 │
│299792458                        │  ← 値（大字）
│m/s                              │  ← 単位
│[Physical]                       │  ← カテゴリ
├─────────────────────────────────┤
│Y:Ans  B:Bank+       S:Save      │
└─────────────────────────────────┘
```
### 操作
| キー | 動作 |
|---|---|
| `Y` | Ans に転送 |
| `B` | Ans バンクに追加 |
| `S` | BMP 保存 |
| `Fn + Esc` | 一覧に戻る |
### Ans に転送（Y）
定数の値を Ans にセット。続けて計算できます。
**例: 光速 c から 1 秒間の距離を計算**
```
[1] Constants → Physical → c
[2] Y（Ans = 299792458）
[3] Fn + Esc で Calculator に戻る
[4] Ans * 1 = 299792458
```
### Ans バンクに追加（B）
複数の定数を記録しておきたい場合に使います。
```
[1] 定数詳細で B を押す
[2] Bank+ (n/20) と表示
→ Ans バンクに保存される
```
最大 20 件まで。`Fn + b` でバンク一覧を開けます。

[1] Unit Converter → Temperature
[2] From: Fahrenheit
[3] To: Celsius
[4] Value: 100
→ 100 °F
  = 37.7778 °C
```
### 例: 100 坪を m² に換算
```
[1] Unit Converter → Area
[2] From: tsubo
[3] To: m²
[4] Value: 100
→ 100 tsubo
  = 330.5785 m²
```
### 操作
| キー | 動作 |
|---|---|
| `Y` | Ans に転送 |
| `S` | BMP 保存 |
| `Fn + Esc` | 一覧に戻る |
### 温度換算の計算式
温度だけは他の単位と異なり、**オフセット**があります。
```
°C → K: K = °C + 273.15
°F → °C: °C = (°F - 32) × 5/9
```
PoMaS は内部でこの変換を自動処理します。

原子量を Ans にセット。分子量の計算などに使えます。

[2] Fn + Esc → Periodic Table → O → Y（Ans = 15.999）
[3] 1.008 * 2 + 15.999 = 18.015
```

## 11.7 Search by Symbol（記号検索）
### 起動
```
SciRef → 5 (Search by Symbol)
```
### 使い方
シンボルや名前の一部を入力すると、
一致する定数を検索します。
**例: "grav" で検索**
```
[1] Search by Symbol
[2] 検索語: grav
→ 該当する定数の一覧:
  G: Newtonian constant of gravitation
  g0_p: Standard gravity (g0)
  g_p: Earth surface gravity (g)
  ...
```
### 検索の仕組み
- 大文字小文字を区別しない
- シンボル・名前の**部分一致**
- 最大 32 件まで表示
**例: "planck" で検索**
```
→ h: Planck constant
  hbar: Reduced Planck constant
```
### 結果から詳細へ
一覧から選ぶと、定数詳細画面に移動。
`Y` で Ans 転送、`B` で Ans バンク追加が可能。

## 11.8 実用例
### 例 1: 光の速さから 1 光年を計算
```
[1] Constants → Physical → c（光速）
[2] Y（Ans = 299792458）
[3] Fn + Esc → Calculator
[4] Ans * 60 * 60 * 24 * 365.25
→ 9.4607e15 m（1 光年）
```
### 例 2: 地球の重力加速度から自由落下距離
**問題**: 物体を 5 秒間自由落下させたときの落下距離
```
[1] Constants → Geo → g_p (9.80665)
[2] Y（Ans = 9.80665）
[3] Calculator
[4] 0.5 * Ans * 5^2
→ 122.58 m
```
公式: h = (1/2)gt²
### 例 3: 摂氏 25°C を華氏に換算
```
[1] Unit Converter → Temperature
[2] From: Celsius, To: Fahrenheit
[3] Value: 25
→ 77 °F
```
### 例 4: アボガドロ数から分子数を求める
**問題**: 水 18g に含まれる水分子の数
```
[1] Constants → Physical → N_A
[2] Y（Ans = 6.022e23）
[3] Calculator
[4] Ans * 1（18g = 1mol）
→ 6.022e23
```
### 例 5: 周期表で分子量を計算
**問題**: CO₂ の分子量
```
[1] Periodic Table → C → Y（12.011）
[2] Fn + Esc → Periodic Table → O → Y（15.999）
[3] Calculator
[4] 12.011 + 2*15.999 = 44.009
```
### 例 6: 電磁気の単位換算
**問題**: 1 T（テスラ）は何ガウスか
```
[1] Unit Converter → Misc (or Density 等)
```
⚠️ **テスラ/ガウスは搭載範囲外**
電磁気の磁束密度は、Misc カテゴリにも該当がありません。
必要に応じて、Calculator で直接計算してください。
（1 T = 10000 G）

## 11.10 トラブルシューティング
| 症状 | 原因 | 対処 |
|---|---|---|
| カテゴリが「Empty」 | データ未登録 | 別カテゴリを選択 |
| 検索で見つからない | 検索語が短い | 3 文字以上で検索 |
| Ans に転送されない | Ans バンクが満杯 | バンク整理後、再実行 |
| 周期表の元素が小さい | 画面サイズの制約 | Enter で詳細画面へ |
| 単位換算の結果が変 | 温度のオフセット | 温度は特別処理（自動） |

## 11.16 実用例集 拡張

### 11.16.1 物理計算

**例 1: 地球の脱出速度を計算**

```
[1] Constants → Astronomy → M_E    Ans = 5.9722e24
[2] Constants → Astronomy → R_eq   Ans = 6378137
[3] 残りは手動: sqrt(2*G*M/R)
[4] Constants → Physical → G
[5] 全体計算:
  sqrt(2 * Ans_G * Ans_M / Ans_R)
→ 約 11186 m/s = 11.19 km/s
（理論値: 11.2 km/s）
```

**例 2: 水素原子の基底エネルギー**

```
E = -me * e^4 / (8 * eps0^2 * h^2)
[1] me: 9.109e-31
[2] e: 1.602e-19
[3] eps0: 8.854e-12
[4] h: 6.626e-34
[5] 式を組み立てて計算
→ -2.18e-18 J = -13.6 eV
```

### 11.16.2 化学計算

**例 1: モル濃度から質量を計算**

問題: 0.1 mol/L の NaCl 溶液 500 mL に含まれる NaCl の質量

```
[1] Periodic → Na → Y     Ans = 22.990
[2] Periodic → Cl → Y     Ans = 35.45
[3] (22.990 + 35.45) * 0.1 * 0.5
→ 2.922 g
```

**例 2: 気体のモル体積から密度を計算**

問題: 標準状態（STP）での O₂ の密度

```
[1] Periodic → O → Y     Ans = 15.999
[2] モル質量 = 15.999 * 2 = 31.998 g/mol
[3] Constants → Physical → V_m    Ans = 22.414e-3 m³/mol
[4] 31.998e-3 / Ans_V_m
→ 1.428 kg/m³
```

### 11.16.3 天文計算

**例 1: 恒星までの距離**

問題: 年周視差 0.1 秒の恒星までの距離（パーセク）

```
距離 = 1 / 視差（秒）
[1] 1 / 0.1
→ 10 pc
[2] 光年に換算: 10 * 3.26
→ 32.6 光年
```

**例 2: 太陽のシュヴァルツシルト半径**

```
r_s = 2 * G * M_sun / c^2
[1] Constants → Astronomy → M_sun    Ans = 1.9884e30
[2] Constants → Physical → G          Ans = 6.674e-11
[3] Constants → Physical → c          Ans = 299792458
[4] 2 * Ans_G * Ans_M / Ans_c^2
→ 2.953 km
```

### 11.16.4 工学計算

**例 1: 銅線の抵抗**

問題: 断面積 1 mm²、長さ 10 m の銅線の抵抗

```
R = ρ * L / A
[1] Constants → EE → rho Cu    Ans = 1.68e-8 Ω·m
[2] L = 10 m, A = 1e-6 m²
[3] Ans_rho * 10 / 1e-6
→ 0.168 Ω
```

**例 2: コンデンサのエネルギー**

```
E = (1/2) C V^2
C = 100 µF, V = 12 V
[1] 0.5 * 100e-6 * 12^2
→ 0.0072 J
```
