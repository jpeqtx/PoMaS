## 表記について

本書では以下の表記を用います。

| 表記 | 意味 |
|---|---|
| `Fn + Esc` | Fn キーを押しながら Esc キーを押す |
| **太字** | 重要な用語 / 注意すべき操作 |
| `コード体` | 画面に表示される文字、または入力する文字 |
| 💡 | 補足・ヒント |
| ⚠️ | 注意事項 |
| 📝 | 練習問題・具体例 |
