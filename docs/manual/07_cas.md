## 7.1 CAS とは
**CAS（Computer Algebra System、コンピュータ代数システム）** は、
数値を計算するのではなく、**数式そのものを操作する** システムです。
### 普通の電卓 vs CAS
**普通の電卓**:
```
x = 3 のとき、x^2 + 2x + 1 = ?
→ 3^2 + 2*3 + 1 = 9 + 6 + 1 = 16
```
**CAS**:
```
x^2 + 2x + 1 = ?
→ (x + 1)^2   ← 式のまま変形
```
**CAS の利点**:
- 数式をそのまま操作できる
- 変数 x を含んだまま計算できる
- 微分・積分を記号的に実行できる
### PoMaS の CAS でできること
PoMaS の CAS は、**多項式** を中心に扱います。
多項式とは、`x^3 - 2x^2 + 5x - 3` のような、
x のべき乗の和で表される式です。
| 機能 | 例 |
|---|---|
| 多項式の評価 | x=2 のとき x²+3x+2 = 12 |
| 微分 | (x³)' = 3x² |
| 積分 | ∫x² dx = x³/3 + C |
| 加減乗算 | (x+1)(x-1) = x²-1 |
| 根 | x²-5x+6 = 0 → x=2, 3 |
| テイラー展開 | sin(x) ≈ x - x³/6 + ... |
| 極限 | lim(sin(x)/x, x→0) = 1 |
| 記号置換 | x²+3x+2 の x→y+1 |

## 7.3 多項式の入力書式
| 書き方 | 意味 |
|---|---|
| `x^3 - 2x + 1` | x³ - 2x + 1 |
| `3x^2 + 2x - 5` | 3x² + 2x - 5 |
| `x` | x（係数 1） |
| `-x^2` | -x²（係数 -1） |
| `5` | 定数 5 |
### 正しい例
```
x^3 - 2x + 1
1 + 2x - x^2
3x^2 + 2x - 5
x + 1
```
### 間違った例
```
x*x*x - 2x + 1     ← * は使わない
x^3 - 2*x + 1      ← 係数と x の間は * 不要
3 x^2 + 2x - 5     ← 係数と x の間に空白不要
```
💡 **係数と x の関係**
- `2x` = 係数 2 の x
- `x` = 係数 1 の x（1 は省略）
- `-x` = 係数 -1 の x
### 次数の上限
PoMaS が扱える多項式は、**最大 16 次** まで。
---
## 7.4 多項式の評価（Eval at x）
### 例: x³ - 2x + 1 を x=2 で評価
```
[1] CAS → 1 (Eval at x)
[2] p(x): x^3 - 2x + 1
[3] x = 2
[4] Enter
→ p(2) = 5
```
**確認**: 2³ - 2×2 + 1 = 8 - 4 + 1 = 5
### 例: x² + 3x + 2 を x=-1 で評価
```
[1] p(x): x^2 + 3x + 2
[2] x = -1
→ p(-1) = 0
```
**確認**: (-1)² + 3(-1) + 2 = 1 - 3 + 2 = 0
💡 **因数の確認**
x=-1 で 0 になるということは、
多項式が (x+1) を因数に持つことを意味します。
### 結果の利用
結果は `Ans` に保存されます。
```
[1] p(2) = 5 → Ans = 5
[2] Fn+Esc で Calculator に戻る
[3] Ans * 10 = 50
```

## 7.5 多項式の微分（Differentiate）
### 例: x³ - 2x + 1 の微分
```
[1] CAS → 2 (Differentiate)
[2] p(x): x^3 - 2x + 1
→ p'(x) = 3x^2 - 2
```
**確認**:
- (x³)' = 3x²
- (-2x)' = -2
- (1)' = 0
- よって p'(x) = 3x² - 2
### 例: x⁴ + 2x² の微分
```
[1] p(x): x^4 + 2x^2
→ p'(x) = 4x^3 + 4x
```
### 微分の公式（参考）
| 関数 | 導関数 |
|---|---|
| xⁿ | nx^(n-1) |
| 定数 k | 0 |
| x | 1 |
| kx | k |
### 高次微分
1 階微分のみ対応。2 階微分は、結果を再度微分します。
```
[1] p(x): x^3
→ p'(x) = 3x^2
[2] もう一度実行 → (3x^2)' = 6x
[3] もう一度実行 → (6x)' = 6
```
---
## 7.6 多項式の積分（Integrate）
### 例: 3x² - 2x + 1 の積分
```
[1] CAS → 3 (Integrate)
[2] p(x): 3x^2 - 2x + 1
→ ∫p(x)dx = x^3 - x^2 + x + C
```
**確認**:
- ∫3x² dx = x³
- ∫(-2x) dx = -x²
- ∫1 dx = x
- 積分定数 C を付加
💡 **積分定数 C**
不定積分には必ず積分定数 C が付きます。
### 例: x⁴ の積分
```
[1] p(x): x^4
→ ∫p(x)dx = x^5/5 + C
```
### 積分の公式（参考）
| 関数 | 不定積分 |
|---|---|
| xⁿ (n≠-1) | x^(n+1)/(n+1) + C |
| 定数 k | kx + C |
| 1 | x + C |
### 定積分の計算
PoMaS の CAS は不定積分のみ対応。
定積分は、結果を Calculator で計算するか、
電卓の拡張ツール（Fn+8 → 2 → 2 Integral）で数値的に求めます。
---
## 7.7 多項式の加減乗算
### 加算（Add）
**例: (x + 1) + (x - 1)**
```
[1] CAS → 4 (Add)
[2] p(x): x + 1
[3] q(x): x - 1
→ p + q = 2x
```
### 減算
減算は Add で 2 つ目の符号を逆にして実現。
**例: (x + 1) - (x - 1) = 2**
```
[1] p(x): x + 1
[2] q(x): -x + 1    ← 符号を逆に
→ p + q = 2
```
### 乗算（Multiply）
**例: (x + 1) × (x - 1)**
```
[1] CAS → 5 (Multiply)
[2] p(x): x + 1
[3] q(x): x - 1
→ p * q = x^2 - 1
```
**確認**: (x+1)(x-1) = x² - x + x - 1 = x² - 1
### 例: (x + 2)² の展開
```
[1] p(x): x + 2
[2] q(x): x + 2
→ p * q = x^2 + 4x + 4
```
### 例: (2x - 3)(x + 4)
```
[1] p(x): 2x - 3
[2] q(x): x + 4
→ p * q = 2x^2 + 5x - 12
```
**確認**: 2x·x + 2x·4 - 3·x - 3·4 = 2x² + 5x - 12
---
## 7.8 多項式の根（Roots）
多項式 = 0 となる x の値を求めます（複素数対応）。
### 例: x² - 5x + 6 = 0 の根
```
[1] CAS → 6 (Roots)
[2] p(x): x^2 - 5x + 6
→ r1 = 3, r2 = 2
```
**確認**: (x-3)(x-2) = 0 → x = 3, 2
### 例: x² + 1 = 0 の根（複素数）
```
[1] p(x): x^2 + 1
→ r1 = i, r2 = -i
```
**確認**: x² = -1 → x = ±i
### 例: x³ - 6x² + 11x - 6 = 0 の根
```
[1] p(x): x^3 - 6x^2 + 11x - 6
→ r1 = 3, r2 = 2, r3 = 1
```
**確認**: (x-1)(x-2)(x-3) = 0 → x = 1, 2, 3
### 根の精度
PoMaS は **Durand-Kerner 法** という数値解法で根を求めます。
5 次以上でも近似解が得られます。
⚠️ **精度の限界**
- 重解（同じ根が複数）の検出は苦手
- 非常に近い根は、わずかに異なる値になる場合がある
---
## 7.9 テイラー展開（Numerical Taylor）
### テイラー展開とは
複雑な関数を、多項式で近似する技法です。
```
sin(x) ≈ x - x³/6 + x⁵/120 - ...
```
### 例: sin(x) のテイラー展開（x0=0, 次数 5）
```
[1] CAS → 7 (Taylor)
[2] f(x): sin(x)
[3] center x0: 0
[4] order (1-7): 5
→ x - 0.16667(x-0)^3 + 0.00833(x-0)^5
```
**確認**:
- sin(x) の x=0 での展開:
  - 1 次: x
  - 3 次: -x³/3! = -x³/6 ≈ -0.16667x³
  - 5 次: +x⁵/5! = x⁵/120 ≈ 0.00833x⁵
### 例: e^x のテイラー展開（x0=0, 次数 5）
```
[1] f(x): exp(x)
[2] center x0: 0
[3] order: 5
→ 1 + x + 0.5x^2 + 0.16667x^3 + 0.04167x^4 + 0.00833x^5
```
**確認**:
- e^0 = 1
- xⁿ/n!
- x⁰: 1, x¹: 1, x²: 0.5, x³: 0.16667, x⁴: 0.04167, x⁵: 0.00833
### 中心 x0 を変える
x0 ≠ 0 のときは、x-a の多項式になります。
**例: sin(x) の x0=π/2 での展開**
```
[1] f(x): sin(x)
[2] center x0: 1.5708 (π/2)
[3] order: 3
→ 1 - 0.5(x-1.5708)^2 + ...
```
sin は x=π/2 で最大値 1 なので、定数項が 1 になります。
### 精度の確認
テイラー展開の近似精度は、x0 からの距離で決まります。
x0 に近いほど高精度、離れるほど誤差が大きくなります。

## 7.10 極限（Numerical Limit）
### 例: lim(x→0) sin(x)/x
**理論値**: 1
```
[1] CAS → 8 (Limit)
[2] f(x): sin(x)/x
[3] x ->: 0
→ Limit = 1.000000
```
### 例: lim(x→0) (1-cos(x))/x²
**理論値**: 1/2
```
[1] f(x): (1-cos(x))/x^2
[2] x ->: 0
→ Limit = 0.500000
```
### 例: lim(x→∞) 1/x
**理論値**: 0
```
[1] f(x): 1/x
[2] x ->: 1000000   ← 大きな値
→ Limit = 0.000001
```
💡 **無限大の極限**
真の ∞ は入力できないので、代わりに大きな値で近似します。
### 極限が存在しない場合
左右の極限が一致しない場合、エラーメッセージが表示されます。
**例: lim(x→0) 1/x**
```
→ L=-1000000 R=1000000 (diff)
```

## 7.11 記号置換（Substitute）
式の中の x を、別の式に置き換えます。
### 例: x² + 3x + 2 の x → y+1
```
[1] CAS → 9 (Substitute)
[2] f(x): x^2 + 3x + 2
[3] Replace x = y+1
→ (y+1)^2 + 3(y+1) + 2
```
結果は展開されず、置換後の式がそのまま表示されます。
### 使用例
**例: f(x) = x² で x → a+b**
```
[1] f(x): x^2
[2] x = a+b
→ (a+b)^2
```
**期待**: (a+b)² = a² + 2ab + b²
PoMaS は展開しないので、結果を手で展開するか、
Calculator で計算します。

## 7.12 この章のまとめ
- CAS は数式をそのまま操作する
- 多項式の評価・微分・積分・加減乗算
- 根の計算（複素数対応）
- テイラー展開（任意の関数、次数 1〜7）
- 極限（数値的アプローチ）
- 記号置換（展開は手動）
- 入力は `x^2 + 3x + 2` の形式（`*` 記号は不要）
### 確認問題
📝 **Q7-1**: x³ - 2x + 1 を x=2 で評価すると？
<details><summary>答え</summary>
8 - 4 + 1 = 5
</details>
📝 **Q7-2**: x³ - 2x + 1 の導関数は？
<details><summary>答え</summary>
3x² - 2
</details>
📝 **Q7-3**: ∫3x² dx は？
<details><summary>答え</summary>
x³ + C
</details>
📝 **Q7-4**: x² - 5x + 6 = 0 の根は？
<details><summary>答え</summary>
x = 2, 3（(x-2)(x-3) = 0）
</details>

<details><summary>答え</summary>
x² - 1
</details>

<details><summary>答え</summary>
x - x³/6 ≈ x - 0.16667x³
</details>
