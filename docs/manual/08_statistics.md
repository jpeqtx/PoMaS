## 8.1 統計とは
**統計** は、データ（数値の集まり）から意味のある情報を引き出す学問です。
### 統計の基本的な流れ
```
[1] データを集める
       ↓
[2] データを整理する（平均、中央値など）
       ↓
[3] データの特徴を分析する（散らばり、傾向）
       ↓
[4] 結論を導く（検定、予測）
```
### PoMaS の統計機能
PoMaS は、統計解析のための本格的なツールを搭載しています。
| 機能 | 内容 |
|---|---|
| **Lists** | データを 8 つのリストに保存（各 200 件） |
| **記述統計** | 平均、中央値、標準偏差など |
| **回帰** | 2 つのデータの関係を式で表す |
| **検定** | 2 つのデータが「同じ」と言えるか判定 |
| **グラフ** | データを視覚化（17 種類） |

## 8.4 記述統計（Descriptive Statistics）
### 記述統計とは
**記述統計** は、データの特徴を数値で要約する方法です。
**主な指標**:
- 平均（mean）: データの中心
- 中央値（median）: データを並べたときの真ん中
- 標準偏差（sd）: データの散らばり具合
### 起動
```
Statistics → 1 (Lists & Descriptive) → 3 (Descriptive Statistics)
```
### 例: L1 = [10, 20, 30, 40, 50] の記述統計
```
[1] List? → 1 (L1)
→ 記述統計ページ 1:
n      = 5
sum    = 150
sum2   = 5500
mean   = 30
sd(samp) = 15.811
sd(pop)  = 14.142
var(samp) = 250
SE       = 7.071  CV = 52.705%
min      = 10   max = 50
→ 記述統計ページ 2（右キー）:
Q1   = 20
med  = 30
Q3   = 40
IQR  = 20   range = 40
skew = 0
kurt = -1.3 (excess)
mode = 10 (x1)
```
### 各指標の意味
| 指標 | 意味 | 計算式 |
|---|---|---|
| **n** | データ件数 | — |
| **sum** | 合計 | Σx |
| **sum2** | 2 乗の合計 | Σx² |
| **mean** | 平均 | Σx / n |
| **sd(samp)** | 標本標準偏差 | √(Σ(x-μ)² / (n-1)) |
| **sd(pop)** | 母標準偏差 | √(Σ(x-μ)² / n) |
| **var(samp)** | 標本分散 | sd(samp)² |
| **SE** | 標準誤差 | sd(samp) / √n |
| **CV** | 変動係数 | sd(samp) / |mean| × 100% |
| **min** | 最小値 | — |
| **max** | 最大値 | — |
| **Q1** | 第 1 四分位数 | データの 25% 点 |
| **med** | 中央値 | データの 50% 点 |
| **Q3** | 第 3 四分位数 | データの 75% 点 |
| **IQR** | 四分位範囲 | Q3 - Q1 |
| **skew** | 歪度 | 分布の左右非対称度 |
| **kurt** | 尖度 | 分布の尖り具合 |
| **mode** | 最頻値 | 最も多く出現する値 |
### 標本 vs 母集団
| 用語 | 意味 | 使い分け |
|---|---|---|
| **標本標準偏差** | 一部のデータから全体を推定 | 一般的にはこちら |
| **母標準偏差** | データ全体の標準偏差 | 全データが手元にある場合 |
💡 **迷ったら標本標準偏差（sd samp）**
統計学の慣例では、標本標準偏差を使うことが多いです。
### 四分位数の計算
データを小さい順に並べ、4 等分する点です。
**例: [10, 20, 30, 40, 50]**
- Q1（25%）= 20
- med（50%）= 30
- Q3（75%）= 40
### 歪度と尖度
**歪度（skewness）**:
- 0: 左右対称
- 正: 右に裾が長い
- 負: 左に裾が長い
**尖度（kurtosis、超過）**:
- 0: 正規分布と同じ
- 正: 尖っている（裾が重い）
- 負: 平たい
### ページ切り替え
記述統計の結果は **2 ページ** に分かれています。
左右キー（`Fn + ,` / `Fn + /`）で切り替え。
### Ans への転送
`Y` キーで平均値を Ans に転送できます。

## 8.5 変数の尺度（Variable Scale）
### 尺度とは
データには 4 種類の尺度があり、尺度によって使える統計手法が変わります。
| 尺度 | 例 | 使える演算 |
|---|---|---|
| **比例（Ratio）** | 身長、体重、金額 | 加減乗除すべて |
| **間隔（Interval）** | 温度（℃）、年号 | 加減（比率は不可） |
| **順序（Ordinal）** | 成績（優良可）、満足度 | 大小比較のみ |
| **名義（Nominal）** | 性別、血液型 | 分類のみ（大小なし） |
### 設定方法
```
Statistics → 1 (Lists & Descriptive) → 2 (Variable Scale)
[1] リスト選択
[2] 尺度選択
```

## 8.6 特殊な平均（Special Means）
### 起動
```
Statistics → 1 (Lists & Descriptive) → 4 (Special Means)
```
### 種類
| 種類 | 計算式 | 用途 |
|---|---|---|
| **重み付き平均** | Σ(w·x) / Σw | 重みの異なるデータ |
| **幾何平均** | (x₁·x₂·...·xₙ)^(1/n) | 成長率、比率 |
| **調和平均** | n / Σ(1/x) | 速度、率 |
| **トリム平均** | 両端を除いた平均 | 外れ値の影響を減らす |
### 例: 重み付き平均
**例: テストの点数（中間 30%、期末 70%）**
- 中間: 60 点
- 期末: 80 点
```
[1] L1 = [60, 80]（点数）
[2] L2 = [30, 70]（重み）
[3] Weighted mean → (60×30 + 80×70) / (30+70) = 74
```
### 例: 幾何平均
**例: 3 年間の成長率 [1.1, 1.2, 1.15]**
```
[1] L1 に [1.1, 1.2, 1.15]
[2] Geometric mean → (1.1 × 1.2 × 1.15)^(1/3) ≈ 1.149
```
年平均成長率は約 14.9%。
### 例: 調和平均
**例: 行き 60km/h、帰り 40km/h の平均速度**
距離を 1 とすると:
- 行き: 1/60 時間
- 帰り: 1/40 時間
- 合計 2 時間（距離 2）
- 平均速度 = 2 / (1/60 + 1/40) = 48 km/h
💡 **相加平均との違い**
相加平均は (60+40)/2 = 50 ですが、
正しい平均速度は 48 km/h（調和平均）。

## 8.7 回帰（Regression）
### 回帰とは
**回帰** は、2 つのデータの関係を式で表す手法です。
**例: 身長と体重の関係**
```
身長 x → 体重 y
y = a + bx
```
この式を使うと、身長から体重を予測できます。
### 起動
```
Statistics → 2 (Regression)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Regression                      │
├─────────────────────────────────┤
│1 Linear (LSM)                   │
│2 Quadratic                      │
│3 Power                          │
│4 Exponential                    │
│5 Logarithmic                    │
│6 Logistic (2-par logit)         │
│7 Med-Med                        │
│8 Multiple Regression            │
│9 Stepwise Selection             │
│10 Predict y from x              │
│11 Save residuals to L?          │
│12 Back                          │
└─────────────────────────────────┘
```
### 例: 線形回帰（Linear）
**データ**: X = L1 = [1, 2, 3, 4, 5], Y = L2 = [2, 4, 6, 8, 10]
**期待される結果**: y = 0 + 2x（y = 2x）
```
[1] Regression → 1 (Linear)
[2] X list: 1 (L1)
[3] Y list: 2 (L2)
→ y = a + b x
  a = 0
  b = 2
  r² = 1.0000
  r  = 1.0000
```
💡 **r² = 1 は完全な相関**
データが完全に直線上にある場合、r² = 1 になります。
### 各回帰の意味
| 種類 | 式 | 用途 |
|---|---|---|
| **Linear** | y = a + bx | 直線関係 |
| **Quadratic** | y = a + bx + cx² | 放物線関係 |
| **Power** | y = a·x^b | 累乗関係 |
| **Exponential** | y = a·e^(bx) | 指数関係（成長・減衰） |
| **Logarithmic** | y = a + b·ln(x) | 対数関係 |
| **Logistic** | logit(y) = a + bx | 0〜1 の確率 |
| **Med-Med** | y = a + bx（中央値ベース） | 外れ値に強い |
| **Multiple** | y = b0 + b1x1 + ... | 多変量 |
### 決定係数 r²
**r²（決定係数）** は、回帰式の当てはまりの良さを示します。
| r² | 評価 |
|---|---|
| 0.9〜1.0 | 非常によく当てはまる |
| 0.7〜0.9 | よく当てはまる |
| 0.5〜0.7 | 中程度 |
| 0.3〜0.5 | 弱い |
| 0〜0.3 | ほとんど当てはまらない |
### 予測（Predict y from x）
**例: 回帰式 y = 2x で x=10 のときの y を予測**
```
[1] Regression → 10 (Predict)
[2] x = 10
→ y = 20
```
### 残差の保存（Save residuals）
残差 = 実測値 - 予測値。
回帰式の当てはまりを確認するために使います。
```
[1] Regression → 11 (Save residuals)
[2] 保存先リスト: L3
→ L3 に残差が保存される
```
### 多重回帰（Multiple Regression）
**例: y を x1, x2 で予測**
```
[1] Regression → 8 (Multiple)
[2] # predictors: 2
[3] X1 list: 1 (L1)
[4] X2 list: 2 (L2)
[5] Y list: 3 (L3)
→ y = b0 + b1*x1 + b2*x2
  b0 = ...
  b1 = ...
  b2 = ...
  R² = ...
  F = ...
  p(F) = ...
```
複数の要因が関与する現象の分析に使います。

## 8.8 検定（Tests）
### 検定とは
**検定** は、データから「主張が正しいか」を判断する統計手法です。
**例**:
- 「新しい薬は効くか？」
- 「2 つのクラスの平均点は違うか？」
- 「サイコロは偏っていないか？」
### 起動
```
Statistics → 3 (Tests)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Tests                           │
├─────────────────────────────────┤
│1 z-test (1-sample)              │
│2 t-test (1-sample)              │
│3 t-test (2-sample, eq. var)     │
│4 Welch's t-test                 │
│5 Paired t-test                  │
│6 F-test (variance)              │
│7 One-way ANOVA                  │
│8 Two-way ANOVA                  │
│9 Chi-Square GOF                 │
│10 Chi-Square Independence       │
│11 Fisher's exact (2x2)          │
│12 Back                          │
└─────────────────────────────────┘
```
### 帰無仮説と対立仮説
| 仮説 | 意味 |
|---|---|
| **帰無仮説（H₀）** | 「差がない」「効果がない」 |
| **対立仮説（H₁）** | 「差がある」「効果がある」 |
検定では、帰無仮説を棄却できるか（否定できるか）を判断します。
### p 値
**p 値** は、「帰無仮説が正しいとき、このデータが得られる確率」です。
| p 値 | 判断 |
|---|---|
| p < 0.05 | 帰無仮説を棄却（有意差あり） |
| p ≥ 0.05 | 帰無仮説を棄却できない（有意差なし） |
⚠️ **p < 0.05 は「有意」だが「絶対」ではない**
0.05 は慣例的な基準です。分野によっては 0.01 を使うこともあります。
### 例: 1 標本 t 検定
**問題**: あるクラスのテスト平均が全国平均 60 点と異なるか？
**データ**: L1 = [65, 70, 55, 62, 68, 72, 58]
```
[1] Tests → 2 (t-test 1-sample)
[2] Sample list: 1 (L1)
[3] mu0: 60
[4] Side: Two-sided
→ stat = 1.961
  df   = 6
  p    = 0.0972
  n.s.（有意差なし）
```
**判断**: p = 0.097 > 0.05 なので、全国平均と異なるとは言えない。
### 例: 2 標本 t 検定（等分散）
**問題**: クラス A と B の平均点に差があるか？
**データ**: L1（A 組） = [65, 70, 55, 62, 68], L2（B 組） = [72, 78, 75, 70, 80]
```
[1] Tests → 3 (t-test 2-sample eq)
[2] Group A list: 1
[3] Group B list: 2
[4] Side: Two-sided
→ stat = -3.474
  df   = 8
  p    = 0.0083
  * significant (a=0.05)
```
**判断**: p = 0.008 < 0.05 なので、有意差あり。
### 例: 対応あり t 検定（Paired t-test）
**問題**: ダイエット前後の体重に差があるか？
**データ**: L1 = 前体重、L2 = 後体重
```
[1] Tests → 5 (Paired t-test)
[2] Pair A list: 1
[3] Pair B list: 2
```
同じ人の「前」「後」を比較する場合に使います。
### 例: χ² 適合度検定（Chi-Square GOF）
**問題**: サイコロの各目が公平に出るか？
**データ**:
- L1 = 観測度数 [18, 22, 17, 20, 21, 22]
- L2 = 期待度数 [20, 20, 20, 20, 20, 20]
```
[1] Tests → 9 (Chi-Square GOF)
[2] Observed: 1
[3] Expected: 2
→ Chi^2 = 1.1
  df    = 5
  p     = 0.954
  n.s.
```
**判断**: p が大きいので、サイコロは偏っていないと判断。
### 検定の選択フローチャート
```
データの種類は？
├─ 連続量（身長、点数など）
│   ├─ 1 群の平均 → 1-sample t-test
│   ├─ 2 群の平均
│   │   ├─ 対応なし → 2-sample t-test
│   │   └─ 対応あり → paired t-test
│   └─ 3 群以上の平均 → ANOVA
└─ カテゴリ（性別、血液型など）
    ├─ 1 変数の分布 → Chi-Square GOF
    ├─ 2 変数の関連 → Chi-Square Independence
    └─ 2×2 の小標本 → Fisher's exact
```

## 8.9 記述統計の各指標 詳細

### 8.9.1 平均（mean）

**数式**: x̄ = Σxᵢ / n

**用途**: データの中心傾向。最も基本的な代表値。

**例**: [10, 20, 30, 40, 50] → (150)/5 = 30

**注意点**: 外れ値に弱い（1 つの極端な値で大きく動く）

### 8.9.2 中央値（median）

**数式**: データを小さい順に並べた中央値（偶数個なら中間 2 つの平均）

**例**: [10, 20, 30, 40, 50] → 30、[10, 20, 30, 40] → 25

**用途**: 外れ値に強い代表値。所得分布などで頻用。

### 8.9.3 最頻値（mode）

**用途**: 最も多く出現する値。

**例**: [1, 2, 2, 3, 3, 3, 4] → 3（3 回）

**備考**: 複数の最頻値がある場合、最小値を返す

### 8.9.4 分散（variance）

**標本分散**: s² = Σ(xᵢ - x̄)² / (n-1)

**母分散**: σ² = Σ(xᵢ - μ)² / n

**用途**: データの散らばりの 2 乗平均。標準偏差の 2 乗。

### 8.9.5 標準偏差（standard deviation）

**標本**: s = √s²、**母**: σ = √σ²

**用途**: データの散らばり具合。平均と同じ単位。

**経験則**（正規分布）:
- 平均 ± 1σ: 約 68% のデータ
- 平均 ± 2σ: 約 95%
- 平均 ± 3σ: 約 99.7%

### 8.9.6 四分位数（Q1, Q3）と IQR

**Q1**: 25% 点、**Q3**: 75% 点、**IQR**: Q3 - Q1

**外れ値判定**: Q1 - 1.5×IQR 未満、または Q3 + 1.5×IQR 超

**例**: [10, 20, 30, 40, 50] → Q1=20, Q3=40, IQR=20

### 8.9.7 歪度（skewness）

**数式**: g₁ = m₃ / s³（m₃ は 3 次モーメント）

**解釈**:
- 0: 左右対称
- 正: 右に裾が長い（平均 > 中央値）
- 負: 左に裾が長い（平均 < 中央値）

### 8.9.8 尖度（kurtosis）

**数式**: g₂ = m₄ / s⁴ - 3（超過尖度）

**解釈**:
- 0: 正規分布と同じ
- 正: 尖っている（裾が重い）
- 負: 平たい

## 8.10 回帰分析 詳細（9 種類）

### 8.10.1 線形回帰（Linear, LSM）

**数式**: y = a + bx

**最小二乗法**:
```
b = Sxy / Sxx
a = ȳ - b·x̄
Sxx = Σ(xᵢ-x̄)², Sxy = Σ(xᵢ-x̄)(yᵢ-ȳ)
```

**決定係数**: r² = Sxy² / (Sxx·Syy)

**例**:
```
X = [1,2,3,4,5], Y = [2,4,6,8,10]
→ y = 0 + 2x, r² = 1.0
```

**用途**: 直線的な関係、最も汎用

### 8.10.2 二次回帰（Quadratic）

**数式**: y = a + bx + cx²

**正規方程式**:
```
[n    Σx   Σx² ] [a]   [Σy  ]
[Σx   Σx²  Σx³ ] [b] = [Σxy ]
[Σx²  Σx³  Σx⁴ ] [c]   [Σx²y]
```

**用途**: 放物線関係（最適化、物理現象）

### 8.10.3 累乗回帰（Power）

**数式**: y = a·x^b

**線形化**: ln y = ln a + b·ln x

**制約**: x > 0, y > 0

**用途**: スケーリング則（生物学、物理学）

### 8.10.4 指数回帰（Exponential）

**数式**: y = a·e^(bx)

**線形化**: ln y = ln a + bx

**制約**: y > 0

**用途**: 成長/減衰、放射性崩壊、人口増加

### 8.10.5 対数回帰（Logarithmic）

**数式**: y = a + b·ln x

**制約**: x > 0

**用途**: 収穫逓減、刺激-反応関係

### 8.10.6 ロジスティック回帰（Logistic, 2-param logit）

**数式**: logit(y) = ln(y/(1-y)) = a + bx

**制約**: 0 < y < 1

**用途**: 確率の予測、感染症の S 字曲線

### 8.10.7 Med-Med 回帰

**用途**: 中央値を用いたロバスト回帰。外れ値に強い。

**アルゴリズム**:
1. データを x で 3 分割
2. 各グループの (x_med, y_med) を計算
3. 3 点を通る直線を最小二乗で求める

**用途**: 外れ値の多い実データ

### 8.10.8 重回帰（Multiple Regression）

**数式**: y = b₀ + b₁x₁ + b₂x₂ + ... + bₖxₖ

**計算**: β = (XᵀX)⁻¹ Xᵀy

**出力**:
- 係数 b₀〜bₖ
- R²、調整済み R²
- F 統計量、p 値
- 各係数の標準誤差・t 値・p 値
- 95% 信頼区間
- VIF（多重共線性の指標）

**用途**: 多因子の影響分析

### 8.10.9 ステップワイズ選択（Stepwise）

**用途**: 変数を 1 つずつ追加して最良モデルを自動選択。

**出力**: 追加順と R² の変化

**用途**: 変数選択、モデル構築

## 8.11 仮説検定の基礎

### 8.11.1 帰無仮説と対立仮説

| 仮説 | 意味 | 例 |
|---|---|---|
| H₀（帰無仮説） | 「差がない」「効果がない」 | 平均 = 60 |
| H₁（対立仮説） | 「差がある」「効果がある」 | 平均 ≠ 60 |

### 8.11.2 p 値

**定義**: H₀ が真のとき、観測データ以上に極端な結果が得られる確率。

| p 値 | 判断 |
|---|---|
| p < 0.01 | 高度に有意 |
| p < 0.05 | 有意 |
| p ≥ 0.05 | 有意でない |

### 8.11.3 有意水準 α と Type I/II エラー

| 状態 | H₀ 真 | H₀ 偽 |
|---|---|---|
| H₀ 棄却 | Type I エラー（α） | 正しい判断（検出力） |
| H₀ 受容 | 正しい判断 | Type II エラー（β） |

- α = 0.05 → 5% の確率で偽陽性
- 検出力 = 1 - β

### 8.11.4 両側検定と片側検定

**両側**: H₁: μ ≠ μ₀ → p 値を 2 倍
**片側（上）**: H₁: μ > μ₀
**片側（下）**: H₁: μ < μ₀

PoMaS では `Side: Two-sided/Upper/Lower` で選択。

## 8.12 z 検定（1 標本）

**用途**: 母集団の標準偏差 σ が既知のとき、標本平均が母平均 μ₀ と異なるか。

**数式**:
```
z = (x̄ - μ₀) / (σ/√n)
```

**前提**: 正規分布、σ 既知、n 十分大

**例**: L1 = [65,70,55,62,68,72,58]、μ₀=60、σ=5
```
[1] Tests → 1 (z-test)
[2] Sample: L1
[3] mu0: 60
[4] sigma: 5
[5] Side: Two-sided
→ z = 1.679, p = 0.093 (n.s.)
```

**実務**: σ 既知のケースは稀、通常は t 検定を使う

---

## 8.13 t 検定 詳細

### 8.13.1 1 標本 t 検定

**数式**:
```
t = (x̄ - μ₀) / (s/√n),  df = n-1
```

**用途**: 母標準偏差 σ が未知のとき、標本平均を μ₀ と比較。

**例**: L1 = [65,70,55,62,68,72,58]、μ₀=60
```
→ t = 1.961, df = 6, p = 0.097 (n.s.)
```

### 8.13.2 2 標本 t 検定（等分散）

**数式**:
```
t = (x̄₁ - x̄₂) / (sp·√(1/n₁ + 1/n₂))
sp² = ((n₁-1)s₁² + (n₂-1)s₂²) / (n₁+n₂-2)
df = n₁ + n₂ - 2
```

**前提**: 2 群の分散が等しい（F 検定で確認）

**例**: L1=[65,70,55,62,68], L2=[72,78,75,70,80]
```
→ t = -3.474, df = 8, p = 0.008 (significant)
```

### 8.13.3 Welch の t 検定（等分散を仮定しない）

**数式**:
```
t = (x̄₁ - x̄₂) / √(s₁²/n₁ + s₂²/n₂)
df = (s₁²/n₁ + s₂²/n₂)² / [(s₁²/n₁)²/(n₁-1) + (s₂²/n₂)²/(n₂-1)]
```

**用途**: 分散が異なる可能性がある場合（より安全）

**推奨**: 等分散が確実でない限り Welch を使う

### 8.13.4 対応あり t 検定（Paired）

**数式**:
```
dᵢ = x₁ᵢ - x₂ᵢ
t = d̄ / (s_d/√n),  df = n-1
```

**用途**: 同一対象の前後比較（ダイエット前後、投薬前後）

**例**: L1=前体重、L2=後体重（同じ人 5 人）
```
→ t = ..., df = 4, p = ...
```

## 8.14 F 検定（分散の比較）

**数式**:
```
F = s₁² / s₂²,  df1 = n₁-1, df2 = n₂-1
```

**用途**: 2 群の分散が等しいか（等分散性の検定）

**p 値**: F 分布の両側

**例**: L1, L2 の分散比較
```
→ F = ..., df1 = ..., df2 = ..., p = ...
```

**注意**: t 検定の前段として使うが、正規性が前提

## 8.15 ANOVA（分散分析）

### 8.15.1 1 元配置 ANOVA

**用途**: 3 群以上の平均を同時比較。

**数式**:
```
SSB = Σ nᵢ(x̄ᵢ - x̄)²    (群間変動)
SSW = Σ Σ (xᵢⱼ - x̄ᵢ)²   (群内変動)
F = (SSB/(k-1)) / (SSW/(N-k))
```

**k**: 群数、**N**: 全データ数

**p < 0.05** → 「少なくとも 1 組に差がある」

**事後検定**: Tukey HSD、Bonferroni 等で個別比較

### 8.15.2 2 元配置 ANOVA

**用途**: 2 つの因子の主効果と交互作用を検討。

**出力**:
- Factor A の主効果
- Factor B の主効果
- A × B の交互作用

**前提**: L1=Y、L2=A 水準、L3=B 水準

---

## 8.16 χ² 検定 詳細

### 8.16.1 適合度検定（GOF）

**用途**: 観測度数が期待度数と一致するか。

**数式**:
```
χ² = Σ (Oᵢ - Eᵢ)² / Eᵢ,  df = k - 1
```

**例**: サイコロ 6 面の公平性
```
L1 = [18, 22, 17, 20, 21, 22]  (観測)
L2 = [20, 20, 20, 20, 20, 20]  (期待)
→ χ² = 1.1, df = 5, p = 0.954 (公平)
```

### 8.16.2 独立性検定

**用途**: 2 変数が独立か（関連なし）を検定。

**数式**:
```
Eᵢⱼ = (row_i × col_j) / N
χ² = Σ (Oᵢⱼ - Eᵢⱼ)² / Eᵢⱼ
df = (r-1)(c-1)
```

**例**: 性別 × 喫煙（2×2）
```
          喫煙  非喫煙
男性       30    70
女性       20    80
→ χ² = ..., df = 1, p = ...
```

## 8.17 Fisher 正確検定

**用途**: 2×2 分割表で期待度数 < 5 のセルがある場合の正確検定。

**原理**: 超幾何分布による厳密計算

**例**:
```
          陽性  陰性
暴露群      8    2
非暴露群    3    7
→ p = 0.0349 (両側)
```

**PoMaS 実装**: lgamma による厳密確率計算

## 8.18 多重比較補正

### 8.18.1 Bonferroni

**方法**: p 値を比較回数 m で割る（α/m）

**例**: 5 回検定 → α = 0.05/5 = 0.01

**利点**: 単純、保守的

**欠点**: 検出力が低い

### 8.18.2 Holm（段階的 Bonferroni）

**方法**: p 値を昇順に並べ、k 番目は α/(m-k+1) と比較

**利点**: Bonferroni より検出力高い

### 8.18.3 FDR（Benjamini-Hochberg）

**方法**: p(k) ≤ k×α/m を満たす最大 k まで棄却

**用途**: 探索的研究（多数検定）

## 8.19 効果量（Effect Size）

### 8.19.1 Cohen's d（2 群比較）

**数式**:
```
d = (x̄₁ - x̄₂) / sp
sp = √((s₁² + s₂²) / 2)
```

**解釈**:

| d | 効果 |
|---|---|
| 0.2 | 小 |
| 0.5 | 中 |
| 0.8 | 大 |

### 8.19.2 η²（ANOVA）

**数式**: η² = SSB / SST

**解釈**:

| η² | 効果 |
|---|---|
| 0.01 | 小 |
| 0.06 | 中 |
| 0.14 | 大 |

### 8.19.3 Cramér's V（χ² 検定）

**数式**:
```
V = √(χ² / (N × min(r-1, c-1)))
```

**範囲**: 0〜1、1 に近いほど関連強い

### 8.19.4 相関係数 r

**解釈**:

| r | 相関 |
|---|---|
| 0〜0.3 | 弱 |
| 0.3〜0.7 | 中 |
| 0.7〜1.0 | 強 |

### 確認問題
📝 **Q8-1**: L1 = [10, 20, 30, 40, 50] の平均は？
<details><summary>答え</summary>
(10+20+30+40+50)/5 = 150/5 = 30
</details>
📝 **Q8-2**: 標本標準偏差と母標準偏差の違いは？
<details><summary>答え</summary>
標本は n-1 で割る、母は n で割る。標本は一部データから全体を推定する場合に使う。
</details>
📝 **Q8-3**: r² = 1 は何を意味するか？
<details><summary>答え</summary>
回帰式がデータに完全に当てはまっている（全点が回帰線上にある）。
</details>
📝 **Q8-4**: p = 0.03 のとき、有意水準 0.05 では？
<details><summary>答え</summary>
p < 0.05 なので、帰無仮説を棄却（有意差あり）。
</details>
📝 **Q8-5**: ダイエット前後の体重比較に適した検定は？
<details><summary>答え</summary>
対応あり t 検定（paired t-test）。同じ人の前後を比較するため。
</details>
