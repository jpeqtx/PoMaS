## 10.1 グラフモードとは
**Graph モード** は、関数のグラフを描画するモードです。
### グラフでできること
| 機能 | 説明 |
|---|---|
| 関数グラフの描画 | y = f(x) の曲線 |
| パラメトリック | x(t), y(t) の媒介変数表示 |
| 極座標 | r = f(t) の極座標 |
| 陰関数 | f(x, y) = 0 の曲線 |
| 不等式 | f(x, y) > 0 の領域 |
| 数列 | a_n のプロット |
| 3D プロット | z = f(x, y) のワイヤーフレーム |
| トレース | カーソルで座標を読む |
| G-Solve | 根・極値・交点・積分 |
| 接線・法線 | 指定点の接線/法線 |
### 画面サイズとアスペクト比
PoMaS の画面は **240 × 135 ピクセル**で、
グラフ描画領域は **240 × 105 ピクセル**（ヘッダ・フッタを除く）です。
```
画面全体: 240 × 135
グラフ領域: 240 × 105
→ 横長の領域
```
⚠️ **アスペクト比の注意**
X 軸と Y 軸のスケールが異なるため、
数学的な円が楕円に見える場合があります。
真円表示には **Square aspect (1:1)** を使います（10.4 節）。

## 10.3 関数の編集（Edit functions）
### 基本操作
`2 (Edit functions)` で 4 本まで関数を登録できます。
```
┌─────────────────────────────────┐
│▌Edit Fns                        │
├─────────────────────────────────┤
│1 *: sin(x)                      │  ← 有効・登録済み
│2  : <empty>                     │  ← 無効・未登録
│3  : <empty>                     │
│4  : <empty>                     │
└─────────────────────────────────┘
```
- `*` = 有効（プロットされる）
- ` ` = 無効（プロットされない）
- `<empty>` = 未登録
### 例: 関数 y = sin(x) を登録
```
[1] Graph → 2 (Edit functions)
[2] 1 番目を選択
[3] "sin(x)" と入力
[4] Enter
→ *1: sin(x)
```
### 例: 複数関数の登録
```
[1] sin(x)
[2] cos(x)
[3] tan(x)
→ 3 本の三角関数が同時にプロット可能
```
### 関数の無効化
空文字列（何も入力しない）で Enter すると、その枠は無効になります。

## 10.4 Plot type（描画タイプ）
`3 (Plot type)` で描画の種類を選択します。
```
┌─────────────────────────────────┐
│▌Plot Type                       │
├─────────────────────────────────┤
│1 y = f(x)                       │
│2 Parametric x(t),y(t)           │
│3 Polar r=f(t)                   │
│4 Implicit f(x,y)=0              │
│5 Inequality f(x,y)>0            │
│6 Sequence a_n                   │
│7 3D z=f(x,y)                    │
│8 Back                           │
└─────────────────────────────────┘
```
### タイプ 1: y = f(x)
**最も基本的なグラフ。**
**例: y = sin(x)**
```
[1] Plot type → 1 (y=f(x))
[2] Edit functions → sin(x)
[3] Plot current functions
→ 正弦波が表示される
```
**入力書式**:
- `sin(x)`, `cos(x)`, `tan(x)`
- `x^2`, `x^3 - 2x + 1`
- `exp(x)`, `log(x)`
- `1/x`, `sqrt(x)`
### タイプ 2: Parametric（パラメトリック）
**x(t), y(t) を媒介変数 t で表す。**
**例: 円（半径 1）**
```
[1] Plot type → 2 (Parametric)
[2] Edit functions → cos(t);sin(t)
[3] Plot current functions
→ 円が表示される
```
⚠️ **セミコロン区切り**
x(t) と y(t) は `;`（セミコロン）で区切ります。
**例: リサージュ図形**
```
sin(3t);sin(2t)
```
**例: 螺旋**
```
t*cos(t);t*sin(t)
```
### タイプ 3: Polar（極座標）
**r = f(t) の形で曲線を描く。**
**例: カージオイド（ハート形）**
```
[1] Plot type → 3 (Polar)
[2] Edit functions → 1+cos(t)
[3] Plot current functions
→ ハート形の曲線
```
**例: バラ曲線**
```
cos(3t)
```
**例: 螺旋**
```
t
```
### タイプ 4: Implicit（陰関数）
**f(x, y) = 0 の形の曲線。**
**例: 円 x² + y² = 4**
```
[1] Plot type → 4 (Implicit)
[2] Edit functions → x^2+y^2-4
[3] Plot current functions
→ 円が表示される
```
**例: 楕円 x²/4 + y² = 1**
```
x^2/4+y^2-1
```
**例: 双曲線 x² - y² = 1**
```
x^2-y^2-1
```
💡 **陰関数のコツ**
`x^2 + y^2 - 4 = 0` をそのまま入力します。
（`=0` は省略可）
### タイプ 5: Inequality（不等式）
**f(x, y) > 0 の領域を塗りつぶす。**
**例: x + y > 0 の領域**
```
[1] Plot type → 5 (Inequality)
[2] Edit functions → x+y
[3] Plot current functions
→ 直線 y = -x の上の領域が塗られる
```
**例: 単位円の内側**
```
4-x^2-y^2
```
（`4 - x² - y² > 0` は x² + y² < 4、つまり半径 2 の円の内側）
### タイプ 6: Sequence（数列）
**a_n を n についてプロット。**
**例: a_n = 1/n**
```
[1] Plot type → 6 (Sequence)
[2] Edit functions → 1/n
[3] Range → n start: 1, n end: 30
[4] Plot current functions
→ 点のプロット（1, 1/2, 1/3, ...）
```
**例: a_n = n²**
```
n^2
```
### タイプ 7: 3D
**z = f(x, y) のワイヤーフレーム。**
**例: z = sin(x)·cos(y)**
```
[1] Plot type → 7 (3D)
[2] Edit functions → sin(x)*cos(y)
[3] Range → zmin: -2, zmax: 2
[4] Plot current functions
→ 3D 曲面のワイヤーフレーム
```
⚠️ **3D は軽量表示**
PoMaS の 3D はワイヤーフレーム（線のみ）で、
塗りつぶしはしません。

## 10.5 Range / Window（範囲設定）
`4 (Range / Window)` で表示範囲を設定します。
### 設定項目
| 項目 | 意味 |
|---|---|
| xmin, xmax | X 軸の最小値・最大値 |
| ymin, ymax | Y 軸の最小値・最大値 |
| tmin, tmax, tstep | 媒介変数（Parametric/Polar 用） |
| n start, n end | 数列の開始・終了（Sequence 用） |
| zmin, zmax | Z 軸の範囲（3D 用） |
### 例: -5 〜 5 の範囲
```
[1] Range → 4
[2] xmin: -5
[3] xmax: 5
[4] ymin: -5
[5] ymax: 5
→ X, Y とも -5〜5 の範囲
```
### 標準ウィンドウ（Standard window）
`5 (Standard window)` で以下の範囲にリセット：
- xmin: -10, xmax: 10
- ymin: -10, ymax: 10
### 三角関数ウィンドウ（Trig window）
`6 (Trig window)` で三角関数に最適な範囲にリセット：
- xmin: -2π ≈ -6.28
- xmax: +2π ≈ +6.28
- ymin: -1.5, ymax: 1.5
sin(x), cos(x) の 1 周期以上が見えます。
### Square aspect (1:1)
`7 (Square aspect)` で X/Y の等比スケールに調整：
**動作**:
- 現在の X 範囲を保つ
- Y 範囲を (X 範囲) × (105/240) に自動調整
**例**: X 範囲 -3〜3（幅 6）のとき
- Y 範囲 = 6 × 105/240 = 2.625 → -1.3125 〜 +1.3125
**使い方**:
```
[1] Range で -3, 3, -3, 3 を設定
[2] Square aspect を実行
[3] Implicit で x^2+y^2-4 をプロット
→ 真円が表示される
```

## 10.7 ズームとトレース
### ズームイン（Z）
画面中央を中心に、範囲を 1/2 倍に縮小します。
```
[1] プロット中に Z を押す
→ xmin, xmax が現在の 1/4 幅、ymin, ymax が 1/4 高さに
```
**連続ズーム**: Z を押すたびに縮小。
### ズームアウト（X）
画面中央を中心に、範囲を 2 倍に拡大します。
### ボックスズーム（B）
数値入力で任意の範囲にジャンプ：
```
[1] B を押す
[2] zoom xmin: -1
[3] zoom xmax: 1
[4] zoom ymin: -1
[5] zoom ymax: 1
→ -1〜1 の範囲に拡大
```
### トレース（T）
カーソルで曲線上の座標を読み取ります。
```
[1] プロット中に T を押す
→ トレースモード ON
[2] ← / → で X 座標を移動
→ 画面右上に「x=..., y=..., F1」が表示
```
**例**:
```
x=1.234  y=0.944  F1
```
（F1 = 1 番目の関数）
### 複数関数の切り替え
トレース中に `+` を押すと、次の関数に切り替わります。
```
1 本目 → 2 本目 → 3 本目 → 4 本目 → 1 本目
```

## 10.8 G-Solve（自動解析）
`8 (G-Solve)` で、グラフの重要な点を自動計算します。
### メニュー
```
┌─────────────────────────────────┐
│▌G-Solve                         │
├─────────────────────────────────┤
│1 Root (sign change scan)        │
│2 Maximum (gradient ascent)      │
│3 Minimum (gradient descent)     │
│4 Intersection f1 = f2           │
│5 y at x                         │
│6 x at y (root of f-y)           │
│7 Definite integral              │
│8 Back                           │
└─────────────────────────────────┘
```
### 1. Root（根）
**f(x) = 0 となる x を探します。**
**例**: sin(x) = 0 の根を x ∈ [-2π, 2π] で探す
```
[1] G-Solve → 1 (Root)
→ x = -6.2832
  x = -3.1416
  x = 0
  x = 3.1416
  x = 6.2832
```
（-2π, -π, 0, π, 2π）
### 2. Maximum（極大値）
**局所的な最大値を探します。**
**例**: y = sin(x) の極大値
```
[1] G-Solve → 2 (Maximum)
→ x=1.5708 y=1.0000
  x=-4.7124 y=1.0000
```
（π/2, -3π/2 で最大値 1）
### 3. Minimum（極小値）
**局所的な最小値を探します。**
### 4. Intersection（交点）
**2 つの関数の交点を探します。**
**例**: y = sin(x) と y = 0.5 の交点
```
[1] 2 本の関数を登録:
    F1 = sin(x)
    F2 = 0.5
[2] G-Solve → 4 (Intersection)
→ x=0.5236 y=0.5000
  x=2.6180 y=0.5000
```
（π/6 ≈ 0.5236, 5π/6 ≈ 2.618）
### 5. y at x
**x を指定して y を計算。**
```
[1] G-Solve → 5 (y at x)
[2] x: 1.5708
→ y = 1.0000
```
（sin(π/2) = 1）
### 6. x at y
**y を指定して x を探す（f(x) = y の解）。**
### 7. Definite integral（定積分）
**指定区間の定積分を数値計算。**
**例**: ∫₀^π sin(x) dx
```
[1] G-Solve → 7 (Integral)
[2] from a: 0
[3] to b: 3.1416
→ Integral = 2.0000
```
**確認**: ∫₀^π sin(x) dx = [-cos(x)]₀^π = 1 - (-1) = 2

## 10.9 接線・法線
`9 (Tangent / Normal at x)` で、指定点の接線と法線の方程式を計算します。
### 例: y = x² の x=2 での接線
**数学的解**:
- f(2) = 4（接点 (2, 4)）
- f'(x) = 2x → f'(2) = 4（傾き）
- 接線: y = 4(x - 2) + 4 = 4x - 4
- 法線: y = -1/4 · (x - 2) + 4
**PoMaS での操作**:
```
[1] 関数 x^2 を登録
[2] Graph → 9 (Tangent/Normal)
[3] at x: 2
→ At (x, y) = (2, 4)
  slope = 4
  Tan: y = 4(X - 2) + 4
  Norm: y = -0.25(X - 2) + 4
```

## 10.12 トラブルシューティング
| 症状 | 原因 | 対処 |
|---|---|---|
| 円が楕円になる | アスペクト比の違い | Square aspect (1:1) |
| 何も表示されない | 関数が空 / Range 外 | 関数登録と Range を確認 |
| 極座標で閉じない | tmax < 2π | tmax: 6.2832 |
| 陰関数がギザギザ | RES=40 の粗さ | 仕様（次期改善予定） |
| 3D が真っ黒 | zmin/zmax 外 | Range で z 範囲を調整 |
| 交点が見つからない | 2 関数未登録 | F1, F2 を両方登録 |

## 10.13 G-Solve 詳細リファレンス

### 10.13.1 Root（根の検出）

**用途**: f(x) = 0 となる x を区間内で全て検出。

**アルゴリズム**: 区間を 200 分割し、各小区間で符号変化を検出 → 二分法で精密化

**検出限界**:
- 重解（タッチして戻る）は検出できない
- 最大 8 個まで同時表示

**例 1: sin(x) = 0 を [-2π, 2π] で**

```
[1] 関数: sin(x)
[2] Range: -6.28, 6.28, -2, 2
[3] G-Solve → 1 (Root)
→ x = -6.2832  (-2π)
  x = -3.1416  (-π)
  x = 0
  x = 3.1416   (π)
  x = 6.2832   (2π)
```

**例 2: x³ - 2x + 1 = 0**

```
[1] 関数: x^3-2x+1
[2] Range: -3, 3, -3, 3
[3] Root
→ x = -1.618   (-φ、黄金比の負)
  x = 0.618    (1/φ)
  x = 1.000
```

**例 3: x² + 1 = 0（実根なし）**

```
→ "No sign change" 表示
（複素根 ±i は Root で検出不可、CAS の cSolve を使う）
```

**精度**: 二分法 60 反復で約 1e-18

### 10.13.2 Maximum（極大値）

**用途**: 区間内の極大値（局所最大）をすべて検出。

**アルゴリズム**: 微分の符号変化を検出 → 二分法で精密化 → 2 階微分で極大判定

**例 1: y = -x² + 4x の最大値**

```
[1] 関数: -x^2+4x
[2] Range: -5, 10, -5, 10
[3] G-Solve → 2 (Maximum)
→ x = 2.0000  y = 4.0000
```

**例 2: y = sin(x) の極大値を [−2π, 2π] で**

```
→ x = 1.5708  y = 1.0000   (π/2)
  x = -4.7124 y = 1.0000   (-3π/2)
```

**例 3: y = x³ - 3x の極大値を [−5, 5] で**

```
→ x = -1.0000 y = 2.0000
（x=1 は極小値、Maximum 検出対象外）
```

**用途**: 最適化問題、最大利益、ピーク値

### 10.13.3 Minimum（極小値）

**用途**: 区間内の極小値（局所最小）をすべて検出。

**例: y = x² - 4x + 3**

```
[1] 関数: x^2-4x+3
[2] Range: -2, 8, -3, 10
[3] G-Solve → 3 (Minimum)
→ x = 2.0000  y = -1.0000
```

**用途**: コスト最小化、誤差最小化

### 10.13.4 Intersection（2 関数の交点）

**用途**: f₁(x) = f₂(x) を解いて交点を求める。

**前提**: 2 本の関数を登録（F1, F2）。

**例 1: y = sin(x) と y = 0.5**

```
[1] F1 = sin(x), F2 = 0.5
[2] Range: -7, 7, -2, 2
[3] G-Solve → 4 (Intersection)
→ x = 0.5236  y = 0.5000   (π/6)
  x = 2.6180  y = 0.5000   (5π/6)
```

**例 2: y = x² と y = 2x**

```
[1] F1 = x^2, F2 = 2x
[2] Range: -1, 3, -1, 5
[3] Intersection
→ x = 0  y = 0
  x = 2  y = 4
```

**例 3: y = exp(x) と y = x + 1**

```
→ x = 0  y = 1  （接する）
```

**用途**: 均衡点、損益分岐点、需要供給曲線

### 10.13.5 y at x（指定 x での y 値）

**用途**: カーソル移動せず、任意の x のときの y を計算。

**例: y = sin(x) で x = π/2 のとき**

```
[1] G-Solve → 5 (y at x)
[2] x: 1.5708
→ y = 1.0000
```

### 10.13.6 x at y（指定 y での x 値）

**用途**: 逆に、y を指定して x を求める（f(x) = y の解）。

**例: y = x² で y = 9 のとき**

```
[1] G-Solve → 6 (x at y)
[2] y: 9
→ x = 3.0000  （正の根のみ、範囲依存）
```

### 10.13.7 Definite Integral（定積分）

**用途**: 区間 [a, b] での f(x) の定積分を数値計算。

**アルゴリズム**: 適応型 Simpson 法（最大深度 22、誤差 < 1e-11）

**例 1: ∫₀^π sin(x) dx**

```
[1] 関数: sin(x)
[2] G-Solve → 7 (Integral)
[3] from a: 0
[4] to b: 3.14159
→ Integral = 2.0000
（検算: [-cos(x)]₀^π = 1-(-1) = 2）
```

**例 2: ∫₀¹ x² dx**

```
[1] 関数: x^2
[2] a: 0, b: 1
→ Integral = 0.33333  (1/3)
```

**例 3: ∫₀¹ e^(-x²) dx**

```
[1] 関数: exp(-x^2)
[2] a: 0, b: 1
→ Integral = 0.74682
（ガウス積分の部分値、erf(1)×√π/2）
```

**注意**: 特異点（f→∞）を含む区間は不安定

## 10.14 陰関数グラフ 詳細

### 10.14.1 陰関数とは

**定義**: F(x, y) = 0 の形で表される曲線。

**陽関数との違い**:
- 陽関数: y = f(x)（x から y が直接求まる）
- 陰関数: F(x, y) = 0（x, y の関係式）

**例**: 円 x² + y² = r² は陰関数（陽関数では y = ±√(r²-x²) の 2 本になる）

### 10.14.2 描画アルゴリズム（Marching Squares）

**手順**:
1. 画面を格子状のセルに分割（implCell ピクセル）
2. 各セル四隅で F(x, y) の符号を計算
3. 符号変化するセルを特定
4. セル内で F = 0 の線分を補間で結ぶ

**実装**: PoMaS は `implCell`（2〜8 px）で解像度を制御

### 10.14.3 円の描画

```
[1] Plot type: Implicit
[2] F1: x^2+y^2-4       （半径 2 の円）
[3] Range: -3, 3, -2, 2
[4] Square aspect (1:1)
[5] Plot
→ 真円が表示される
```

**⚠️ 楕円に見える場合**: Square aspect を実行して縦横比を揃える

### 10.14.4 楕円

```
[1] F1: x^2/4 + y^2 - 1   （長径 4、短径 2）
[2] Range: -3, 3, -2, 2
[3] Square aspect
[4] Plot
```

### 10.14.5 双曲線

```
[1] F1: x^2 - y^2 - 1
[2] Range: -3, 3, -3, 3
[3] Square aspect
[4] Plot
→ 2 本の枝が表示される
```

### 10.14.6 レムニスケート（連珠形）

```
[1] F1: (x^2+y^2)^2 - 2*(x^2-y^2)
[2] Range: -2, 2, -1, 1
[3] Square aspect
[4] Plot
→ ∞ 字型の曲線
```

### 10.14.7 カージオイド（心臓形、陰関数版）

```
[1] F1: (x^2+y^2+x)^2 - (x^2+y^2)
[2] Range: -2, 1, -1, 1
[3] Square aspect
[4] Plot
```

### 10.14.8 ハート曲線

```
[1] F1: (x^2+y^2-1)^3 - x^2*y^3
[2] Range: -2, 2, -2, 2
[3] Square aspect
[4] Plot
→ ハート形
```

### 10.14.9 陰関数の精度調整

**implCell 値**:
| 値 | 解像度 | 用途 |
|---|---|---|
| 2 | 最高（120×52 セル） | 精密曲線、遅い |
| 4 | 中（60×26 セル） | 標準 |
| 6 | 低（40×17 セル） | 高速 |
| 8 | 最低（30×13 セル） | プレビュー |

**調整方法**: Graph → 4 (Range) → implCell 入力

## 10.15 3D グラフ 詳細

```
→ 中央が盛り上がった波形
```

### 10.15.4 ガウス分布曲面

```
[1] F1: exp(-(x^2+y^2))
[2] Range: -3, 3, -3, 3, zmin=0, zmax=1
[3] Plot

```

### 10.15.5 放物面

```
[1] F1: x^2+y^2
[2] Range: -2, 2, -2, 2, zmin=0, zmax=8
[3] Plot

```

### 10.15.6 鞍点（サドル）

```
[1] F1: x^2-y^2
[2] Range: -2, 2, -2, 2, zmin=-4, zmax=4
[3] Plot
→ 馬の鞍型
```

### 10.15.7 3D 回転操作

**キー操作**:
| キー | 動作 |
|---|---|
| `Fn + ←` | 方位角（φ）を -0.15 rad |
| `Fn + →` | 方位角（φ）を +0.15 rad |
| `Fn + ↑` | 仰角（θ）を +0.1 rad |
| `Fn + ↓` | 仰角（θ）を -0.1 rad |

**初期値**: φ = π/6（30°）、θ = π/8（22.5°）

### 10.15.8 grid3N の調整

**grid3N**: メッシュの分割数（6〜40）

| 値 | メッシュ密度 | 速度 |
|---|---|---|
| 6 | 粗い（見やすい） | 高速 |
| 16 | 標準 | 中速 |
| 30 | 細かい | 低速 |
| 40 | 非常に細かい | 最遅 |

**調整**: Graph → 4 (Range) → grid N 入力

### 10.15.9 3D の制限事項

- 塗りつぶしなし（ワイヤーフレームのみ）
- 隠面消去なし（奥の線も見える）
- 複数曲面同時表示不可（1 関数のみ）
- 軸ラベルなし（zmin/zmax で範囲指定のみ）

## 10.16 パラメトリック曲線 詳細

### 10.16.1 パラメトリックとは

**定義**: x = f(t), y = g(t) で媒介変数 t を使って曲線を表現。

**入力形式**: `x(t);y(t)` — セミコロンで区切る

### 10.16.2 円

```
[1] Plot type: Parametric
[2] F1: cos(t);sin(t)
[3] Range: tmin=0, tmax=6.2832 (=2π)
[4] Square aspect
[5] Plot
→ 半径 1 の円
```

**t の範囲**: 0 〜 2π で一周（tmax = 6.2832）

### 10.16.3 楕円

```
[1] F1: 2*cos(t);sin(t)
[2] Range: 0, 6.2832
[3] Square aspect
→ 長径 4、短径 2
```

### 10.16.4 リサージュ図形

```
[1] F1: sin(3t);sin(2t)
[2] Range: 0, 6.2832
[3] Plot
→ 複雑な曲線パターン
```

**パターン変化**: `sin(nt);sin(mt)` の n:m 比で形が変わる

### 10.16.5 螺旋

```
[1] F1: t*cos(t);t*sin(t)
[2] Range: 0, 20 (=10π)
[3] Plot
→ 外側に広がる螺旋
```

### 10.16.6 サイクロイド

```
[1] F1: t-sin(t);1-cos(t)
[2] Range: 0, 20
[3] Plot
→ 坂を転がる円の軌跡
```

### 10.16.7 アステロイド

```
[1] F1: cos(t)^3;sin(t)^3
[2] Range: 0, 6.2832
[3] Square aspect
→ 4 つの尖った星形
```

### 10.16.8 tstep の調整

**tstep**: t の増分（デフォルト 0.05）

| tstep | 曲線の滑らかさ | 速度 |
|---|---|---|
| 0.01 | 非常に滑らか | 遅い |
| 0.05 | 標準 | 中速 |
| 0.1 | やや粗い | 速い |

**調整**: Graph → 4 (Range) → tstep 入力

## 10.18 不等式領域 詳細

### 10.18.1 不等式グラフとは

**用途**: f(x, y) > 0 の領域を塗りつぶし表示。

**機能**: 領域の可視化、複数条件の共通部分

### 10.18.2 単一不等式

**例: y > x（f = y - x > 0）**

```
[1] Plot type: Inequality
[2] F1: y-x
[3] Range: -5, 5, -5, 5
[4] Plot
→ 直線 y = x の上の領域が塗られる
```

### 10.18.3 円の内側

**例: x² + y² < 4（半径 2 の円の内部）**

```
[1] F1: 4-x^2-y^2
[2] Range: -3, 3, -2, 2
[3] Square aspect
[4] Plot
→ 円の内側が塗られる
```

### 10.18.4 放物線の上側

**例: y > x²（放物線の上）**

```
[1] F1: y-x^2
[2] Range: -3, 3, -1, 5
[3] Plot
```

### 10.18.5 複数不等式の交差

**用途**: 複数の条件を同時に満たす領域。

**操作**:
```
[1] F1: y-x       （y > x）
[2] F2: 1-x-y     （x+y < 1）
[3] F3: x         （x > 0）
[4] Plot type → Inequality intersect
[5] Plot
→ 3 条件を満たす三角形領域のみ塗られる
```

**用途**: 線形計画法の実行可能領域、集合の可視化

### 10.18.6 不等式の応用例

- 三角不等式の可視化
- 制約条件の領域確認
- 確率分布の支持領域

## 10.19 図形重ね描き 詳細

### 10.19.1 図形重ねとは

**用途**: 関数グラフの上に円・線・矩形を重ねて表示。

```
[1] Graph → 13 (Shape overlay)
```

## 10.22 この章のまとめ
- Graph モードは 7 種類のプロットタイプ
- y=f(x), Parametric, Polar, Implicit, Inequality, Sequence, 3D
- Range / Window で表示範囲を設定
- Square aspect (1:1) で真円表示
- Z / X / R / B でズーム操作
- T でトレース、+ で複数関数切り替え
- G-Solve で根・極値・交点・定積分
- Tangent / Normal で接線・法線
- S キーで BMP 保存
