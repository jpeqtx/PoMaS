## 3.1 起動から終了まで
### 起動の流れ
PoMaS の起動は、次の 3 段階で進みます。
```
[1] 電源 ON
&#x20;      ↓
[2] スプラッシュ表示（2.5 秒）
&#x20;      ↓
[3] メインメニュー表示
```
### 各段階の詳細
**段階 1: 電源 ON**
電源ボタンを 2 秒以上長押しします。USB 給電でも起動します。
**段階 2: スプラッシュ**
PoMaS のロゴとバージョンが表示されます。
この間、内部では以下の処理が走っています。
- SD カードの初期化
- 設定（NVS）の読み込み
- 統計リスト用メモリの確保
- μLisp 環境の初期化
**段階 3: メインメニュー**
7 つのモードが一覧表示されます。
```
┌─────────────────────────────────┐
│▌PoMaS 0.92          DEG|NRM     │  ← ヘッダ
├─────────────────────────────────┤
│1 Calculator                     │
│2 CAS                            │
│3 Statistics                     │
│4 Scientific Reference           │
│5 Graph                          │
│6 Tools (Sheet/uLisp/WiFi)       │
│7 About                          │
├─────────────────────────────────┤
│ENT:OK                ESC:back   │  ← フッタ
└─────────────────────────────────┘
```
### 終了の流れ
1. 任意のモードから **Fn + Esc** でメインメニューに戻る
2. **電源ボタンを 2 秒以上長押し**
3. 画面が暗くなり、電源 OFF
**注意**
モード内で電源を切ると、入力中のデータは失われます。
必ずメインメニューに戻ってから終了してください。

## 3.2 画面の構成要素
### 3 つの領域
PoMaS の画面は、次の 3 つの領域からなります。
```
┌─────────────────────────────────┐
│ ヘッダ                          │  ← タイトル・状態
├─────────────────────────────────┤
│                                 │
│ ボディ                          │  ← メインコンテンツ
│                                 │
├─────────────────────────────────┤
│ フッタ                          │  ← 操作ヒント
└─────────────────────────────────┘
```
### ヘッダの見方
左端に **3px のアクセントバー**、タイトルの右に **バッジ** があります。
```
▌Calculator               DEG|FIX|RPN
↑                          ↑
アクセントバー              バッジ
```
**バッジの読み方**
| 表示 | 意味 |
|---|---|
| `DEG` | 角度は度数法（0〜360°） |
| `RAD` | 角度は弧度法（0〜2π） |
| `GRA` | 角度はグラジアン（0〜400） |
| `NRM` | 数値は通常表示 |
| `FIX` | 数値は固定小数点表示 |
| `SCI` | 数値は科学表記（1.23e+4） |
| `ENG` | 数値は工学表記（12.3k） |
| `RPN` | RPN モード（逆ポーランド記法） |
| `HEX` | 16 進数モード |
| `OCT` | 8 進数モード |
| `BIN` | 2 進数モード |
### フッタの見方
左右と中央に、その場で使えるキーのヒントが表示されます。
```
ENT:OK                Fn+1:Set    ESC:back
↑                     ↑            ↑
左ヒント              中央ヒント   右ヒント
```

## 3.3 メニューの操作
### メニューの基本
PoMaS のメニューは、縦に項目が並んでいます。
```
┌─────────────────────────────────┐
│▌Graph                           │
├─────────────────────────────────┤
│1 Plot current functions         │  ← 選択中（ミント背景）
│2 Edit functions                 │
│3 Plot type                      │
│4 Range / Window                 │
│5 Standard window                │
│6 Trig window                    │
│7 Square aspect (1:1)            │
│8 G-Solve                        │
│9 Tangent / Normal at x          │
│10 Save plot as BMP              │
│11 Back                          │
├─────────────────────────────────┤
│ENT:OK                ESC:back   │
└─────────────────────────────────┘
```
### 選択の移動
| キー | 動作 |
|---|---|
| `;` | 上に移動 |
| `.` | 下に移動 |
| `Fn + ;` | 上に移動（代替） |
| `Fn + .` | 下に移動（代替） |
**数字キーで直接ジャンプ**
メニュー項目には番号が振られています。
`1`〜`9` を押すと、その番号の項目に直接ジャンプできます。
### 決定と取消
| キー | 動作 |
|---|---|
| `Enter` | 選択中の項目を決定 |
| `Fn + Esc` | 前の画面に戻る |
| `Esc`（バッククォート） | 前の画面に戻る |
### スクロールバー
項目が画面に収まらない場合、右端にスクロールバーが表示されます。
```
│1 Plot current...        ▌  ← スクロール位置
│2 Edit functions         ▌
│3 Plot type              ▌
│4 Range / Window         █  ← つまみ（現在位置）
│5 Standard window        █
│6 Trig window            ▌
```

## 3.4 入力の基本
### 数式の入力
Calculator モードでの入力例を紹介します。
**例: `2 + 3` を計算する**
1. メインメニューから `1` を押して Calculator を選択
2. `2` キーを押す
3. `+` キーを押す
4. `3` キーを押す
5. `Enter` キーを押す
**画面の流れ**:
```
[1] 入力前
&#x20;   ┌─────────────────────────────┐
&#x20;   │Ans = 0                      │
&#x20;   │─────────────────────────────│
&#x20;   │_                            │
&#x20;   └─────────────────────────────┘
[2] "2" 入力後
&#x20;   ┌─────────────────────────────┐
&#x20;   │Ans = 0                      │
&#x20;   │─────────────────────────────│
&#x20;   │2_                           │
&#x20;   └─────────────────────────────┘
[3] "2+" 入力後
&#x20;   ┌─────────────────────────────┐
&#x20;   │Ans = 0                      │
&#x20;   │─────────────────────────────│
&#x20;   │2+_                          │
&#x20;   └─────────────────────────────┘
[4] "2+3" 入力後
&#x20;   ┌─────────────────────────────┐
&#x20;   │Ans = 0                      │
&#x20;   │─────────────────────────────│
&#x20;   │2+3_                         │
&#x20;   └─────────────────────────────┘
[5] Enter 押下
&#x20;   ┌─────────────────────────────┐
&#x20;   │2+3 = 5                      │
&#x20;   │Ans = 5                      │
&#x20;   │─────────────────────────────│
&#x20;   │_                            │
&#x20;   └─────────────────────────────┘
```
### 入力の修正
| キー | 動作 |
|---|---|
| `Del` | 最後の 1 文字を削除 |
| `Fn + Esc` | 入力をキャンセル（画面を抜ける） |
**長い式の入力**
式が画面幅を超えると、自動的にスクロールします。
カーソルは常に右端に追従します。
### 入力ダイアログ
数値や文字列の入力を求められる場面があります。
```
┌─────────────────────────────────┐
│▌Settings                        │
├─────────────────────────────────┤
│  ┌───┐                          │
│  │digits 0-9:│                  │  ← プロンプト（ミント）
│  └───┘                          │
│  ┌──────────────────────────┐   │
│  │4_                        │   │  ← 入力欄
│  └──────────────────────────┘   │
└─────────────────────────────────┘
```
- `Enter` で確定
- `Fn + Esc` でキャンセル
- `Del` で 1 文字削除

## 3.5 通知と確認
### 通知（Notify）
操作の結果を短時間表示します。
```
┌─────────────────────────────────┐
│                                 │
│        ┌──────────────┐         │
│        │▌Saved        │         │  ← 通知（中央）
│        └──────────────┘         │
│                                 │
└─────────────────────────────────┘
```
通知は約 0.8 秒で自動的に消えます。操作は不要です。
### 確認（Confirm）
重要な操作の前に、Yes/No を求められます。
```
┌─────────────────────────────────┐
│                                 │
│    ┌─────────────────────┐      │
│    │ Reset all?          │      │
│    │  ┌────┐  ┌────┐     │      │
│    │  │[Y] │  │[N] │     │      │
│    │  │Yes │  │No  │     │      │
│    │  └────┘  └────┘     │      │
│    └─────────────────────┘      │
│                                 │
└─────────────────────────────────┘
```
| キー | 動作 |
|---|---|
| `Y` | Yes（実行） |
| `N` | No（キャンセル） |
| `Esc` | No と同じ（キャンセル） |

## 3.6 各モードへの入り方と戻り方
### Calculator モード
```
メインメニュー → 1 または Enter → Calculator
Calculator → Fn + Esc → メインメニュー
```
### CAS モード
```
メインメニュー → 2 → CAS
CAS → Fn + Esc → メインメニュー
```
### Statistics モード
```
メインメニュー → 3 → Statistics サブメニュー
Statistics サブメニュー → 各機能
各機能 → Fn + Esc → Statistics サブメニュー
Statistics サブメニュー → Fn + Esc → メインメニュー
```
**階層の深さ**
PoMaS のメニューは最大 4 階層まで潜ります。
`Fn + Esc` を押すたびに 1 階層ずつ戻ります。
### ESC の連続押しについて
**v0.92 の改良点**: ESC を押した直後に連続で ESC が反応しないよう、
**ESC クールダウン** 機能が入っています。
```
[1] Fn + Esc 押下 → 1 階層戻る
[2] キーを離す
[3] もう一度 Fn + Esc 押下 → さらに 1 階層戻る
```
素早く 2 回押すと、2 階層戻るのではなく、1 階層だけ戻ります。
**誤ってメインメニューまで戻ってしまう事故を防ぐ**ための仕様です。

## 3.7 設定の基本
### 設定画面への入り方
**方法 1**: メインメニュー → 6 Tools → 4 Settings
**方法 2**: Calculator → Fn + 1
### 変更できる設定
| 項目 | 選択肢 |
|---|---|
| 角度モード | DEG / RAD / GRA |
| 表示形式 | Norm / Fix / Sci / Eng |
| 表示桁数 | 0 〜 9 |
| Norm の閾値 | Norm 1 / Norm 2 |
### 設定の保存
設定は自動的に NVS（不揮発性ストレージ）に保存されます。
再起動しても維持されます。
**手動保存**
`Settings → Save settings now` で明示的に保存できます。
通常は 60 秒ごとに自動保存されています。

## 3.9 ESC 階層動作の詳細

### 3.9.1 ESC の基本動作

- **物理キー**: バッククォート（`` ` ``）
- **代替**: `Fn + ` ``（確実に動作）
- **用途**: 前の画面に戻る / 入力をキャンセル

### 3.9.2 階層の深さ

PoMaS のメニュー階層は最大 4 層です:

```
[1] メインメニュー
    [2] モードメニュー（Calculator/CAS/Statistics など）
        [3] サブメニュー（Settings/Tools など）
            [4] 詳細画面（入力ダイアログ・結果表示）
```

### 3.9.3 ESC の連続押し制御

ESC を素早く 2 回押すと、1 階層だけ戻ります:

```
[1] ESC 押下 → 1 階層戻る
[2] 100ms 以内に ESC 再押下 → 無視（クールダウン）
[3] 100ms 経過後の ESC → さらに 1 階層戻る
```

**理由**: 誤ってメインメニューまで戻る事故を防ぐため

### 3.9.4 ESC が効かない画面

| 画面 | 動作 |
|---|---|
| 確認ダイアログ（Y/N） | ESC は N と同じ |
| 通知（Notify） | ESC は通知を消す |
| スプラッシュ | ESC 無効 |
| 電源 OFF 待機 | ESC 無効 |

### 3.9.5 モード固有の ESC 動作

- **Calculator**: 入力中なら入力をクリア、そうでなければメニューへ
- **Statistics**: リスト編集中なら編集キャンセル、そうでなければメニューへ
- **uLisp REPL**: REPL を抜ける
- **グラフプロット中**: グラフメニューへ

## 3.10 Notify（通知）詳細

### 3.10.1 表示形式

```
┌─────────────────────────────────┐
│                                 │
│        ┌──────────────┐         │
│        │▌Saved        │         │
│        └──────────────┘         │
│                                 │
└─────────────────────────────────┘
```

- 画面中央に表示
- 左端にアクセントストライプ
- 影付きパネル

### 3.10.2 表示時間

| 種類 | 既定時間 |
|---|---|
| 通常 | 800 ms |
| 成功 | 800 ms |
| エラー | 1000-1500 ms |
| 長文エラー | 1500-2000 ms |

### 3.10.3 消去方法

- 時間経過（800-2000 ms）
- `ESC` 押下（即座に消去）
- 任意キー押下（v0.92 以降は ESC のみ）

### 3.10.4 通知の種類

| 色 | 種類 |
|---|---|
| C_ACC（ミント） | 情報 |
| C_OK（緑） | 成功 |
| C_ERR（赤） | エラー |
| C_WARN（琥珀） | 警告 |
| C_DIM（グレー） | 補足 |

### 3.10.5 通知使用例

```
[1] 設定保存: "Saved to NVS"（成功、800ms）
[2] 計算結果: "-> Ans"（情報、800ms）
[3] エラー: "division by zero"（エラー、1000ms）
[4] 警告: "Bank full"（警告、1200ms）
```

## 3.11 確認ダイアログ詳細

### 3.11.1 表示形式

```
┌─────────────────────────────────┐
│                                 │
│    ┌─────────────────────┐      │
│    │ Reset all?          │      │
│    │  ┌────┐  ┌────┐     │      │
│    │  │[Y] │  │[N] │     │      │
│    │  │Yes │  │No  │     │      │
│    │  └────┘  └────┘     │      │
│    └─────────────────────┘      │
│                                 │
└─────────────────────────────────┘
```

### 3.11.2 キー操作

| キー | 動作 |
|---|---|
| `Y` / `y` | Yes（実行） |
| `N` / `n` | No（キャンセル） |
| `ESC` / `` ` `` | No と同じ（キャンセル） |
| `Enter` | **無効** |

**重要**: Enter は Yes/No を選択しません。必ず Y または N を押してください。

### 3.11.3 確認が必要な操作

| 操作 | メッセージ |
|---|---|
| 全設定リセット | "Reset all?" |
| NVS クリア | "Clear NVS settings?" |
| Ans バンククリア | "Clear all bank?" |
| 統計リストクリア | "Clear all 6 lists?" |
| ユーザー関数クリア | "Clear all user fns?" |
| データ削除 | "Delete?" |

### 3.11.4 確認不要な操作

- 通常の計算実行
- メニュー選択
- 結果表示
- 通知表示

## 3.12 入力ダイアログ詳細

### 3.12.1 表示形式

```
┌─────────────────────────────────┐
│▌Settings                        │
├─────────────────────────────────┤
│  ┌───────────┐                  │
│  │digits 0-9:│                  │  ← プロンプト
│  └───────────┘                  │
│  ┌──────────────────────────┐   │
│  │4_                        │   │  ← 入力欄
│  └──────────────────────────┘   │
└─────────────────────────────────┘
```

### 3.12.2 キー操作

| キー | 動作 |
|---|---|
| 文字キー | 文字入力 |
| `Enter` | 確定 |
| `Del` | 1 文字削除 |
| `ESC` | キャンセル |
| `Fn + ←` | カーソル左 |
| `Fn + →` | カーソル右 |
| `Fn + ↑` | カーソル先頭 |
| `Fn + ↓` | カーソル末尾 |
| `Fn + Del` | 全消去 |

### 3.12.3 カーソル編集

入力欄のカーソル位置で編集できます:
- 矢印キーで移動
- 挿入・削除
- 長い式は自動スクロール

### 3.12.4 数値入力の検証

PoMaS は入力値の範囲を検証します:

| プロンプト | 有効範囲 |
|---|---|
| "digits 0-9:" | 0〜9 |
| "auto off min (0=off):" | 0〜600 |
| "Size n (2-5):" | 2〜5 |
| "bins:" | 2〜50 |

範囲外の値を入力しても、確定時にエラー通知。

### 3.12.5 複数行入力

長い入力（80 文字超）は自動的にスクロールし、カーソルが見える位置を表示。

## 3.13 メニュー操作の詳細

### 3.13.1 選択の移動

| キー | 動作 |
|---|---|
| `;` / `Fn + ;` | 上に移動 |
| `.` / `Fn + .` | 下に移動 |
| `Fn + ,` | 前ページ |
| `Fn + /` | 次ページ |

### 3.13.2 端での循環

- 最上段で `↑` → 最下段へ
- 最下段で `↓` → 最上段へ

### 3.13.3 数字キー直接ジャンプ

- `1` 〜 `9`: その番号の項目へ
- `a` 〜 `z`: 10 番目以降（10=a、11=b、...）

### 3.13.4 スクロールバー

右端の縦バーで現在位置を表示:

```
│1 Item1        ▌
│2 Item2        ▌
│3 Item3        █  ← つまみ
│4 Item4        █
│5 Item5        ▌
```

### 3.13.5 選択位置の記憶

各メニューは前回の選択位置を記憶します。再度開いた時、前回選択した項目がハイライトされます。

## 3.14 エラー画面の見方

### 3.14.1 Calculator エラー

```
┌─────────────────────────────────┐
│2+3 = 5                          │
│sin(30) = 0.5                    │
│1/0 = ERR                        │  ← エラー表示
│                                 │
│Ans = 0.5                        │
│─────────────────────────────────│
│_                                │
└─────────────────────────────────┘
```

エラー時は履歴に `ERR` と表示され、Ans は更新されません。

### 3.14.2 Notify エラー

```
┌─────────────────────────────────┐
│                                 │
│    ┌────────────────────┐       │
│    │▌division by zero   │       │
│    └────────────────────┘       │
│                                 │
└─────────────────────────────────┘
```

エラーメッセージは 1000-1500ms で自動消去。

### 3.14.3 uLisp エラー

REPL 内で `ERR: xxx` 形式で表示、履歴に残ります:

```
> (foo 5)
ERR: unbound symbol

> (+ 1 2)
-> 3

> (car nil)
-> nil
```

### 3.14.4 SD エラー

ファイル操作時に Notify で表示:

```
"File not found"
"Open failed"
"No SD card"
```

## 3.15 モード切替のコツ

### 3.15.1 素早い切替

- メインメニューに戻らずに、ESC 連打で切替
- 例: Calculator → ESC → メインメニュー → 3 (Statistics)

### 3.15.2 前回モードの記憶

メインメニューは前回選択したモードを記憶。再度開いた時にハイライト。

### 3.15.3 モード間のデータ共有

| データ | 共有先 |
|---|---|
| Ans | 全モード |
| 変数 A〜J | 全モード |
| メモリ M | 全モード |
| Ans バンク | 全モード |
| 統計リスト L1〜L8 | Statistics + Tools (Spreadsheet) |
| 履歴 | Calculator のみ |

## 3.16 この章のまとめ

- ESC 階層: 最大 4 層、100ms クールダウンで連続押し防止
- Notify: 800-2000ms で自動消去、ESC で即消去
- Confirm: Y/N/ESC で応答、Enter 無効
- InputLine: カーソル編集、範囲検証、自動スクロール
- メニュー: 上下移動・直接ジャンプ・スクロールバー・選択位置記憶
- エラー: 履歴に ERR、Notify 表示、uLisp REPL で ERR
- モード切替: ESC 連打、前回モード記憶

### 確認問題

Q3-5: ESC のクールダウン時間は？ → 100ms

Q3-6: Notify の既定表示時間は？ → 800ms（エラーは 1000-1500ms）

Q3-7: Confirm ダイアログで Yes を選ぶキーは？ → Y キー

Q3-8: 入力ダイアログで全消去するキーは？ → Fn + Del

Q3-9: メニューの選択位置は記憶される？ → される（前回の項目がハイライト）

Q3-10: メニューで 10 番目の項目を直接選ぶには？ → a キー
