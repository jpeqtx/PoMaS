## 3.1 起動から終了まで



### 起動の流れ



PoMaS の起動は、次の 3 段階で進みます。



```

[1] 電源 ON

&#x20;      ↓

[2] スプラッシュ表示（2.5 秒）

&#x20;      ↓

[3] メインメニュー表示

```



### 各段階の詳細



**段階 1: 電源 ON**

電源ボタンを 2 秒以上長押しします。USB 給電でも起動します。



**段階 2: スプラッシュ**

PoMaS のロゴとバージョンが表示されます。

この間、内部では以下の処理が走っています。

- SD カードの初期化

- 設定（NVS）の読み込み

- 統計リスト用メモリの確保

- μLisp 環境の初期化



**段階 3: メインメニュー**

7 つのモードが一覧表示されます。



```

┌─────────────────────────────────┐

│▌PoMaS 0.92          DEG|NRM     │  ← ヘッダ

├─────────────────────────────────┤

│1 Calculator                     │

│2 CAS                            │

│3 Statistics                     │

│4 Scientific Reference           │

│5 Graph                          │

│6 Tools (Sheet/uLisp/WiFi)       │

│7 About                          │

├─────────────────────────────────┤

│ENT:OK                ESC:back   │  ← フッタ

└─────────────────────────────────┘

```



### 終了の流れ



1. 任意のモードから **Fn + Esc** でメインメニューに戻る

2. **電源ボタンを 2 秒以上長押し**

3. 画面が暗くなり、電源 OFF



⚠️ **注意**

モード内で電源を切ると、入力中のデータは失われます。

必ずメインメニューに戻ってから終了してください。

## 3.2 画面の構成要素



### 3 つの領域



PoMaS の画面は、次の 3 つの領域からなります。



```

┌─────────────────────────────────┐

│ ヘッダ                          │  ← タイトル・状態

├─────────────────────────────────┤

│                                 │

│ ボディ                          │  ← メインコンテンツ

│                                 │

├─────────────────────────────────┤

│ フッタ                          │  ← 操作ヒント

└─────────────────────────────────┘

```



### ヘッダの見方



左端に **3px のアクセントバー**、タイトルの右に **バッジ** があります。



```

▌Calculator               DEG|FIX|RPN

↑                          ↑

アクセントバー              バッジ

```



**バッジの読み方**



| 表示 | 意味 |

|---|---|

| `DEG` | 角度は度数法（0〜360°） |

| `RAD` | 角度は弧度法（0〜2π） |

| `GRA` | 角度はグラジアン（0〜400） |

| `NRM` | 数値は通常表示 |

| `FIX` | 数値は固定小数点表示 |

| `SCI` | 数値は科学表記（1.23e+4） |

| `ENG` | 数値は工学表記（12.3k） |

| `RPN` | RPN モード（逆ポーランド記法） |

| `HEX` | 16 進数モード |

| `OCT` | 8 進数モード |

| `BIN` | 2 進数モード |



### フッタの見方



左右と中央に、その場で使えるキーのヒントが表示されます。



```

ENT:OK                Fn+1:Set    ESC:back

↑                     ↑            ↑

左ヒント              中央ヒント   右ヒント

```

## 3.3 メニューの操作



### メニューの基本



PoMaS のメニューは、縦に項目が並んでいます。



```

┌─────────────────────────────────┐

│▌Graph                           │

├─────────────────────────────────┤

│1 Plot current functions         │  ← 選択中（ミント背景）

│2 Edit functions                 │

│3 Plot type                      │

│4 Range / Window                 │

│5 Standard window                │

│6 Trig window                    │

│7 Square aspect (1:1)            │

│8 G-Solve                        │

│9 Tangent / Normal at x          │

│10 Save plot as BMP              │

│11 Back                          │

├─────────────────────────────────┤

│ENT:OK                ESC:back   │

└─────────────────────────────────┘

```



### 選択の移動



| キー | 動作 |

|---|---|

| `;` | 上に移動 |

| `.` | 下に移動 |

| `Fn + ;` | 上に移動（代替） |

| `Fn + .` | 下に移動（代替） |



💡 **数字キーで直接ジャンプ**

メニュー項目には番号が振られています。

`1`〜`9` を押すと、その番号の項目に直接ジャンプできます。



### 決定と取消



| キー | 動作 |

|---|---|

| `Enter` | 選択中の項目を決定 |

| `Fn + Esc` | 前の画面に戻る |

| `Esc`（バッククォート） | 前の画面に戻る |



### スクロールバー



項目が画面に収まらない場合、右端にスクロールバーが表示されます。



```

│1 Plot current...        ▌  ← スクロール位置

│2 Edit functions         ▌

│3 Plot type              ▌

│4 Range / Window         █  ← つまみ（現在位置）

│5 Standard window        █

│6 Trig window            ▌

```

## 3.4 入力の基本



### 数式の入力



Calculator モードでの入力例を紹介します。



**例: `2 + 3` を計算する**



1. メインメニューから `1` を押して Calculator を選択

2. `2` キーを押す

3. `+` キーを押す

4. `3` キーを押す

5. `Enter` キーを押す



**画面の流れ**:



```

[1] 入力前

&#x20;   ┌─────────────────────────────┐

&#x20;   │Ans = 0                      │

&#x20;   │─────────────────────────────│

&#x20;   │_                            │

&#x20;   └─────────────────────────────┘



[2] "2" 入力後

&#x20;   ┌─────────────────────────────┐

&#x20;   │Ans = 0                      │

&#x20;   │─────────────────────────────│

&#x20;   │2_                           │

&#x20;   └─────────────────────────────┘



[3] "2+" 入力後

&#x20;   ┌─────────────────────────────┐

&#x20;   │Ans = 0                      │

&#x20;   │─────────────────────────────│

&#x20;   │2+_                          │

&#x20;   └─────────────────────────────┘



[4] "2+3" 入力後

&#x20;   ┌─────────────────────────────┐

&#x20;   │Ans = 0                      │

&#x20;   │─────────────────────────────│

&#x20;   │2+3_                         │

&#x20;   └─────────────────────────────┘



[5] Enter 押下

&#x20;   ┌─────────────────────────────┐

&#x20;   │2+3 = 5                      │

&#x20;   │Ans = 5                      │

&#x20;   │─────────────────────────────│

&#x20;   │_                            │

&#x20;   └─────────────────────────────┘

```



### 入力の修正



| キー | 動作 |

|---|---|

| `Del` | 最後の 1 文字を削除 |

| `Fn + Esc` | 入力をキャンセル（画面を抜ける） |



💡 **長い式の入力**

式が画面幅を超えると、自動的にスクロールします。

カーソルは常に右端に追従します。



### 入力ダイアログ



数値や文字列の入力を求められる場面があります。



```

┌─────────────────────────────────┐

│▌Settings                        │

├─────────────────────────────────┤

│  ┌───┐                          │

│  │digits 0-9:│                  │  ← プロンプト（ミント）

│  └───┘                          │

│  ┌──────────────────────────┐   │

│  │4_                        │   │  ← 入力欄

│  └──────────────────────────┘   │

└─────────────────────────────────┘

```



- `Enter` で確定

- `Fn + Esc` でキャンセル

- `Del` で 1 文字削除

## 3.5 通知と確認



### 通知（Notify）



操作の結果を短時間表示します。



```

┌─────────────────────────────────┐

│                                 │

│        ┌──────────────┐         │

│        │▌Saved        │         │  ← 通知（中央）

│        └──────────────┘         │

│                                 │

└─────────────────────────────────┘

```



通知は約 0.8 秒で自動的に消えます。操作は不要です。



### 確認（Confirm）



重要な操作の前に、Yes/No を求められます。



```

┌─────────────────────────────────┐

│                                 │

│    ┌─────────────────────┐      │

│    │ Reset all?          │      │

│    │  ┌────┐  ┌────┐     │      │

│    │  │[Y] │  │[N] │     │      │

│    │  │Yes │  │No  │     │      │

│    │  └────┘  └────┘     │      │

│    └─────────────────────┘      │

│                                 │

└─────────────────────────────────┘

```



| キー | 動作 |

|---|---|

| `Y` | Yes（実行） |

| `N` | No（キャンセル） |

| `Esc` | No と同じ（キャンセル） |

## 3.6 各モードへの入り方と戻り方



### Calculator モード



```

メインメニュー → 1 または Enter → Calculator

Calculator → Fn + Esc → メインメニュー

```



### CAS モード



```

メインメニュー → 2 → CAS

CAS → Fn + Esc → メインメニュー

```



### Statistics モード



```

メインメニュー → 3 → Statistics サブメニュー

Statistics サブメニュー → 各機能

各機能 → Fn + Esc → Statistics サブメニュー

Statistics サブメニュー → Fn + Esc → メインメニュー

```



💡 **階層の深さ**

PoMaS のメニューは最大 4 階層まで潜ります。

`Fn + Esc` を押すたびに 1 階層ずつ戻ります。



### ESC の連続押しについて



**v0.92 の改良点**: ESC を押した直後に連続で ESC が反応しないよう、

**ESC クールダウン** 機能が入っています。



```

[1] Fn + Esc 押下 → 1 階層戻る

[2] キーを離す

[3] もう一度 Fn + Esc 押下 → さらに 1 階層戻る

```



素早く 2 回押すと、2 階層戻るのではなく、1 階層だけ戻ります。

**誤ってメインメニューまで戻ってしまう事故を防ぐ**ための仕様です。

## 3.7 設定の基本



### 設定画面への入り方



**方法 1**: メインメニュー → 6 Tools → 4 Settings

**方法 2**: Calculator → Fn + 1



### 変更できる設定



| 項目 | 選択肢 |

|---|---|

| 角度モード | DEG / RAD / GRA |

| 表示形式 | Norm / Fix / Sci / Eng |

| 表示桁数 | 0 〜 9 |

| Norm の閾値 | Norm 1 / Norm 2 |



### 設定の保存



設定は自動的に NVS（不揮発性ストレージ）に保存されます。

再起動しても維持されます。



💡 **手動保存**

`Settings → Save settings now` で明示的に保存できます。

通常は 60 秒ごとに自動保存されています。

## 3.8 この章のまとめ



- 起動: 電源ボタン長押し → スプラッシュ → メインメニュー

- 画面は ヘッダ / ボディ / フッタ の 3 領域

- メニュー操作: `;` `.` で移動、`Enter` で決定、`Fn + Esc` で戻る

- 入力修正: `Del` で 1 文字削除

- 通知（0.8 秒）と確認（Y/N）の 2 種類のダイアログ

- ESC 連続押し防止機能あり

- 設定は自動保存（NVS）



### 確認問題



📝 **Q3-1**: メインメニューから Calculator に入るには？

<details><summary>答え</summary>

`1` キーを押す、または `Enter` で 1 番目の項目を選択。

</details>



📝 **Q3-2**: メニューで 1 つ上の項目に移動するには？

<details><summary>答え</summary>

`;` キー、または `Fn + ;`。

</details>



📝 **Q3-3**: ESC を素早く 2 回押すと、2 階層戻りますか？

<details><summary>答え</summary>

いいえ。ESC クールダウン機能により、1 階層だけ戻ります。

キーを離してからもう一度押すと、さらに 1 階層戻ります。

</details>



📝 **Q3-4**: 設定を変更した後、保存操作は必要ですか？

<details><summary>答え</summary>

通常は不要。自動保存されます。

明示的に保存したい場合は `Save settings now` を実行。

</details>
