## 1.1 PoMaS とは
**PoMaS（ポマス、Pocket Mathematics Station）** は、M5Stack Cardputer-Adv という
手のひらサイズのコンピュータの上で動く、多機能な関数電卓です。
「関数電卓」と聞いて、どんなものを思い浮かべますか？
- 学校で使う、sin や cos が計算できる電卓
- 科学者の机に置いてある、ボタンがたくさんある機械
- スマートフォンの電卓アプリの、もっと高機能な版
PoMaS は、これらすべてを含み、さらに超えた機能を持っています。
### PoMaS でできること
| できること | 例 |
|---|---|
| ふつうの計算 | `2 + 3 = 5` |
| 関数の計算 | `sin(30°) = 0.5` |
| 統計の計算 | 平均・分散・回帰・検定 |
| グラフの描画 | `y = sin(x)` の曲線 |
| 科学定数の検索 | 光速 `c = 299792458 m/s` |
| 周期表の参照 | 118 元素の原子量 |
| プログラミング | μLisp 言語で関数を定義 |
### なぜ「ポケット数学ステーション」なのか
数学や科学の作業では、次のような場面がよくあります。
1. 数式を計算したい
2. 結果をグラフで確認したい
3. 統計的に分析したい
4. 使った定数の値を確認したい
5. ちょっとしたスクリプトを書きたい
通常、これらは別々のアプリやツールを使い分ける必要があります。
PoMaS は、**これらすべてを 1 台に統合**しました。
ポケットに入るサイズで、机の上を占有しません。

## 1.2 対象読者
本書は、以下のような方を想定しています。
### 🎓 学生の方
- 中学・高校の数学で関数電卓を使い始めたい
- 大学の統計の授業で電卓が必要
- 研究で数値計算をしたい
### 🔬 科学・技術者の方
- 実験データをその場で統計処理したい
- 複雑な計算を手元で済ませたい
- 科学定数をすぐ参照したい
### 💻 プログラミング好きの方
- 小さな Lisp 処理系で遊びたい
- ハードウェアとソフトウェアの両方を楽しみたい
### 📚 数学が好きな方
- 関数電卓の新しい可能性に興味がある
- ポケットに入る計算機が欲しい
### 前提知識
- **特別な予備知識は不要です**
- 四則演算（+ − × ÷）ができれば十分
- プログラミング経験は必須ではありません

## 1.3 本書の構成
本書は **全 17 章** からなり、大きく 10 部に分かれています。
```
第 I 部 はじめに          … 第1〜3章（本書の入り口）
第 II 部 キーボードと画面 … 第4章
第 III 部 Calculator       … 第5〜6章
第 IV 部 CAS               … 第7章
第 V 部 Statistics         … 第8〜9章
第 VI 部 Graph             … 第10章
第 VII 部 SciRef           … 第11章
第 VIII 部 Tools           … 第12章
第 IX 部 設定              … 第13章
第 X 部 リファレンス       … 第14〜17章
```
### 読み方の 3 つのパターン

**パターン 1: 通読**

最初から最後まで順に読む。最も理解が深まります。
所要時間の目安: 20〜30 時間（じっくり演習しながら）

**パターン 2: 辞書的に使う**

必要な章だけを開く。目次から目的の章へジャンプ。
所要時間: 必要な分だけ

**パターン 3: 実践優先**

第 1〜3 章だけ読んで、あとは実際に使いながら必要な章を参照。
所要時間: 1〜2 時間で使い始められます

## 1.4 PoMaS の全体像
PoMaS の機能は、**6 つのモード** に分かれています。
モードはメインメニューから選択します。
```
┌──────────────────────────────────────────┐
│  1. Calculator   （電卓）                  │
│  2. CAS          （数式処理）              │
│  3. Statistics   （統計）                  │
│  4. SciRef       （科学資料）              │
│  5. Graph        （グラフ）                │
│  6. Tools        （ツール）                │
│  7. About        （バージョン情報）        │
└──────────────────────────────────────────┘
```
### 各モードの役割
| モード | 主な用途 | 章 |
|---|---|---|
| **Calculator** | 日常の計算、関数計算、単位換算 | 第5〜6章 |
| **CAS** | 数式の変形、微分、積分 | 第7章 |
| **Statistics** | 統計解析、検定、グラフ | 第8〜9章 |
| **SciRef** | 定数・法則・単位・周期表の検索 | 第11章 |
| **Graph** | 関数のグラフ描画 | 第10章 |
| **Tools** | スプレッドシート、Lisp、Wi-Fi | 第12章 |
