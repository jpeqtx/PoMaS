## 1.1 PoMaS とは
**PoMaS（ポマス、Pocket Mathematics Station）** は、M5Stack Cardputer-Adv という
手のひらサイズのコンピュータの上で動く、多機能な関数電卓です。
「関数電卓」と聞いて、どんなものを思い浮かべますか？
- 学校で使う、sin や cos が計算できる電卓
- 科学者の机に置いてある、ボタンがたくさんある機械
- スマートフォンの電卓アプリの、もっと高機能な版
PoMaS は、これらすべてを含み、さらに超えた機能を持っています。
### PoMaS でできること
| できること | 例 |
|---|---|
| ふつうの計算 | `2 + 3 = 5` |
| 関数の計算 | `sin(30°) = 0.5` |
| 統計の計算 | 平均・分散・回帰・検定 |
| グラフの描画 | `y = sin(x)` の曲線 |
| 科学定数の検索 | 光速 `c = 299792458 m/s` |
| 周期表の参照 | 118 元素の原子量 |
| プログラミング | μLisp 言語で関数を定義 |
### なぜ「ポケット数学ステーション」なのか
数学や科学の作業では、次のような場面がよくあります。
1. 数式を計算したい
2. 結果をグラフで確認したい
3. 統計的に分析したい
4. 使った定数の値を確認したい
5. ちょっとしたスクリプトを書きたい
通常、これらは別々のアプリやツールを使い分ける必要があります。
PoMaS は、**これらすべてを 1 台に統合**しました。
ポケットに入るサイズで、机の上を占有しません。

## 1.2 対象読者
本書は、以下のような方を想定しています。
### 学生の方
- 中学・高校の数学で関数電卓を使い始めたい
- 大学の統計の授業で電卓が必要
- 研究で数値計算をしたい
### 科学・技術者の方
- 実験データをその場で統計処理したい
- 複雑な計算を手元で済ませたい
- 科学定数をすぐ参照したい
### プログラミング好きの方
- 小さな Lisp 処理系で遊びたい
- ハードウェアとソフトウェアの両方を楽しみたい
### 数学が好きな方
- 関数電卓の新しい可能性に興味がある
- ポケットに入る計算機が欲しい
### 前提知識
- **特別な予備知識は不要です**
- 四則演算（+ − × ÷）ができれば十分
- プログラミング経験は必須ではありません

## 1.4 PoMaS の全体像
PoMaS の機能は、**6 つのモード** に分かれています。
モードはメインメニューから選択します。
```
┌──────────────────────────────────────────┐
│  1. Calculator   （電卓）                  │
│  2. CAS          （数式処理）              │
│  3. Statistics   （統計）                  │
│  4. SciRef       （科学資料）              │
│  5. Graph        （グラフ）                │
│  6. Tools        （ツール）                │
│  7. About        （バージョン情報）        │
└──────────────────────────────────────────┘
```
### 各モードの役割
| モード | 主な用途 | 章 |
|---|---|---|
| **Calculator** | 日常の計算、関数計算、単位換算 | 第5〜6章 |
| **CAS** | 数式の変形、微分、積分 | 第7章 |
| **Statistics** | 統計解析、検定、グラフ | 第8〜9章 |
| **SciRef** | 定数・法則・単位・周期表の検索 | 第11章 |
| **Graph** | 関数のグラフ描画 | 第10章 |
| **Tools** | スプレッドシート、Lisp、Wi-Fi | 第12章 |

## 1.5 PoMaS の歴史と設計思想

### 1.5.1 開発の動機

PoMaS は「ポケットサイズで本格的な数学環境を実現する」という単一の目標から生まれました。既存の関数電卓では:

- **CAS がない**: 数値計算のみ、記号計算不可
- **統計が弱い**: 平均程度しかない、検定や回帰は外部ツール
- **グラフが貧弱**: 1 関数、モノクロ、拡大縮小なし
- **科学資料がない**: 定数・法則・単位は別途参照
- **プログラミング不可**: 単なる計算機

M5Stack Cardputer-Adv という手のひらサイズのハードウェアを活用し、これらすべてを 1 ファームウェアに統合するのが PoMaS の設計です。

### 1.5.2 設計の基本方針

| 方針 | 内容 |
|---|---|
| **オフライン完結** | 全機能がネット不要で動作 |
| **明るい Paper UI** | 長時間の作業でも疲れない配色 |
| **物理キーボード活用** | スマホ電卓を超える入力速度 |
| **永続化** | 設定・履歴・関数は NVS/SD に自動保存 |
| **拡張性** | ソースを公開、誰でも機能追加可能 |
| **互換性重視** | 一般的な数学記法（sin, cos, log など） |

### 1.5.3 バージョン履歴

| バージョン | 主な変更 |
|---|---|
| v0.91 | 初期実装（6 モード、基本 CAS、統計） |
| **v0.92** | Paper UI v2、医学計算、統計 17 グラフ、uLisp 強化 |

v0.92 は機能面・バグ修正面・UI 面のすべてで大幅な強化が行われた版です。以降のバージョンは互換性を保ちながら拡張されます。

### 1.5.4 今後のロードマップ

- v0.93: 画面輝度設定、スリープ時間設定、Notes Application
- v0.94: 追加の医学計算スコア、拡張統計グラフ
- v1.00: 安定版、マニュアル完全版、リポジトリ整理

## 1.6 他の数学ツールとの比較

### 1.6.1 関数電卓（Casio fx-991 など）

| 観点 | 関数電卓 | PoMaS |
|---|---|---|
| 電卓基本機能 | 完全 | 完全 |
| CAS（微分・積分） | 限定 | 34 コマンド |
| 統計検定 | 数種 | 11 種 + ノンパラ |
| グラフ | 小型液晶 | 240×135 カラー |
| データ保存 | なし | NVS + SD |
| 拡張性 | なし | uLisp |

### 1.6.2 スマートフォンアプリ（Wolfram Alpha など）

| 観点 | スマホアプリ | PoMaS |
|---|---|---|
| 高性能計算 | クラウド | ローカル |
| ネット必要 | はい | いいえ |
| 電池持ち | 1 日 | 数日〜1 週間 |
| 持ち運び | スマホ + ネット | 単体で完結 |
| 学習用途 | 制限（ネット依存） | 自由（オフライン） |

### 1.6.3 PC ソフト（Mathematica、Maxima）

| 観点 | PC ソフト | PoMaS |
|---|---|---|
| 高性能計算 | 圧倒的 | 中程度（実用範囲） |
| 起動時間 | 数秒 | 0.5 秒（電源 ON → 利用可能） |
| 携帯性 | ノート PC | ポケット |
| 電池持ち | 数時間 | 数日 |
| 学習コスト | 高い | 低い（直感的 UI） |

**PoMaS の強み**: 「ポケットに入る」「起動が速い」「電池持ちが良い」「オフラインで完結」の 4 点で、他のどのツールにもない独自の位置を確立しています。

## 1.7 対象ユーザー別の使い方

### 1.7.1 学生（中学・高校）

**推奨モード**: Calculator → Statistics → Graph

**学習シナリオ**:
1. 授業中に素早い計算（四則・三角・対数）
2. 試験前に統計の基本（平均・標準偏差）
3. 数学の宿題でグラフ確認（関数の形）

**避けた方が良い機能**: CAS の高度コマンド、uLisp、医学計算

### 1.7.2 大学生（理系）

**推奨モード**: Calculator → CAS → Statistics → Graph

**学習シナリオ**:
1. 微積分の検算（CAS の Derivative / Integral）
2. 物理実験のデータ処理（回帰・検定）
3. 卒研の数値計算（ODE ソルバー、最適化）

### 1.7.3 大学院生・研究者

**推奨モード**: Statistics → CAS → Tools

**研究シナリオ**:
1. 多変量解析（PCA、因子分析、重回帰）
2. 生存分析（KM、Cox PH）
3. メタアナリシス
4. カスタム計算（uLisp）

### 1.7.4 医療従事者

**推奨モード**: Medical Calculator → Statistics

**臨床シナリオ**:
1. バイタル評価（MAP、Shock Index）
2. 重症度スコア（GCS、CURB-65、qSOFA）
3. 薬剤投与量計算（PK）
4. 腎機能評価（CKD-EPI、Cockcroft-Gault）

### 1.7.5 エンジニア

**推奨モード**: Calculator → SciRef → Graph

**業務シナリオ**:
1. 単位換算（電気・材料）
2. 科学定数の参照（抵抗率、誘電率）
3. 関数グラフの確認（設計検証）

### 1.7.6 教育者

**推奨モード**: すべて

**活用例**:
1. 授業デモ（グラフ、統計、CAS の「見える化」）
2. 問題作成（乱数、方程式）
3. 生徒の学習進度確認（統計の基礎）

## 1.9 用語の基本

### 1.9.1 PoMaS 特有の用語

| 用語 | 意味 |
|---|---|
| **モード** | 機能の大分類（Calculator/CAS/Statistics など） |
| **サブメニュー** | モード内の細分類 |
| **Ans** | 直前の計算結果 |
| **Ans バンク** | 複数の結果を保存する領域（20 個） |
| **変数** | A〜J の 10 個の記憶領域 |
| **メモリ M** | 単一の記憶領域（古典的電卓の M+/M-） |
| **ヘッダ** | 画面上部のタイトルバー |
| **フッタ** | 画面下部のヒントバー |
| **バッジ** | ヘッダ右の状態表示（DEG/NRM など） |

### 1.9.2 数学用語

| 用語 | 意味 |
|---|---|
| **多項式** | x^n の和で表される式 |
| **因数分解** | 多項式を積の形に |
| **展開** | 積を多項式の和に |
| **微分** | 変化率を求める |
| **積分** | 累積量を求める |
| **行列** | 数を行列状に並べたもの |
| **ベクトル** | 数を 1 列に並べたもの |
| **確率分布** | 確率の分布形状（正規・二項など） |
| **仮説検定** | データから仮説を判定 |

## 1.10 はじめての 5 分

### 1.10.1 起動手順

1. 電源ボタンを 2 秒長押し
2. スプラッシュ（2.5 秒）
3. メインメニュー表示

### 1.10.2 最初の計算

**例: 2 + 3 の計算**

```
[1] メインメニューで 1（Calculator）
[2] "2" キー
[3] "+" キー
[4] "3" キー
[5] Enter
→ 画面に "2+3 = 5" が表示される
```

### 1.10.3 関数の計算

**例: sin(30°)**

```
[1] ヘッダのバッジが DEG であることを確認
[2] "sin(30)" と入力
[3] Enter
→ 0.5
```

### 1.10.4 メニューを抜ける

```
[1] Fn + ESC → メインメニュー
[2] 電源ボタン長押し → 電源 OFF
```

### 1.10.5 最初に覚えるべき 3 つのキー

| キー | 用途 |
|---|---|
| `Fn + ESC` | 前の画面に戻る（最重要） |
| `Enter` | 決定・実行 |
| `;` `.` | メニュー上下移動 |

これだけで PoMaS の 80% は操作できます。

## 1.11 FAQ

### 1.11.1 電源が入らない

- USB-C ケーブルで充電（1.5〜2 時間）
- 電源ボタンを 2 秒以上長押し
- G0 ボタン + リセット（ダウンロードモード）

### 1.11.2 日本語入力はできる？

- 数式入力では日本語不可（英数字・記号のみ）
- メニュー表示は日本語対応
- SD カードのファイル名は英数字推奨

### 1.11.3 電池はどのくらい持つ？

- 連続使用: 4〜6 時間（使用状況による）
- 待機: 10 分で自動電源 OFF（設定変更可）
- 充電: 1.5〜2 時間

### 1.11.4 ネット接続は必須？

- すべての基本機能はオフラインで動作
- Wi-Fi は Maxima 連携のみ使用（オプション）

### 1.11.5 データは保存される？

- 設定: NVS に自動保存（60 秒ごと）
- 統計データ: SD カードに CSV 保存
- 計算履歴: メモリ内のみ（電源 OFF で消える）
- Ans バンク: メモリ内のみ

### 1.11.6 SD カードは必須？

- 基本機能: SD 不要
- CSV 保存/読込: SD 必須
- uLisp スクリプト: SD 必須
- BMP スクリーンショット: SD 必須

### 1.11.7 ファームウェア更新方法

- Arduino IDE で書き込み（詳細は第 19 章）
- esptool で書き込み（コマンドライン）

### 1.11.8 他の人と共有するには

- `.bin` ファイル（プリビルド版）を共有
- ソースコードは GitHub で公開
- マニュアルは GitHub Pages
