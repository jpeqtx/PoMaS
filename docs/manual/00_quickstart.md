## 0.1 この章の目的

この章は **5 分で PoMaS を使い始められる** ようにする最短ガイドです。詳細な説明は第1章以降に譲り、ここでは「電源を入れる → 計算する → よく使う機能を呼ぶ → 電源を切る」までの流れだけを扱います。

### 対象読者

- PoMaS を初めて触る方
- 買ったばかりで何から始めればいいか分からない方
- 説明書を読む前に、まず動かしてみたい方

### 前提

- PoMaS が書き込まれた M5Stack Cardputer-Adv
- USB ケーブル（充電用）

## 0.2 電源を入れる

### 手順

```
[1] 電源ボタンを 2 秒以上長押し
[2] 画面に PoMaS ロゴが表示される（2.5 秒）
[3] メインメニューが表示される
```

### 画面の見方

```
┌─────────────────────────────────┐
│▌PoMaS 0.92          DEG|NRM     │  ← ヘッダ
├─────────────────────────────────┤
│1 Calculator                     │
│2 CAS                            │
│3 Statistics                     │
│4 Medical Calculator             │
│5 Scientific Reference           │
│6 Graph                          │
│7 Tools (Sheet/uLisp/WiFi)       │
│8 About                          │
├─────────────────────────────────┤
│ENT:OK                ESC:back   │  ← フッタ
└─────────────────────────────────┘
```

| 部分 | 意味 |
|---|---|
| ヘッダ | タイトル + 状態バッジ（DEG/NRM など） |
| ボディ | メニュー項目・計算結果・グラフ |
| フッタ | キーヒント |

## 0.3 最初の計算

### 2 + 3 を計算する

```
[1] "1" キー → Calculator モードに入る
[2] "2" キー
[3] "+" キー
[4] "3" キー
[5] "Enter" キー
→ 画面に "2+3 = 5" と表示される
```

### sin(30°) を計算する

```
[1] Calculator モードで
[2] "sin(30)" と入力
[3] "Enter"
→ 0.5
```

**注意**: ヘッダのバッジが `DEG` であることを確認してください。`RAD` だと sin(30) は -0.988 になります。

### 計算結果を続けて使う

直前の結果は `Ans` で参照できます。

```
[1] "5" "Enter" → Ans = 5
[2] "Ans * 2" "Enter" → 10
[3] "Ans + 3" "Enter" → 13
```

---

## 0.4 よく使う機能（ショートカット）

Calculator モードで `Fn + 数字` を押すと、主要機能に直接アクセスできます。

| ショートカット | 機能 | 使う場面 |
|---|---|---|
| `Fn + 1` | 設定 | 角度モード・表示形式を変える |
| `Fn + 2` | 履歴 | 過去の計算を呼び出す |
| `Fn + 4` | 変数 A〜J | 値を保存・参照 |
| `Fn + 5` | 基数変換 | 16進/8進/2進に変換 |
| `Fn + 7` | 複素数 | 3+4i の計算 |
| `Fn + 8` | 拡張ツール | 方程式・行列・幾何 |
| `Fn + 9` | RPN 切替 | 逆ポーランド記法 |

**ヒント**: まずは `Fn + 1`（設定）と `Fn + 8`（拡張ツール）だけ覚えれば十分です。

## 0.5 メニューの基本操作

### 移動と決定

| キー | 動作 |
|---|---|
| `;` または `Fn + ;` | 上に移動 |
| `.` または `Fn + .` | 下に移動 |
| `1` 〜 `9` | 該当番号へ直接ジャンプ |
| `Enter` | 決定 |
| `` ` ``（ESC） | 戻る |

### 実際の操作例

```
[1] メインメニューで ". " を 2 回押す
→ "3 Statistics" がハイライト
[2] "Enter"
→ Statistics サブメニュー表示
[3] "1" を押す
→ "Lists & Descriptive" へ
[4] ESC を押す
→ Statistics サブメニューへ
[5] ESC を押す
→ メインメニューへ
```

**重要**: ESC キーは物理的には `` ` ``（バッククォート）です。`Fn + Esc` でも同じ動作をします。

## 0.6 電源を切る

### 手順

```
[1] 任意の画面で電源ボタンを 2 秒以上長押し
[2] 画面が暗くなり電源 OFF
```

### 注意

- モード内で電源を切ると、入力中のデータは失われます
- 重要な計算結果は Ans バンク（`Fn + b`）に保存してから切ってください
- 無操作 10 分で自動電源 OFF します（設定変更可）

---

## 0.7 5 分で覚える 5 つのこと

### 1. 起動と終了

- 電源ボタン **2 秒長押し** で起動
- 電源ボタン **2 秒長押し** で終了

### 2. 戻るキー

- `` ` ``（ESC）または `Fn + Esc` で **1 階層戻る**
- これを覚えれば迷子にならない

### 3. メニュー操作

- `;` 上、`.` 下、`Enter` 決定
- 数字キーで直接ジャンプも可能

### 4. 計算と Ans

- Calculator で式を入力して `Enter`
- `Ans` で直前の結果を再利用

### 5. ショートカット

- `Fn + 1`（設定）、`Fn + 8`（拡張ツール）だけまず覚える

## 0.9 困ったときは

|---|---|

| メニューから戻れない | `` ` `` または `Fn + Esc` |
