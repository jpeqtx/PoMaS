## 23.1 この章の使い方

この章は **目的から逆引き** できる索引です。「こういうことをしたい」と思ったとき、該当する章・セクションを探すのに使います。

### 索引の構造

- **23.2 数学を学ぶ**: 学生・独学者向け
- **23.3 物理実験を解析する**: 実験レポート向け
- **23.4 化学計算をする**: 化学系
- **23.5 生物統計を扱う**: 生物・医学系
- **23.6 臨床計算をする**: 医療従事者向け
- **23.7 工学計算をする**: エンジニア向け
- **23.8 金融計算をする**: 投資・ローン
- **23.9 教育現場で使う**: 教師向け
- **23.10 プログラミングする**: uLisp 学習者向け
- **23.11 上級テクニック**: 慣れた方向け

## 23.11 上級テクニック

### 23.11.1 効率的なワークフロー

**データ分析の 5 ステップ**:

```
[1] Tools → Spreadsheet で生データ整理
[2] T キーで Sheet → L1..L8 変換
[3] Statistics で記述統計
[4] 回帰・検定
[5] Statistics → 10 でグラフ化
```

### 23.11.2 モード間連携

**Ans と変数の使い分け**:

| 用途 | 推奨 |
|---|---|
| 一時的な計算結果 | Ans |
| 複数の値を保持 | Ans バンク |
| 名前付き変数 | A〜J |
| 累積計算 | メモリ M |
| 統計データ | L1〜L8 |

### 23.11.3 ショートカットの組み合わせ

**最速計算の例**:

```
[1] Fn+1 で設定確認（DEG/NRM）
[2] 式入力 → Enter
[3] Ans で連続計算
[4] Fn+b で重要結果を Ans バンクへ
[5] Fn+2 で履歴確認
```

### 23.11.4 数式の再利用

**過去の式を呼び出す**:

```
[1] Fn+2 で履歴
[2] ; . で移動
[3] Enter で入力欄に挿入
[4] 一部を修正して再実行
```

### 23.11.5 グラフの高速描画

**描画速度を上げる**:

| 設定 | 効果 |
|---|---|
| implCell = 8 | 陰関数を高速化（粗くなる） |
| grid3N = 6 | 3D を高速化 |
| tstep = 0.1 | パラメトリックを高速化 |

### 23.11.6 統計の効率化

**大規模データの処理**:

| 手法 | 用途 |
|---|---|
| CSV ストリーム統計 | メモリを使わず大規模 CSV |
| リストの分割 | 200 件超は分割 |
| 平均・分散を先に確認 | 外れ値の検出 |

### 23.11.7 uLisp で自動化

**よく使う計算の自動化**:

```
(define (my-stats lst)
  (list (mean lst) (sd lst) (sum lst)))
(my-stats '(10 20 30 40 50))
→ (30 15.811 150)
```

### 23.11.8 医学計算の応用

**複数患者の一括評価**:

```
[1] 各患者のデータを L1〜L5 に整理
[2] Medical でスコア計算
[3] 結果を L6 にコピー
[4] Statistics で分布確認
[5] Graph で可視化
```

### 23.11.9 カスタム関数の活用
