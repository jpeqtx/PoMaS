## 5.1 Calculator モードの画面
Calculator モードは、PoMaS の中心となる機能です。
日常の計算から高度な関数計算まで、あらゆる計算をここで行います。
### 画面レイアウト
```
┌─────────────────────────────────┐
│▌Calculator          DEG|NRM     │  ← ヘッダ
├─────────────────────────────────┤
│2+3 = 5                          │
│10*2 = 20                        │  ← 履歴（過去 3 件）
│sin(30) = 0.5                    │
│                                 │
│                                 │
│Ans = 20                         │  ← 直前の結果
│─────────────────────────────────│
│_                                │  ← 入力欄
├─────────────────────────────────┤
│Fn+0:Help            Fn+9:RPN    │  ← フッタ
└─────────────────────────────────┘
```
### 各領域の役割
| 領域 | 内容 |
|---|---|
| **履歴** | 過去 3 回の計算結果（式と答え） |
| **Ans** | 直前の計算結果 |
| **入力欄** | 現在入力中の式 |
| **ヘッダバッジ** | 角度モード（DEG/RAD/GRA）と表示形式（NRM/FIX/SCI/ENG） |

## 5.2 四則演算
### 足し算
**例: 2 + 3 を計算する**
```
[1] 2 を押す
[2] + を押す
[3] 3 を押す
[4] Enter を押す
結果: Ans = 5
```
### 引き算
**例: 10 - 4**
```
10 - 4 Enter → 6
```
💡 **負の数**
`-5 + 3` のように、先頭に `-` を付けられます。
`2 + -3` も `2 - 3` と同じ結果です。
### 掛け算
**例: 6 × 7**
```
6 * 7 Enter → 42
```
⚠️ **`×` 記号は使わない**
`*`（アスタリスク）を使います。
### 割り算
**例: 20 ÷ 4**
```
20 / 4 Enter → 5
```
⚠️ **ゼロで割ると**
`10 / 0` → `ERR: division by zero`（エラー）
### 複合演算
**例: (2 + 3) × 4**
```
(2+3)*4 Enter → 20
```
**演算子の優先順位**:
| 優先度 | 演算子 |
|---|---|
| 高 | `()`（括弧） |
| ↓ | `^`（べき乗） |
| ↓ | `!`（階乗） |
| ↓ | `*`, `/`, `%`（乗除算） |
| 低 | `+`, `-`（加減算） |
💡 **迷ったら括弧を付ける**
`2+3*4` は `2+(3*4) = 14` になります。
`(2+3)*4 = 20` としたい場合は括弧が必須です。
---
## 5.3 べき乗と階乗
### べき乗
**例: 2 の 10 乗**
```
2^10 Enter → 1024
```
**負の指数**
```
2^-3 Enter → 0.125
```
**小数の指数**
```
9^0.5 Enter → 3  （√9 と同じ）
```
### 階乗（!）
**例: 5 の階乗（5! = 5×4×3×2×1）**
```
5! Enter → 120
```
**大きな階乗**
```
10! Enter → 3628800
20! Enter → 2.43e18
```
💡 **階乗の上限**
内部的には 170! 程度まで計算できますが、
それ以上は無限大（Inf）になります。

## 5.4 数学関数
### 三角関数
**角度モードに注意**
三角関数の結果は、現在の角度モード（DEG/RAD/GRA）に依存します。
| モード | 30 の意味 |
|---|---|
| DEG | 30° |
| RAD | 30 ラジアン（約 1718°） |
| GRA | 30 グラジアン（= 27°） |
**デフォルトは DEG**（度数法）です。
**例: sin(30°)**
```
sin(30) Enter → 0.5
```
**例: cos(60°)**
```
cos(60) Enter → 0.5
```
**例: tan(45°)**
```
tan(45) Enter → 1
```
### 逆三角関数
**例: arcsin(0.5) を DEG で求める**
```
asin(0.5) Enter → 30
```
結果は **30**（30°）です。角度モードに応じた単位で返ります。
### 双曲線関数
**例: sinh(1)**
```
sinh(1) Enter → 1.1752
```
| 関数 | 意味 |
|---|---|
| `sinh` | 双曲線正弦 |
| `cosh` | 双曲線余弦 |
| `tanh` | 双曲線正接 |
| `asinh` | 逆双曲線正弦 |
| `acosh` | 逆双曲線余弦 |
| `atanh` | 逆双曲線正接 |
### 指数・対数
| 関数 | 意味 | 例 |
|---|---|---|
| `exp(x)` | e の x 乗 | `exp(1) = 2.718` |
| `ln(x)` | 自然対数 | `ln(e) = 1` |
| `log(x)` | 常用対数（底 10） | `log(100) = 2` |
| `log2(x)` | 底 2 の対数 | `log2(8) = 3` |
| `logn(a,b)` | 底 a の b の対数 | `logn(3,81) = 4` |
⚠️ **`log` は底 10**
`ln` と間違えないように注意。
底 10 の対数は `log`、自然対数は `ln` です。
### 平方根・立方根
| 関数 | 意味 | 例 |
|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(16) = 4` |
| `cbrt(x)` | 立方根 | `cbrt(27) = 3` |
| `nrt(n,x)` | n 乗根 | `nrt(3,27) = 3` |
### 絶対値・符号
| 関数 | 意味 | 例 |
|---|---|---|
| `abs(x)` | 絶対値 | `abs(-5) = 5` |
| `sign(x)` | 符号 | `sign(-3) = -1` |
| `sgn(x)` | 符号（同上） | `sgn(0) = 0` |
### 丸め
| 関数 | 意味 | 例 |
|---|---|---|
| `floor(x)` | 切り捨て | `floor(3.7) = 3` |
| `ceil(x)` | 切り上げ | `ceil(3.2) = 4` |
| `round(x)` | 四捨五入 | `round(3.5) = 4` |
| `int(x)` | 整数部 | `int(3.7) = 3` |
| `frac(x)` | 小数部 | `frac(3.7) = 0.7` |
### 組合せ・順列
| 関数 | 意味 | 例 |
|---|---|---|
| `nCr(n,r)` | 組合せ（n から r 選ぶ） | `nCr(5,2) = 10` |
| `nPr(n,r)` | 順列（順番も区別） | `nPr(5,2) = 20` |
**使い分け**:
- **組合せ（nCr）**: 順番を区別しない。「5 人から 2 人の委員を選ぶ」
- **順列（nPr）**: 順番を区別する。「5 人から 1 位と 2 位を選ぶ」
### その他
| 関数 | 意味 |
|---|---|
| `gcd(a,b)` | 最大公約数 |
| `lcm(a,b)` | 最小公倍数 |
| `isPrime(n)` | 素数判定（1 or 0） |
| `nextPrime(n)` | 次の素数 |
| `prevPrime(n)` | 前の素数 |
| `hypot(x,y)` | √(x² + y²) |
| `min(a,b)` | 最小値 |
| `max(a,b)` | 最大値 |
| `mod(a,b)` | a を b で割った余り |
| `pow(a,b)` | a の b 乗（`^` と同じ） |
| `random()` | 0〜1 の乱数 |
| `randInt(n)` | 0〜n-1 のランダム整数 |
| `randN(sd)` | 平均 0、標準偏差 sd の正規乱数 |
| `randR(a,b)` | a〜b の乱数 |

## 5.5 定数
### 数学定数
| 名前 | 値 | 入力 |
|---|---|---|
| 円周率 π | 3.14159... | `pi` |
| ネイピア数 e | 2.71828... | `e` または `euler` |
| 黄金比 φ | 1.61803... | `phi` |
| オイラー・マスケローニ | 0.57721... | `gamma` |
| 無限大 | ∞ | `inf` |
| 非数 | NaN | `nan` |
### 直前の結果（Ans）
```
10 * 2 Enter → 20
Ans + 5 Enter → 25
Ans * 2 Enter → 50
```
`Ans` は直前の計算結果を参照します。
連続した計算で便利です。
### メモリ（mem）
`mem` は独立したメモリ領域です。
`Fn + 3` から操作できます。
```
mem = 100  (Fn + 3 で設定)
mem * 2 Enter → 200
```

## 5.6 変数 A〜J
### 変数とは
**変数** は、数値に名前を付けて保存する仕組みです。
計算の途中経過や、よく使う値を覚えておけます。
PoMaS では、**A〜J の 10 個** の変数が使えます。
大文字・小文字の両方で参照できます。
### 変数の使い方
**Step 1: 変数に値を代入**
`Fn + 4` で変数メニューを開きます。
```
┌─────────────────────────────────┐
│▌Variables A..J                  │
├─────────────────────────────────┤
│1 A = 0                          │
│2 B = 0                          │
│3 C = 0                          │
│4 D = 0                          │
│5 E = 42                         │
│...                              │
└─────────────────────────────────┘
```
`5`（E）を選ぶと、値を入力できます。
`42` と入力して Enter。
**Step 2: 変数を式で使う**
Calculator 画面で:
```
E * 2 Enter → 84
```
### 変数の参照
| 入力 | 参照される値 |
|---|---|
| `A` | 変数 A の値 |
| `a` | 変数 A の値（小文字も同じ） |
| `E` | 変数 E の値 |
| `e` | オイラー数（定数、変数 E ではない） |
⚠️ **E と e の違い**
- `E`（大文字）: 変数 E（デフォルト 0、ユーザーが変更可能）
- `e`（小文字）: オイラー数 2.718...
混同しやすいので注意。
### 変数の使用例
**例: 三角形の面積を計算**
```
[1] Fn+4 → A に底辺 6 を代入
[2] Fn+4 → B に高さ 4 を代入
[3] A * B / 2 Enter → 12
```
**例: 連立方程式**
```
[1] A = 2, B = 3, C = 8
[2] A * 2 + B Enter → 7
[3] A * 3 + B * 2 Enter → 12
```

## 5.7 履歴
### 履歴の概要
PoMaS は、過去 **100 件** の計算を記録しています。
直近 3 件は常に画面に表示されます。
### 履歴の表示
```
┌─────────────────────────────────┐
│2+3 = 5                          │  ← 3 回前
│10*2 = 20                        │  ← 2 回前
│sin(30) = 0.5                    │  ← 直前
│                                 │
```
### 履歴呼び出し（Fn + 2）
過去の計算を呼び出して再実行できます。
```
[1] Fn + 2 で履歴一覧を開く
[2] ; . で移動
[3] Enter で選択
→ 選択した式が入力欄に挿入されます
```
💡 **履歴の再利用**
「あの計算をもう一度」というときに便利です。
値だけを再利用したい場合は、履歴から Ans に転送してから使います。

## 5.8 メモリ M
### メモリの概要
**メモリ M** は、変数とは別の単一記憶領域です。
古典的な電卓の「M+」「M-」「MR」に相当します。
### メモリ操作（Fn + 3）
```
┌─────────────────────────────────┐
│▌Memory M=0                      │
├─────────────────────────────────┤
│1 M+ (M += Ans)                  │
│2 M- (M -= Ans)                  │
│3 MR (Ans <- M)                  │
│4 MC (M = 0)                     │
│5 Set M = ...                    │
│6 Back                           │
└─────────────────────────────────┘
```
| 操作 | 動作 |
|---|---|
| M+ | M に Ans を加算 |
| M- | M から Ans を減算 |
| MR | Ans に M をコピー |
| MC | M を 0 にクリア |
| Set | M に直接値を設定 |
### 使用例
**例: 合計を計算**
```
[1] 10 Enter → Ans = 10
[2] Fn+3 → M+ (M = 10)
[3] 20 Enter → Ans = 20
[4] Fn+3 → M+ (M = 30)
[5] 15 Enter → Ans = 15
[6] Fn+3 → M+ (M = 45)
[7] Fn+3 → MR (Ans = 45)
```
合計 45 が Ans にセットされます。

## 5.9 Ans バンク
### Ans バンクとは
**Ans バンク** は、複数の Ans を保存できる機能です。
最大 **20 件** まで保存できます。
古典的な電卓にはない、PoMaS 独自の機能です。
### 使い方（Fn + b）
```
┌─────────────────────────────────┐
│▌Ans Bank (3/20)                 │
├─────────────────────────────────┤
│1 Ans      = 5                   │
│2 Ans      = 20                  │
│3 Ans      = 45                  │
│4 [+] Add current Ans            │
│5 [V] Pop to variable A..J       │
│6 [C] Clear all bank             │
│7 [<-] Back                      │
└─────────────────────────────────┘
```
### 主な操作
| 操作 | 意味 |
|---|---|
| エントリ選択 | Insert / Ans に戻す / 変数へ / 削除 |
| [+] Add | 現在の Ans をバンクに追加 |
| [V] Pop | 最後のエントリを変数に移送 |
| [C] Clear | バンク全体をクリア |
### 使用例
**例: 3 つの異なる計算結果を保存**
```
[1] 5 Enter
[2] Fn+b → [+] Add (エントリ1 = 5)
[3] 20 Enter
[4] Fn+b → [+] Add (エントリ2 = 20)
[5] 45 Enter
[6] Fn+b → [+] Add (エントリ3 = 45)
後で:
[7] Fn+b → エントリ1を選択
[8] "Insert into expression" を選ぶ
[9] 入力欄に 5 が挿入される
```
💡 **統計計算の途中結果を保持**
平均・分散・標準偏差を別々に計算して Ans バンクに保存し、
最後に組み合わせて使う、といった使い方ができます。

## 5.10 表示形式
### 表示形式の種類
| 形式 | 例 | 説明 |
|---|---|---|
| **Norm** | 1.23456 | 通常の表示 |
| **Fix** | 1.23 | 固定小数点（桁数指定） |
| **Sci** | 1.23e+00 | 科学表記 |
| **Eng** | 1.23 | 工学表記（3 桁区切り） |
### 切り替え
`Settings → Display` または `Fn + 1` で切り替えます。
### 表示桁数
`Fn + ,` で 1 桁増、`Fn + /` で 1 桁減。
0〜9 の範囲で設定できます。
💡 **桁数の目安**
- 3 桁: 概算で十分
- 5 桁: 通常の計算
- 7 桁: 精度重視
- 9 桁: 最大精度
### Norm 1 / Norm 2 の違い
**Norm** は「通常表示」ですが、非常に小さい数や大きい数をどう表示するかで 2 種類あります。
| モード | 小さい数の閾値 | 例 |
|---|---|---|
| Norm 1 | 0.01 未満で指数表示 | `0.005` → `5e-3` |
| Norm 2 | 0.000000001 未満で指数表示 | `0.005` → `0.005` |
💡 **迷ったら Norm 1**
Norm 1 は「0.01 未満は指数表示」なので、科学技術計算向き。
Norm 2 は「日常的な数値を見やすく」したい場合向け。

## 5.11 角度モード
### 3 つの角度モード
| モード | 単位 | 1 周 |
|---|---|---|
| **DEG** | 度数法 | 360° |
| **RAD** | 弧度法 | 2π（約 6.28） |
| **GRA** | グラジアン | 400 |
### 切り替え
`Settings → Angle` または `Fn + 1`。
### 三角関数への影響
同じ `sin(30)` でも、モードによって結果が変わります。
| モード | sin(30) |
|---|---|
| DEG | 0.5（30°） |
| RAD | -0.988（30 rad） |
| GRA | 0.454（30 grad） |
⚠️ **モードの確認**
三角関数を使う前に、ヘッダのバッジで現在のモードを確認してください。

## 5.12 三角関数 個別リファレンス

### sin(x) — 正弦

**用途**: 角度 x の正弦を返します。

**構文**:
```
sin(x)
```

**引数**: x — 角度（現在の角度モード DEG/RAD/GRAD に依存）

**戻り値**: -1.0 〜 1.0

**例**:
```
sin(30)      → 0.5     (DEG)
sin(90)      → 1       (DEG)
sin(0)       → 0
sin(pi/2)    → 1       (RAD)
sin(-30)     → -0.5
```

**備考**:
- ヘッダのバッジ（DEG/RAD/GRA）を事前に確認
- 戻り値の範囲は常に -1 ≤ y ≤ 1
- 引数が極端に大きいと精度低下

**関連**: cos, tan, asin, csc

### cos(x) — 余弦

**用途**: 角度 x の余弦を返します。

**構文**:
```
cos(x)
```

**引数**: x — 角度

**戻り値**: -1.0 〜 1.0

**例**:
```
cos(0)       → 1
cos(60)      → 0.5     (DEG)
cos(90)      → 0       (DEG)
cos(pi)      → -1      (RAD)
```

**備考**:
- sin(x) = cos(x - 90°)（DEG）
- 三角関数の合成で頻用

**関連**: sin, tan, acos, sec

### tan(x) — 正接

**用途**: 角度 x の正接（sin/cos）を返します。

**構文**:
```
tan(x)
```

**引数**: x — 角度

**戻り値**: 実数（±∞ に発散可能）

**例**:
```
tan(0)       → 0
tan(45)      → 1       (DEG)
tan(30)      → 0.57735 (DEG)
tan(60)      → 1.73205 (DEG)
```

**備考**:
- 90°（DEG）/ π/2（RAD）の奇数倍で発散（数学的に定義されない）
- PoMaS 内部で cos が 0 に近い場合、大きな値を返す
- 精度誤差で想定外の値になる場合あり

**関連**: sin, cos, atan, cot

## 5.13 逆三角関数 個別リファレンス

### asin(x) — 逆正弦

**用途**: sin(y) = x を満たす角度 y を返します。

**構文**:
```
asin(x)
```

**引数**: x — -1.0 〜 1.0 の範囲（外れると NaN）

**戻り値**: 角度（-90° 〜 90° / -π/2 〜 π/2）

**例**:
```
asin(0.5)    → 30      (DEG)
asin(1)      → 90      (DEG)
asin(-1)     → -90     (DEG)
asin(0)      → 0
```

**備考**:
- |x| > 1 の入力は NaN
- 戻り値は現在の角度モードに従う
- 主値のみ（多価関数ではない）

**関連**: sin, acos, atan

### acos(x) — 逆余弦

**用途**: cos(y) = x を満たす角度 y を返します。

**構文**:
```
acos(x)
```

**引数**: x — -1.0 〜 1.0

**戻り値**: 角度（0° 〜 180° / 0 〜 π）

**例**:
```
acos(0.5)    → 60      (DEG)
acos(1)      → 0
acos(-1)     → 180     (DEG)
acos(0)      → 90      (DEG)
```

**備考**:
- 戻り値は 0 〜 180°（DEG）の範囲
- 三角形の角度計算で頻用（余弦定理）

**関連**: cos, asin, atan

### atan(x) — 逆正接

**用途**: tan(y) = x を満たす角度 y を返します。

**構文**:
```
atan(x)
```

**引数**: x — 任意の実数

**戻り値**: 角度（-90° 〜 90° / -π/2 〜 π/2）

**例**:
```
atan(1)      → 45      (DEG)
atan(0)      → 0
atan(1.732)  → 60      (DEG)
atan(-1)     → -45     (DEG)
```

**備考**:
- 引数は任意の実数
- 4 象限対応は `atan2(y, x)` を使用

**関連**: tan, asin, acos, atan2

## 5.19 組合せ・順列・階乗

### fact(n) — 階乗

**構文**: `fact(n)` または `n!`

**用途**: n! = n × (n-1) × ... × 1

**例**:
```
fact(0)      → 1
fact(1)      → 1
fact(5)      → 120
fact(10)     → 3628800
fact(20)     → 2.43e18
```

**備考**: n > 170 で Inf（double 上限）、負数・非整数は gamma で拡張

**関連**: gamma, nPr, nCr

### nCr(n, r) — 組合せ

**構文**: `nCr(n, r)`

**用途**: n 個から r 個選ぶ組合せ（順序なし）。

**数式**: nCr = n! / (r! × (n-r)!)

**例**:
```
nCr(5, 2)    → 10
nCr(10, 3)   → 120
nCr(5, 0)    → 1
nCr(5, 5)    → 1
nCr(5, 6)    → 0
```

**用途例**: 5 人から 2 人委員 = 10 通り、宝くじ 6/49 = nCr(49,6) ≈ 1.4e7

**関連**: nPr

### nPr(n, r) — 順列

**構文**: `nPr(n, r)`

**用途**: n 個から r 個選んで並べる順列（順序あり）。

**数式**: nPr = n! / (n-r)!

**例**:
```
nPr(5, 2)    → 20
nPr(10, 3)   → 720
nPr(5, 5)    → 120
nPr(5, 0)    → 1
```

**用途例**: 5 人から 1 位・2 位 = 20 通り

**関連**: nCr, fact

直前の計算結果。連続した計算で使える。
</details>
📝 **Q5-5**: `log(100)` と `ln(e)` の結果は？
<details><summary>答え</summary>
`log(100) = 2`（底 10）、`ln(e) = 1`（自然対数）。
</details>
📝 **Q5-6**: `E` と `e` の違いは？
<details><summary>答え</summary>
`E`（大文字）は変数 E、`e`（小文字）はオイラー数 2.718...。
</details>
