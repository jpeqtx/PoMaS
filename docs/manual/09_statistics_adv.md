## 9.2 ノンパラメトリック検定

### ノンパラメトリックとは

**パラメトリック検定**（t 検定など）は、
データが正規分布していると仮定します。

**ノンパラメトリック検定** は、その仮定が不要です。
以下の場合に使います。

- データが少ない（10 件未満）
- 外れ値がある
- 順序尺度（満足度など）
- 正規分布していない

### 起動

```
Statistics → 4 (Non-parametric / Risk)
```

### メニュー

```
┌─────────────────────────────────┐
│▌Nonpar/Risk                     │
├─────────────────────────────────┤
│1 Mann-Whitney U                 │
│2 Wilcoxon signed rank           │
│3 Kruskal-Wallis                 │
│4 Friedman                       │
│5 Sign test                      │
│6 Spearman correlation           │
│7 Kendall tau                    │
│8 Odds Ratio + 95% CI            │
│9 Risk Ratio + 95% CI            │
│10 Risk Difference + 95% CI      │
│11 NNT                           │
│12 CI (mean)                     │
│13 CI (proportion)               │
│14 Back                          │
└─────────────────────────────────┘
```

### Mann-Whitney U 検定

**用途**: 2 群の中央値に差があるか（ノンパラ版 t 検定）

**例**: L1 = [1,2,3,4,5], L2 = [6,7,8,9,10]

```
[1] Mann-Whitney U
[2] Group A: 1
[3] Group B: 2
→ stat = 0
  z = -2.611
  p = 0.009
  * significant
```

**解釈**: p = 0.009 < 0.05 なので、2 群の中央値に有意差あり。

### Wilcoxon 符号順位検定

**用途**: 対応あり 2 群の中央値に差があるか（ノンパラ版 paired t 検定）

**例**: ダイエット前後の体重（正規分布していない場合）

```
[1] Wilcoxon signed rank
[2] Pair A list: 1 (前)
[3] Pair B list: 2 (後)
→ z = ...
  p = ...
```

### Kruskal-Wallis 検定

**用途**: 3 群以上の中央値に差があるか（ノンパラ版 ANOVA）

**例**: L1, L2, L3 の 3 群比較

```
[1] Kruskal-Wallis
[2] 自動的に全リスト（n≥2）を比較
→ H = ...
  df = 2
  p = ...
```

### Friedman 検定

**用途**: 同じ対象に 3 回以上の測定（反復測定、ノンパラ版）

**例**: 同じ人に 3 種類の薬を試した結果

### 符号検定（Sign test）

**用途**: 対応あり 2 群で「+」と「-」の数が偏るか

最もシンプルなノンパラ検定。差の符号だけを見ます。

### Spearman 順位相関

**用途**: 2 変数の順位相関（ノンパラ版相関）

**例**: L1 = [1,2,3,4,5], L2 = [2,4,6,8,10]

```
→ rho = 1.0000
  p = 0.0000
  * significant
```

順位が完全に一致しているので、rho = 1。

### Kendall τ（ケンドールのタウ）

**用途**: 2 変数の順位相関（Spearman とは別の指標）

| 指標 | 特徴 |
|---|---|
| Spearman | 順位の差の 2 乗を使う |
| Kendall | 順位の一致/不一致ペア数を使う |

Kendall の方が外れ値に強い。

## 9.3 リスク指標

### 2×2 分割表

リスク指標は、2×2 の分割表から計算します。

```
             疾病あり  疾病なし
暴露あり      a         b
暴露なし      c         d
```

### オッズ比（Odds Ratio, OR）

**例**: 喫煙と肺がんでの 2×2 表

```
             肺がんあり  肺がんなし
喫煙あり      90          910
喫煙なし      10          990
```

```
[1] Nonpar/Risk → 8 (Odds Ratio)
[2] a: 90, b: 910, c: 10, d: 990
→ OR = (a·d)/(b·c) = (90·990)/(910·10) = 9.79
  95% CI [4.99, 19.22]
```

**解釈**: 喫煙者は非喫煙者より、肺がんになるオッズが約 9.79 倍。

### リスク比（Risk Ratio, RR）

```
r1 = a/(a+b) = 90/1000 = 0.09
r2 = c/(c+d) = 10/1000 = 0.01
RR = r1/r2 = 9.0
```

**解釈**: 喫煙者は非喫煙者の 9 倍のリスク。

### リスク差（Risk Difference, RD）

```
RD = r1 - r2 = 0.09 - 0.01 = 0.08
```

**解釈**: リスクが 8% 高い。

### NNT（Number Needed to Treat）

1 人の患者を救うのに、何人の治療が必要か。

```
NNT = 1 / |RD| = 1 / 0.08 = 12.5 ≈ 13
```

**解釈**: 13 人治療すれば 1 人救える。

### 信頼区間（CI）

**信頼区間** は、「真の値が入っている可能性が高い範囲」です。
95% CI は「95% の確率で真の値がこの範囲に入る」ことを意味します。

| 指標 | CI に 1 が含まれる？ | 解釈 |
|---|---|---|
| OR | 含まれない | 有意な関連あり |
| OR | 含まれる | 関連なし |
| RR | 同上 | 同上 |

### 信頼区間（CI）の計算（mean / proportion）

**CI（mean）**: 平均の信頼区間

```
[1] Nonpar/Risk → 12 (CI mean)
[2] List: 1
[3] Confidence: 0.95
→ mean = 30
  95% CI = [10.4, 49.6]
```

**CI（proportion）**: 比率の信頼区間（Wilson 法）

```
[1] Nonpar/Risk → 13 (CI proportion)
[2] x = 30 (成功数)
[3] n = 100 (試行数)
[4] Conf: 0.95
→ p = 0.30
  95% CI = [0.217, 0.399]
```

## 9.4 確率分布ブラウザ

### 起動

```
Statistics → 5 (Distributions)
```

### メニュー

```
┌─────────────────────────────────┐
│▌Distribution                    │
├─────────────────────────────────┤
│1 Normal N(mu, sigma)            │
│2 Student t (df)                 │
│3 Chi-Square (df)                │
│4 F (d1, d2)                     │
│5 Binomial (n, p)                │
│6 Poisson (lambda)               │
│7 Geometric (p)                  │
│8 Back                           │
└─────────────────────────────────┘
```

### 各分布の用途

| 分布 | 用途 | 例 |
|---|---|---|
| **正規分布** | 身長、テスト点など自然現象 | 成人男性の身長 |
| **t 分布** | 小標本の平均検定 | 5 人の平均 |
| **χ² 分布** | 適合度検定、独立性検定 | サイコロの公平性 |
| **F 分布** | 分散分析、F 検定 | 3 群の比較 |
| **二項分布** | 成功/失敗の試行 | コイン 10 回の表の数 |
| **ポアソン分布** | 単位時間当たりの発生回数 | 1 時間の来客数 |
| **幾何分布** | 初成功までの試行回数 | ガチャの当たるまで |

### 各分布でできること

| 操作 | 記号 | 内容 |
|---|---|---|
| **PDF/PMF** | f(x) | 確率密度関数 / 確率質量関数 |
| **CDF** | F(x) | 累積分布関数 P(X≤x) |
| **Inverse** | F⁻¹(q) | 逆関数（分位点） |
| **Plot PDF** | — | グラフ描画 |

### 例: 正規分布 N(0, 1) の CDF

**問題**: P(X ≤ 1.96) は？

```
[1] Normal → 1 (CDF)
[2] mu: 0, sigma: 1
[3] x: 1.96
→ CDF = 0.975
```

**解釈**: 標準正規分布で 1.96 以下の確率は 97.5%。

### 例: 正規分布の逆関数

**問題**: 上位 5% に入る値は？（P(X ≤ x) = 0.95）

```
[1] Normal → 2 (Inverse)
[2] mu: 0, sigma: 1
[3] q: 0.95
→ x = 1.6449
```

### 例: 二項分布

**問題**: コイン 10 回投げて表がちょうど 5 回の確率

```
[1] Binomial → 0 (PMF)
[2] n: 10, p: 0.5
[3] k: 5
→ PMF = 0.2461
```

### 例: ポアソン分布

**問題**: 平均 3 人来客の店で、5 人来る確率

```
[1] Poisson → 0 (PMF)
[2] lambda: 3
[3] k: 5
→ PMF = 0.1008
```

### PDF プロット

`4 (Plot PDF)` で分布の形をグラフで確認できます。
全 7 分布で利用可能。

## 9.5 多変量解析

### 起動

```
Statistics → 6 (Multivariate)
```

### メニュー

```
┌─────────────────────────────────┐
│▌Multivariate                    │
├─────────────────────────────────┤
│1 PCA (Principal Component)      │
│2 Factor Analysis (Varimax)      │
│3 k-means Clustering             │
│4 Hierarchical (Ward)            │
│5 Decision Tree (CART)           │
│6 Back                           │
└─────────────────────────────────┘
```

### PCA（主成分分析）

**用途**: 多次元データを少ない次元に圧縮

**例**: 5 科目のテスト点（国語、数学、英語、理科、社会）を
「文系能力」「理系能力」の 2 軸に要約。

```
[1] PCA
[2] L1〜L5 を自動使用
→ PC  eig    var%   cumul%
   1  2.5    50.0%  50.0%
   2  1.8    36.0%  86.0%
   ...
```

**解釈**: 第 1 主成分で 50%、第 2 主成分までで 86% の情報を捉えている。

### 因子分析（Factor Analysis）

**用途**: 観測データの背後にある「潜在因子」を推定

**例**: 5 科目のテスト点から、「言語能力」「論理能力」などの
因子を抽出。

```
[1] Factor Analysis
[2] # factors: 2
→ 各変数の負荷量（Varimax 回転後）
```

### k-means クラスタリング

**用途**: データを k 個のグループに分類

**例**: 顧客データを 3 つのセグメントに分類。

```
[1] k-means
[2] k clusters: 3
→ C1: [顧客 A, B, ...]
  C2: [顧客 C, D, ...]
  C3: [顧客 E, F, ...]
```

### 階層クラスタリング（Ward 法）

**用途**: データを階層的に分類

デンドログラム（樹形図）を作る手法。
k-means と違い、事前にクラスタ数を決めなくても良い。

### 決定木（CART）

**用途**: 目的変数を予測するルールを木構造で表現

**例**: 生存予測の決定木

```
[1] 年齢 ≤ 50
    ├─ Yes → [2] 性別 = 男
    │         ├─ Yes → 生存率 80%
    │         └─ No  → 生存率 90%
    └─ No  → [3] ステージ
              ├─ I-II → 生存率 70%
              └─ III-IV → 生存率 30%
```

## 9.6 層別解析

### 層別解析とは

データを「層（グループ）」に分けて分析する手法。
交絡因子の影響を排除できます。

**例**: 薬の効果を性別ごとに検討（性別で層別）。
全体では効果なしに見えても、男女別では効果があるケースを発見できます。

### 起動

```
Statistics → 7 (Stratified)
```

### メニュー

```
┌─────────────────────────────────┐
│▌Stratified                      │
├─────────────────────────────────┤
│1 MH OR + per-stratum + Forest   │
│2 MH RR + per-stratum + Forest   │
│3 Food Poisoning (auto detect)   │
│4 Cochran's Q (heterogeneity)    │
│5 Breslow-Day test               │
│6 Back                           │
└─────────────────────────────────┘
```

### Mantel-Haenszel OR

層ごとのオッズ比を統合して、全体のオッズ比を推定します。

**例**: 2 層（若年層、高齢層）の各 2×2 表から、全体の OR を計算。

```
[1] MH OR
[2] # strata: 2
[3] S1 の a, b, c, d を入力
[4] S2 の a, b, c, d を入力
→ Per-stratum: S1 OR, S2 OR
  Common (MH): 全体 OR
  95% CI
  Breslow-Day 検定（異質性）
```

### Food Poisoning Trace

食中毒の原因食品を特定する特殊機能。

**例**: 5 種類の食品（L1〜L5）と発症（L6）のデータから、
原因食品を特定。

```
[1] L1〜L5: 各食品の摂取（1=摂取, 0=非摂取）
[2] L6: 発症（1=発症, 0=非発症）
[3] Food Poisoning Trace
→ 食品ごとの RR を計算し、ランキング表示
   赤色 = RR > 2 かつ p < 0.05（要注意）
```

**使い方**:
1. 5 種類の食品を食べたかどうかを L1〜L5 に記録
2. 発症したかどうかを L6 に記録
3. Food Poisoning Trace を実行
4. 「RR が高く、p が小さい」食品が原因の候補

### Cochran's Q

複数の研究の効果が均一かどうかの検定。

```
[1] # studies: 5
[2] 各研究の効果 y と分散 v を入力
→ Q = ...
  p = ...
  I² = ...
```

I² > 50% なら異質性が高いと判断。

### Breslow-Day 検定

層ごとの効果が均一かどうかの検定。

## 9.8 メタアナリシス

### メタアナリシスとは

複数の研究を統合して、全体の効果を推定する手法。
「研究の研究」とも呼ばれます。

### 起動

```
Statistics → 9 (Meta-analysis)
```

### メニュー

```
┌─────────────────────────────────┐
│▌Meta-Analysis                   │
├─────────────────────────────────┤
│1 Inverse variance (FE/RE)       │
│2 DerSimonian-Laird (RE)         │
│3 Forest plot                    │
│4 Funnel plot                    │
│5 Egger's test                   │
│6 Back                           │
└─────────────────────────────────┘
```

### Inverse variance

各研究の効果を、分散の逆数で重み付けして統合。

**理論**: 分散が小さい（精度が高い）研究ほど、重視される。

### DerSimonian-Laird

研究間の異質性を考慮したランダム効果モデル。

### Forest plot

各研究と統合結果を視覚化。

```
S1 ─●─
S2  ─●─
S3   ─●─
────────●──── Pool
```

各研究の効果と 95% CI、プールされた効果が表示されます。

### Funnel plot

出版バイアスをチェック。

```
効果
  ↑
  │   ●
  │  ● ●
  │ ● ● ●
  │  ● ●
  │   ●
  └────→ 標準誤差
```

左右対称なら出版バイアスなし。

### Egger's test

出版バイアスの統計的検定。

```
[1] Egger's test
→ intercept = ...
  t = ...
  p = ...
```

p < 0.05 なら出版バイアスの可能性。

0.975（97.5%）。
</details>

📝 **Q9-5**: PCA（主成分分析）の用途は？
<details><summary>答え</summary>
多次元データを少ない次元に圧縮し、データの構造を理解する。
</details>

📝 **Q9-6**: Kaplan-Meier 曲線は何を表すか？
<details><summary>答え</summary>
時間経過に伴う生存率の変化。
</details>

📝 **Q9-7**: 森林プロット（Forest plot）は何に使う？
<details><summary>答え</summary>
メタアナリシスで、各研究の効果と統合結果を視覚化する。
</details>
