## 9.2 ノンパラメトリック検定
### ノンパラメトリックとは
**パラメトリック検定**（t 検定など）は、
データが正規分布していると仮定します。
**ノンパラメトリック検定** は、その仮定が不要です。
以下の場合に使います。
- データが少ない（10 件未満）
- 外れ値がある
- 順序尺度（満足度など）
- 正規分布していない
### 起動
```
Statistics → 4 (Non-parametric / Risk)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Nonpar/Risk                     │
├─────────────────────────────────┤
│1 Mann-Whitney U                 │
│2 Wilcoxon signed rank           │
│3 Kruskal-Wallis                 │
│4 Friedman                       │
│5 Sign test                      │
│6 Spearman correlation           │
│7 Kendall tau                    │
│8 Odds Ratio + 95% CI            │
│9 Risk Ratio + 95% CI            │
│10 Risk Difference + 95% CI      │
│11 NNT                           │
│12 CI (mean)                     │
│13 CI (proportion)               │
│14 Back                          │
└─────────────────────────────────┘
```
### Mann-Whitney U 検定
**用途**: 2 群の中央値に差があるか（ノンパラ版 t 検定）
**例**: L1 = [1,2,3,4,5], L2 = [6,7,8,9,10]
```
[1] Mann-Whitney U
[2] Group A: 1
[3] Group B: 2
→ stat = 0
  z = -2.611
  p = 0.009
  * significant
```
**解釈**: p = 0.009 < 0.05 なので、2 群の中央値に有意差あり。
### Wilcoxon 符号順位検定
**用途**: 対応あり 2 群の中央値に差があるか（ノンパラ版 paired t 検定）
**例**: ダイエット前後の体重（正規分布していない場合）
```
[1] Wilcoxon signed rank
[2] Pair A list: 1 (前)
[3] Pair B list: 2 (後)
→ z = ...
  p = ...
```
### Kruskal-Wallis 検定
**用途**: 3 群以上の中央値に差があるか（ノンパラ版 ANOVA）
**例**: L1, L2, L3 の 3 群比較
```
[1] Kruskal-Wallis
[2] 自動的に全リスト（n≥2）を比較
→ H = ...
  df = 2
  p = ...
```
### Friedman 検定
**用途**: 同じ対象に 3 回以上の測定（反復測定、ノンパラ版）
**例**: 同じ人に 3 種類の薬を試した結果
### 符号検定（Sign test）
**用途**: 対応あり 2 群で「+」と「-」の数が偏るか
最もシンプルなノンパラ検定。差の符号だけを見ます。
### Spearman 順位相関
**用途**: 2 変数の順位相関（ノンパラ版相関）
**例**: L1 = [1,2,3,4,5], L2 = [2,4,6,8,10]
```
→ rho = 1.0000
  p = 0.0000
  * significant
```
順位が完全に一致しているので、rho = 1。
### Kendall τ（ケンドールのタウ）
**用途**: 2 変数の順位相関（Spearman とは別の指標）
| 指標 | 特徴 |
|---|---|
| Spearman | 順位の差の 2 乗を使う |
| Kendall | 順位の一致/不一致ペア数を使う |
Kendall の方が外れ値に強い。

## 9.3 リスク指標
### 2×2 分割表
リスク指標は、2×2 の分割表から計算します。
```
             疾病あり  疾病なし
暴露あり      a         b
暴露なし      c         d
```
### オッズ比（Odds Ratio, OR）
**例**: 喫煙と肺がんでの 2×2 表
```
             肺がんあり  肺がんなし
喫煙あり      90          910
喫煙なし      10          990
```
```
[1] Nonpar/Risk → 8 (Odds Ratio)
[2] a: 90, b: 910, c: 10, d: 990
→ OR = (a·d)/(b·c) = (90·990)/(910·10) = 9.79
  95% CI [4.99, 19.22]
```
**解釈**: 喫煙者は非喫煙者より、肺がんになるオッズが約 9.79 倍。
### リスク比（Risk Ratio, RR）
```
r1 = a/(a+b) = 90/1000 = 0.09
r2 = c/(c+d) = 10/1000 = 0.01
RR = r1/r2 = 9.0
```
**解釈**: 喫煙者は非喫煙者の 9 倍のリスク。
### リスク差（Risk Difference, RD）
```
RD = r1 - r2 = 0.09 - 0.01 = 0.08
```
**解釈**: リスクが 8% 高い。
### NNT（Number Needed to Treat）
1 人の患者を救うのに、何人の治療が必要か。
```
NNT = 1 / |RD| = 1 / 0.08 = 12.5 ≈ 13
```
**解釈**: 13 人治療すれば 1 人救える。
### 信頼区間（CI）
**信頼区間** は、「真の値が入っている可能性が高い範囲」です。
95% CI は「95% の確率で真の値がこの範囲に入る」ことを意味します。
| 指標 | CI に 1 が含まれる？ | 解釈 |
|---|---|---|
| OR | 含まれない | 有意な関連あり |
| OR | 含まれる | 関連なし |
| RR | 同上 | 同上 |
### 信頼区間（CI）の計算（mean / proportion）
**CI（mean）**: 平均の信頼区間
```
[1] Nonpar/Risk → 12 (CI mean)
[2] List: 1
[3] Confidence: 0.95
→ mean = 30
  95% CI = [10.4, 49.6]
```
**CI（proportion）**: 比率の信頼区間（Wilson 法）
```
[1] Nonpar/Risk → 13 (CI proportion)
[2] x = 30 (成功数)
[3] n = 100 (試行数)
[4] Conf: 0.95
→ p = 0.30
  95% CI = [0.217, 0.399]
```

## 9.4 確率分布ブラウザ
### 起動
```
Statistics → 5 (Distributions)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Distribution                    │
├─────────────────────────────────┤
│1 Normal N(mu, sigma)            │
│2 Student t (df)                 │
│3 Chi-Square (df)                │
│4 F (d1, d2)                     │
│5 Binomial (n, p)                │
│6 Poisson (lambda)               │
│7 Geometric (p)                  │
│8 Back                           │
└─────────────────────────────────┘
```
### 各分布の用途
| 分布 | 用途 | 例 |
|---|---|---|
| **正規分布** | 身長、テスト点など自然現象 | 成人男性の身長 |
| **t 分布** | 小標本の平均検定 | 5 人の平均 |
| **χ² 分布** | 適合度検定、独立性検定 | サイコロの公平性 |
| **F 分布** | 分散分析、F 検定 | 3 群の比較 |
| **二項分布** | 成功/失敗の試行 | コイン 10 回の表の数 |
| **ポアソン分布** | 単位時間当たりの発生回数 | 1 時間の来客数 |
| **幾何分布** | 初成功までの試行回数 | ガチャの当たるまで |
### 各分布でできること
| 操作 | 記号 | 内容 |
|---|---|---|
| **PDF/PMF** | f(x) | 確率密度関数 / 確率質量関数 |
| **CDF** | F(x) | 累積分布関数 P(X≤x) |
| **Inverse** | F⁻¹(q) | 逆関数（分位点） |
| **Plot PDF** | — | グラフ描画 |
### 例: 正規分布 N(0, 1) の CDF
**問題**: P(X ≤ 1.96) は？
```
[1] Normal → 1 (CDF)
[2] mu: 0, sigma: 1
[3] x: 1.96
→ CDF = 0.975
```
**解釈**: 標準正規分布で 1.96 以下の確率は 97.5%。
### 例: 正規分布の逆関数
**問題**: 上位 5% に入る値は？（P(X ≤ x) = 0.95）
```
[1] Normal → 2 (Inverse)
[2] mu: 0, sigma: 1
[3] q: 0.95
→ x = 1.6449
```
### 例: 二項分布
**問題**: コイン 10 回投げて表がちょうど 5 回の確率
```
[1] Binomial → 0 (PMF)
[2] n: 10, p: 0.5
[3] k: 5
→ PMF = 0.2461
```
### 例: ポアソン分布
**問題**: 平均 3 人来客の店で、5 人来る確率
```
[1] Poisson → 0 (PMF)
[2] lambda: 3
[3] k: 5
→ PMF = 0.1008
```
### PDF プロット
`4 (Plot PDF)` で分布の形をグラフで確認できます。
全 7 分布で利用可能。

### 起動

Statistics → 6 (Multivariate)

### メニュー

### PCA（主成分分析）
**用途**: 多次元データを少ない次元に圧縮
**例**: 5 科目のテスト点（国語、数学、英語、理科、社会）を
「文系能力」「理系能力」の 2 軸に要約。
```
[1] PCA
[2] L1〜L5 を自動使用
→ PC  eig    var%   cumul%
   1  2.5    50.0%  50.0%
   2  1.8    36.0%  86.0%
   ...
```
**解釈**: 第 1 主成分で 50%、第 2 主成分までで 86% の情報を捉えている。
### 因子分析（Factor Analysis）
**用途**: 観測データの背後にある「潜在因子」を推定
**例**: 5 科目のテスト点から、「言語能力」「論理能力」などの
因子を抽出。
```
[1] Factor Analysis
[2] # factors: 2
→ 各変数の負荷量（Varimax 回転後）
```
### k-means クラスタリング
**用途**: データを k 個のグループに分類
**例**: 顧客データを 3 つのセグメントに分類。
```
[1] k-means
[2] k clusters: 3
→ C1: [顧客 A, B, ...]
  C2: [顧客 C, D, ...]
  C3: [顧客 E, F, ...]
```
### 階層クラスタリング（Ward 法）
**用途**: データを階層的に分類
デンドログラム（樹形図）を作る手法。
k-means と違い、事前にクラスタ数を決めなくても良い。
### 決定木（CART）
**用途**: 目的変数を予測するルールを木構造で表現
**例**: 生存予測の決定木
```
[1] 年齢 ≤ 50
    ├─ Yes → [2] 性別 = 男
    │         ├─ Yes → 生存率 80%
    │         └─ No  → 生存率 90%
    └─ No  → [3] ステージ
              ├─ I-II → 生存率 70%
              └─ III-IV → 生存率 30%
```

## 9.6 層別解析
### 層別解析とは
データを「層（グループ）」に分けて分析する手法。
交絡因子の影響を排除できます。
**例**: 薬の効果を性別ごとに検討（性別で層別）。
全体では効果なしに見えても、男女別では効果があるケースを発見できます。
### 起動
```
Statistics → 7 (Stratified)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Stratified                      │
├─────────────────────────────────┤
│1 MH OR + per-stratum + Forest   │
│2 MH RR + per-stratum + Forest   │
│3 Food Poisoning (auto detect)   │
│4 Cochran's Q (heterogeneity)    │
│5 Breslow-Day test               │
│6 Back                           │
└─────────────────────────────────┘
```
### Mantel-Haenszel OR
層ごとのオッズ比を統合して、全体のオッズ比を推定します。
**例**: 2 層（若年層、高齢層）の各 2×2 表から、全体の OR を計算。
```
[1] MH OR
[2] # strata: 2
[3] S1 の a, b, c, d を入力
[4] S2 の a, b, c, d を入力
→ Per-stratum: S1 OR, S2 OR
  Common (MH): 全体 OR
  95% CI
  Breslow-Day 検定（異質性）
```
### Food Poisoning Trace
食中毒の原因食品を特定する特殊機能。
**例**: 5 種類の食品（L1〜L5）と発症（L6）のデータから、
原因食品を特定。
```
[1] L1〜L5: 各食品の摂取（1=摂取, 0=非摂取）
[2] L6: 発症（1=発症, 0=非発症）
[3] Food Poisoning Trace
→ 食品ごとの RR を計算し、ランキング表示
   赤色 = RR > 2 かつ p < 0.05（要注意）
```
**使い方**:
1. 5 種類の食品を食べたかどうかを L1〜L5 に記録
2. 発症したかどうかを L6 に記録
3. Food Poisoning Trace を実行
4. 「RR が高く、p が小さい」食品が原因の候補
### Cochran's Q
複数の研究の効果が均一かどうかの検定。
```
[1] # studies: 5
[2] 各研究の効果 y と分散 v を入力
→ Q = ...
  p = ...
  I² = ...
```
I² > 50% なら異質性が高いと判断。
### Breslow-Day 検定
層ごとの効果が均一かどうかの検定。

## 9.8 メタアナリシス
### メタアナリシスとは
複数の研究を統合して、全体の効果を推定する手法。
「研究の研究」とも呼ばれます。
### 起動
```
Statistics → 9 (Meta-analysis)
```
### メニュー
```
┌─────────────────────────────────┐
│▌Meta-Analysis                   │
├─────────────────────────────────┤
│1 Inverse variance (FE/RE)       │
│2 DerSimonian-Laird (RE)         │
│3 Forest plot                    │
│4 Funnel plot                    │
│5 Egger's test                   │
│6 Back                           │
└─────────────────────────────────┘
```
### Inverse variance
各研究の効果を、分散の逆数で重み付けして統合。
**理論**: 分散が小さい（精度が高い）研究ほど、重視される。
### DerSimonian-Laird
研究間の異質性を考慮したランダム効果モデル。
### Forest plot
各研究と統合結果を視覚化。
```
S1 ─●─
S2  ─●─
S3   ─●─
────────●──── Pool
```
各研究の効果と 95% CI、プールされた効果が表示されます。
### Funnel plot
出版バイアスをチェック。
```
効果
  ↑
  │   ●
  │  ● ●
  │ ● ● ●
  │  ● ●
  │   ●
  └────→ 標準誤差
```
左右対称なら出版バイアスなし。
### Egger's test
出版バイアスの統計的検定。
```
[1] Egger's test
→ intercept = ...
  t = ...
  p = ...
```
p < 0.05 なら出版バイアスの可能性。

## 9.10 ノンパラメトリック検定 詳細

### 9.10.1 Mann-Whitney U 検定

**用途**: 独立 2 群の中央値に差があるかをノンパラメトリックに検定。

**前提**: 正規分布を仮定しない、独立 2 群、順序尺度以上。

**仮説**: H₀: 2 群の分布が同じ、H₁: 異なる

**数式**:
```
R₁ = 群 A の順位和（同順位は平均順位）
U₁ = R₁ - n₁(n₁+1)/2
U₂ = n₁n₂ - U₁
U = min(U₁, U₂)
z = (U - n₁n₂/2) / √(n₁n₂(n₁+n₂+1)/12)
```

**操作例**:
```
[1] Nonpar → 1 (Mann-Whitney U)
[2] Group A: 1 (L1 = [1,2,3,4,5])
[3] Group B: 2 (L2 = [6,7,8,9,10])
→ U = 0, z = -2.611, p = 0.009 (significant)
```

**解釈**: p < 0.05 で 2 群の中央値に有意差あり。

**用途**: 少標本、外れ値あり、順序尺度、正規性が疑わしい場合。

### 9.10.2 Wilcoxon 符号順位検定

**用途**: 対応あり 2 群の中央値に差があるか（ノンパラ版 paired t）。

**前提**: 対応あり、正規性を仮定しない。

**数式**:
```
dᵢ = x₁ᵢ - x₂ᵢ  （差）
|dᵢ| を順位付け、0 は除外
W⁺ = 正の差の順位和
W⁻ = 負の差の順位和
W = min(W⁺, W⁻)
z = (W - n(n+1)/4) / √(n(n+1)(2n+1)/24)
```

**操作例**:
```
[1] Nonpar → 2 (Wilcoxon)
[2] Pair A: 1 (前)
[3] Pair B: 2 (後)
→ z = ..., p = ...
```

**用途**: 前後比較で正規性が疑わしい場合（ダイエット、治療前後）。

### 9.10.3 Kruskal-Wallis 検定

**用途**: 3 群以上の中央値に差があるか（ノンパラ版 ANOVA）。

**前提**: 独立 k 群（k ≥ 3）、正規性を仮定しない。

**数式**:
```
全データを順位付け
H = 12/(N(N+1)) × Σ(Rᵢ²/nᵢ) - 3(N+1)
df = k - 1
```

**操作例**:
```
[1] Nonpar → 3 (Kruskal-Wallis)
[2] 自動的に全リスト（n≥2）を比較
→ H = ..., df = 2, p = ...
```

**用途**: 3 群以上の多重比較のノンパラ版。

**事後検定**: Dunn 検定などで個別比較。

### 9.10.4 Friedman 検定

**用途**: 同対象への 3 回以上の反復測定（ノンパラ版反復 ANOVA）。

**前提**: 対応あり k 条件（k ≥ 3）。

**数式**:
```
各被験者内で順位付け
Rj = 各条件の順位和
Q = 12/(nk(k+1)) × Σ(Rj²) - 3n(k+1)
df = k - 1
```

**用途**: 同じ人に 3 種類の薬を試した結果など。

### 9.10.5 符号検定（Sign test）

**用途**: 対応あり 2 群で差の符号（+/-）に偏りがあるか。

**前提**: 差の符号のみを使用（最もシンプル）。

**数式**:
```
pos = 差が正の個数
neg = 差が負の個数
N = pos + neg  （差 0 は除外）
k = min(pos, neg)
p = 2 × BinomCDF(k, N, 0.5)
```

**用途**: 順序尺度、正規性なし、極端な外れ値がある場合。

**解釈**: p < 0.05 で符号に偏りあり。

### 9.10.6 Spearman 順位相関

**用途**: 2 変数の順位相関（ノンパラ版相関）。

**数式**:
```
各変数を順位付け → Rₓ, R_y
ρ = 1 - 6Σdᵢ² / (n(n²-1))
dᵢ = Rₓᵢ - R_yᵢ
```

**操作例**:
```
[1] Nonpar → 6 (Spearman)
[2] X: L1 = [1,2,3,4,5]
[3] Y: L2 = [2,4,6,8,10]
→ rho = 1.0000, p = 0.0000 (significant)
```

**用途**: 単調関係、順序尺度、外れ値あり。

**関連**: Kendall τ

### 9.10.7 Kendall τ（ケンドールのタウ）

**用途**: 2 変数の順位相関（Spearman の別版）。

**数式**:
```
conc = 一致ペア数
disc = 不一致ペア数
tieX = X の同順位ペア数
tieY = Y の同順位ペア数
τ = (conc - disc) / √((N-tieX)(N-tieY))
z = 3τ√(n(n-1)) / √(2(2n+5))
```

**Spearman vs Kendall**:
| 指標 | 特徴 |
|---|---|
| Spearman | 順位の差の 2 乗を使う |
| Kendall | 一致/不一致ペア数を使う |

**Kendall の利点**: 外れ値に頑健、解釈が直感的。

## 9.11 リスク指標 詳細

2×2 分割表（a: 暴露+疾病+、b: 暴露+疾病-、c: 暴露-疾病+、d: 暴露-疾病-）から計算。

### 9.11.1 オッズ比（Odds Ratio, OR）

**数式**:
```
OR = (a × d) / (b × c)
```

**95% CI**:
```
ln(OR) ± 1.96 × √(1/a + 1/b + 1/c + 1/d)
→ exp(...)
```

**例**:
```
a=90, b=910, c=10, d=990
→ OR = (90×990) / (910×10) = 9.79
  95% CI = [4.99, 19.22]
```

**解釈**: 暴露群は非暴露群の 9.79 倍のオッズで疾病が発生。

**用途**: 症例対照研究、横断研究。

### 9.11.2 リスク比（Risk Ratio, RR、相対リスク）

**数式**:
```
r1 = a/(a+b)  （暴露群のリスク）
r2 = c/(c+d)  （非暴露群のリスク）
RR = r1 / r2
```

**95% CI**:
```
ln(RR) ± 1.96 × √(b/(a(a+b)) + d/(c(c+d)))
→ exp(...)
```

**例**:
```
a=90, b=910, c=10, d=990
→ r1=0.09, r2=0.01, RR=9.0
  95% CI = [...]
```

**解釈**: 暴露群は非暴露群の 9 倍のリスク。

**用途**: コホート研究、RCT。

### 9.11.3 リスク差（Risk Difference, RD、絶対リスク減少）

**数式**:
```
RD = r1 - r2 = a/(a+b) - c/(c+d)
```

**95% CI**:
```
RD ± 1.96 × √(r1(1-r1)/n1 + r2(1-r2)/n2)
```

**解釈**: リスクが 8% 高い（0.08）。

**用途**: 絶対効果量、NNT の基礎。

### 9.11.4 NNT（Number Needed to Treat）

**数式**:
```
NNT = 1 / |RD|
```

**解釈**: 1 人の患者を救うのに必要な治療患者数。

**例**: RD = 0.08 → NNT = 12.5 ≈ 13

**備考**: RD = 0（効果なし）の場合 NNT = ∞

**用途**: 治療効果の実感しやすい指標。

### 9.11.5 比率の信頼区間（Wilson 法）

**数式**:
```
p̂ = x/n
denom = 1 + z²/n
center = (p̂ + z²/(2n)) / denom
half = z × √(p̂(1-p̂)/n + z²/(4n²)) / denom
CI = center ± half
```

**例**: x=30, n=100, 95% CI
```
p̂ = 0.30
→ 95% CI = [0.217, 0.399]
```

**利点**: Wald 法より正確、n が小さくても安定。

## 9.12 確率分布 詳細

### 9.12.1 正規分布 N(μ, σ²)

**用途**: 自然界の多くの現象（身長、測定誤差）。

**PDF**:
```
f(x) = 1/(σ√(2π)) × e^(-(x-μ)²/(2σ²))
```

**CDF**: Φ((x-μ)/σ) で標準正規 CDF に変換。

**逆関数**: Φ⁻¹(q) × σ + μ

**性質**:
- 左右対称、平均 = 中央値 = 最頻値
- 68-95-99.7 ルール
- 平均 0、SD 1 を「標準正規分布」と呼ぶ

**用途例**: 検査値の異常判定、信頼区間の計算。

### 9.12.2 Student t 分布 (df)

**用途**: 小標本での平均検定、信頼区間。

**PDF**:
```
f(t) = Γ((df+1)/2) / (√(df·π)·Γ(df/2)) × (1 + t²/df)^(-(df+1)/2)
```

**性質**:
- 正規分布より裾が重い
- df → ∞ で標準正規分布に収束
- df = n-1 で標本サイズに対応

**用途例**: n=10 の t 検定、95% CI = x̄ ± t₀.₀₂₅ × s/√n。

### 9.12.3 カイ二乗分布 χ²(df)

**用途**: 適合度検定、独立性検定、分散の信頼区間。

**PDF**:
```
f(x) = x^(df/2-1) × e^(-x/2) / (2^(df/2) × Γ(df/2))
```

**性質**:
- x ≥ 0
- 平均 = df、分散 = 2df
- 独立した標準正規の 2 乗和が従う

**用途例**: サイコロの公平性検定（df=5）。

### 9.12.4 F 分布 (d1, d2)

**用途**: 分散分析、F 検定、分散比の信頼区間。

**性質**:
- x ≥ 0
- 2 つの独立 χ² 分布の比 / df
- 分散分析の F 統計量が従う

**用途例**: ANOVA の p 値計算、VIF の判定。

### 9.12.5 二項分布 B(n, p)

**用途**: n 回の独立試行で成功回数が k の確率。

**PMF**:
```
P(X=k) = C(n,k) × p^k × (1-p)^(n-k)
```

**CDF**: Σ P(X=i) for i=0..k

**性質**:
- 平均 = np、分散 = np(1-p)
- p=0.5 で左右対称、それ以外は歪む

**用途例**: コイン 10 回で表 5 回の確率、品質管理。

### 9.12.6 ポアソン分布 Pois(λ)

**用途**: 単位時間あたりの稀な事象の発生回数。

**PMF**:
```
P(X=k) = e^(-λ) × λ^k / k!
```

**性質**:
- 平均 = 分散 = λ
- 二項分布で n→∞、p→0、np→λ の極限

**用途例**: 1 時間の来客数、放射線崩壊、交通事故。

### 9.12.7 幾何分布 Geom(p)

**用途**: 初成功までの試行回数。

**PMF**:
```
P(X=k) = p × (1-p)^(k-1)  (k ≥ 1)
```

**CDF**: 1 - (1-p)^k

**性質**:
- 平均 = 1/p、分散 = (1-p)/p²
- 無記憶性

**用途例**: ガチャの当たるまでの回数、初成功までの試行。

## 9.13 多変量解析 詳細

### 9.13.1 PCA（主成分分析）

**用途**: 多次元データを少ない次元に圧縮。

**アルゴリズム**:
1. データを標準化（平均 0、分散 1）
2. 相関行列 R を計算
3. R の固有値分解 R = V Λ Vᵀ
4. 固有値の大きい順に主成分

**寄与率**: λᵢ / Σλj × 100%

**累積寄与率**: 上位 k 個の寄与率の和

**用途例**: 5 科目のテスト点 → 「文系能力」「理系能力」の 2 軸に要約。

**出力**: 固有値、寄与率、累積寄与率、負荷量（各変数の主成分への寄与）。

### 9.13.2 因子分析（Varimax 回転）

**用途**: 観測データの背後にある「潜在因子」を推定。

**モデル**: x = Λf + ε（Λ: 負荷量、f: 因子、ε: 独自誤差）

**Varimax 回転**: 負荷量の分散を最大化し、因子の解釈を容易にする。

**用途例**: 5 科目 → 「言語」「論理」「記憶」の因子を抽出。

**出力**: 各変数の負荷量（回転後）、因子間相関、共通性。

### 9.13.3 k-means クラスタリング

**用途**: n 個のデータを k 個のグループに分類。

**アルゴリズム**:
1. k 個の初期重心をランダムに選ぶ
2. 各データを最近の重心に割り当て
3. 各クラスタの重心を再計算
4. 変化がなくなるまで繰り返し

**用途例**: 顧客データを 3 セグメントに分類。

**出力**: 各データの所属、各クラスタの重心、クラスタサイズ。

**注意**: k は事前に指定、局所解に陥る可能性。

### 9.13.4 階層クラスタリング（Ward 法）

**用途**: データを階層的に分類（樹形図）。

**アルゴリズム**:
1. 各点を 1 クラスタとして開始
2. 最も近いクラスタ同士を併合
3. k 個になるまで繰り返し

**Ward 法**: クラスタ内分散の増加が最小になるペアを併合。

**用途例**: 遺伝子発現データの分類、系統樹推定。

**出力**: 樹形図、各クラスタの所属。

### 9.13.5 決定木（CART 回帰）

**用途**: 目的変数を予測するルールを木構造で表現。

**アルゴリズム**:
1. 各特徴量・各閾値で分割を試す
2. 分散減少が最大の分割を選ぶ
3. 再帰的に分割（最大深度まで）

**用途例**: 患者データから生存予測、顧客の購買予測。

**出力**: 木構造（各ノードの分割条件、葉の予測値）。

**注意**: 過学習しやすい、剪定が必要。

## 9.14 層別解析 詳細

### 9.14.1 Mantel-Haenszel OR

**用途**: 層ごとのオッズ比を統合して共通の OR を推定。

**数式**:
```
MH-OR = Σ(aᵢdᵢ/nᵢ) / Σ(bᵢcᵢ/nᵢ)
nᵢ = aᵢ + bᵢ + cᵢ + dᵢ
```

**95% CI**: exp(ln(OR) ± 1.96 × √V)、V は Robins-Breslow-Greenland の式。

**用途例**: 薬の効果を性別層別で統合、交絡因子の調整。

### 9.14.2 Mantel-Haenszel RR

**用途**: 層ごとのリスク比を統合。

**数式**:
```
MH-RR = Σ(aᵢn₀ᵢ/Tᵢ) / Σ(cᵢn₁ᵢ/Tᵢ)
```

**用途例**: 性別・年齢層別のリスク比統合。

### 9.14.3 Breslow-Day 検定

**用途**: 層ごとの OR が均一かを検定。

**数式**:
```
各層で期待値 aE, bE, cE, dE を計算
X² = Σ(aᵢ - aEᵢ)² / var(aEᵢ)
df = K - 1
```

**解釈**: p < 0.05 で異質性あり（層別で効果が異なる）。

### 9.14.4 Cochran's Q 検定

**用途**: 複数研究・複数層の効果が均一かを検定。

**数式**:
```
Q = Σwᵢ(yᵢ - ȳ)²、wᵢ = 1/vᵢ
ȳ = Σwᵢyᵢ / Σwᵢ
df = K - 1
```

**I²（異質性指標）**:
```
I² = max(0, (Q - df) / Q × 100%)
```

**解釈**:

| I² | 異質性 |
|---|---|
| 0〜25% | 低 |
| 25〜50% | 中 |
| 50〜75% | 高 |
| > 75% | 非常に高い |

### 9.14.5 食中毒原因追跡（Outbreak Source Trace）

**用途**: 複数の食品と発症データから原因を統計的に特定。

**前提**: 各露出リスト（L1〜L5）が 0/1、アウトカム（L6）が 0/1、同じ長さ。

**アルゴリズム**:
1. 各食品ごとに RR/OR と p 値を計算
2. 期待度数 < 5 のセルがあれば Fisher 検定を自動選択
3. RR > 2 かつ p < 0.05 を「要注意」として赤表示

**出力**: 食品ごとの RR/OR/95% CI/p 値のランキング、森林プロット。

**用途例**: 集団食中毒の原因食品の早期特定。

## 9.15 生存分析 詳細

### 9.15.1 Kaplan-Meier 推定

**用途**: 打ち切りデータから生存関数 S(t) を推定。

**データ形式**: L1=時間、L2=イベント（1=死亡、0=打ち切り）。

**アルゴリズム**:
```
各死亡時点 tᵢ で:
S(t) = Π_{tᵢ ≤ t} (1 - dᵢ/nᵢ)
dᵢ = イベント数、nᵢ = リスク集合サイズ
```

**出力**: 階段状の生存曲線、S(t) の推定値。

**用途例**: 癌患者の 5 年生存率、医療機器の寿命。

### 9.15.2 Log-rank 検定

**用途**: 2 群の生存曲線に差があるか。

**数式**:
```
O₁ = 群 1 の観測イベント数
E₁ = Σ (dᵢ × n₁ᵢ/nᵢ)   （期待値）
V = Σ (dᵢ(nᵢ-dᵢ)n₁ᵢn₂ᵢ) / (nᵢ²(nᵢ-1))
χ² = (O₁ - E₁)² / V
df = 1
```

**用途例**: 治療群 vs 対照群の生存比較。

**解釈**: p < 0.05 で 2 群の生存曲線に有意差あり。

### 9.15.3 Cox 比例ハザードモデル

**用途**: 共変量のハザード比を推定。

**モデル**:
```
h(t|x) = h₀(t) × exp(βx)
HR = exp(β)
```

**数式（部分尤度）**:
```
L(β) = Π_{i:event} exp(βxᵢ) / Σ_{j∈R(tᵢ)} exp(βxⱼ)
```

**95% CI**: exp(β ± 1.96 × SE(β))

**例**:
```
治療群 (x=1) vs 対照群 (x=0)
β = -0.35、HR = exp(-0.35) = 0.70
→ 治療群はハザードが 30% 減少
```

**前提**: 比例ハザード仮定（HR が時間で一定）。

**用途例**: 薬剤効果、予後因子の評価。

### 9.15.4 Median Survival（中央生存時間）

**用途**: 生存率が 50% になる時間。

**計算**: KM 曲線から S(t) ≤ 0.5 となる最初の時点。

**解釈**: 患者の 50% が生存する時間の目安。

## 9.16 メタアナリシス 詳細

### 9.16.1 Inverse Variance 法（固定効果モデル）

**用途**: 各研究の効果を分散の逆数で重み付けして統合。

**数式**:
```
wᵢ = 1/vᵢ  (vᵢ = 各研究の分散)
μ_FE = Σwᵢyᵢ / Σwᵢ
SE(μ) = 1/√Σwᵢ
```

**95% CI**: μ ± 1.96 × SE(μ)

**前提**: 全研究が同じ真の効果を推定（異質性なし）。

**用途**: 均一なデータの統合。

### 9.16.2 DerSimonian-Laird（ランダム効果モデル）

**用途**: 研究間の異質性を考慮した統合。

**数式**:
```
τ² = max(0, (Q - df) / (Σwᵢ - Σwᵢ²/Σwᵢ))
wᵢ' = 1/(vᵢ + τ²)
μ_RE = Σwᵢ'yᵢ / Σwᵢ'
```

**用途**: 研究間で効果が異なる可能性がある場合。

**比較**:
| モデル | 仮定 | 用途 |
|---|---|---|
| 固定効果 (FE) | 同じ真の効果 | 均一データ |
| ランダム効果 (RE) | 効果が分布 | 異質なデータ |

**推奨**: 異質性 I² > 50% なら RE を選ぶ。

### 9.16.3 Forest Plot（森林プロット）

**用途**: 各研究と統合結果の視覚化。

**表示**:
```
S1   ●─         (効果量 + 95% CI)
S2    ─●─
S3     ●─
────────────────
Pool   ◆        (統合効果)
```

**読み方**:
- 各研究の点: 効果量の推定値
- 横線: 95% CI
- 菱形: 統合効果と CI
- 縦線: 効果なし (OR=1)

### 9.16.4 Funnel Plot（ファンネルプロット）

**用途**: 出版バイアスのチェック。

**表示**: X 軸に効果量、Y 軸に標準誤差。

**解釈**:
- 左右対称: 出版バイアスなし
- 非対称: 出版バイアス疑い

**理論**: 効果量が同じ研究は標準誤差の逆数でばらつくため、ファンネル状になる。

### 9.16.5 Egger's Test（エガー検定）

**用途**: 出版バイアスの統計的検定。

**数式**:
```
yᵢ/seᵢ = a + b × (1/seᵢ)   （回帰）
H₀: a = 0（切片ゼロ）
```

**解釈**: 切片の p < 0.05 で出版バイアス疑い。

**前提**: K ≥ 3 研究必要。

## 9.17 統計グラフ 17 種 詳細

### 9.17.1 ヒストグラム（Histogram）

**用途**: データの分布形状を可視化。

**操作**: List 選択 → bins 指定（2〜50）。

**表示**: 度数分布の棒グラフ。

**用途例**: 身長の分布、テスト点の分布。

### 9.17.2 箱ひげ図（Box-and-Whisker）

**用途**: 中央値・四分位数・外れ値の可視化。

**表示**: 箱（Q1〜Q3）+ 中央値線 + ひげ（1.5 IQR）+ 外れ値点。

**用途例**: 複数群の分布比較、外れ値検出。

### 9.17.3 散布図（Scatter）

**用途**: 2 変数の関係の可視化。

**操作**: X list → Y list → （オプション）回帰直線重ね描き。

**用途例**: 身長 vs 体重、気温 vs 売上。

### 9.17.4 Q-Q プロット

**用途**: データが正規分布に従うかの視覚的確認。

**表示**: X 軸に理論分位点（標準正規）、Y 軸に観測値。

**解釈**: 点が直線上 → 正規分布、曲がる → 非正規。

**用途例**: t 検定の前提チェック。

### 9.17.5 棒グラフ（Bar chart）

**用途**: カテゴリ別の値の比較。

**表示**: 各カテゴリの値を棒で表示。

**用途例**: 月別売上、地域別人口。

### 9.17.6 円グラフ（Pie chart）

**用途**: 構成比の可視化。

**表示**: 各カテゴリを扇形で表示。

**用途例**: 支出内訳、市場シェア。

**注意**: 7 カテゴリ以上は見にくい、棒グラフ推奨。

### 9.17.7 折れ線グラフ（Line chart）

**用途**: 時系列データの可視化。

**表示**: データ点を順に結ぶ折れ線。

**用途例**: 株価推移、気温変化。

### 9.17.8 茎葉図（Stem-and-Leaf）

**用途**: 分布を数値のまま表示。

**表示**: 十の位を茎、一の位を葉として並べる。

**例**:
```
1 | 2 3 5
2 | 0 1 4
3 | 7 9
```

**用途例**: 少データの分布確認、元データを保ちたい場合。

### 9.17.9 パレート図（Pareto chart）

**用途**: 問題の優先順位付け（80/20 の法則）。

**表示**: 棒グラフ（頻度降順）+ 累積パーセント折れ線。

**用途例**: 品質管理の不良原因分析。

### 9.17.10 ECDF（経験累積分布関数）

**用途**: 累積分布の可視化。

**表示**: 各データ点で 1/n ずつ増える階段関数。

**用途例**: 分布の比較、中央値の視覚的読み取り。

### 9.17.11 KDE（カーネル密度推定）

**用途**: ヒストグラムのスムーズ版（連続密度関数）。

**数式**:
```
f̂(x) = (1/(nh)) × Σ K((x-xᵢ)/h)
h = 1.06 × s × n^(-0.2)  (Silverman's rule)
```

**用途例**: 分布の形状を滑らかに見たい場合。

### 9.17.12 ストリップ図（Strip chart）

**用途**: 1 次元データの散布図（jitter 付き）。

**表示**: 各データ点を縦方向にランダム jitter させて重なりを防ぐ。

**用途例**: 少データの分布確認、個別値の可視化。

### 9.17.13 累積和（Cumulative）

**用途**: データの累積和を可視化。

**用途例**: 累積売上、累積利益。

### 9.17.14 平均 ± SD プロット

**用途**: 複数群の平均と標準偏差を同時表示。

**表示**: 各群の平均点 + エラーバー（± SD）。

**用途例**: 群間比較の概要把握。

### 9.17.15 残差プロット

**用途**: 回帰モデルの当てはまりの確認。

**表示**: X 軸に予測値（または X）、Y 軸に残差。

**解釈**: ランダムに散らばる → 良好、パターンあり → モデル不適切。

**用途例**: 線形回帰の仮定チェック。

### 9.17.16 P-P プロット

**用途**: 累積分布の一致度を可視化（Q-Q の別版）。

**表示**: X 軸に理論 CDF、Y 軸に経験 CDF。

**解釈**: 直線上 → 適合、曲がる → 不適合。

### 9.17.17 複数系列折れ線（Multi-line）

**用途**: 複数リストの折れ線を重ねて表示。

**用途例**: 複数銘柄の株価推移、複数群の時系列比較。

## 9.18 この章のまとめ

- ノンパラメトリック検定 7 種（Mann-Whitney, Wilcoxon, Kruskal-Wallis, Friedman, Sign, Spearman, Kendall）
- リスク指標 5 種（OR, RR, RD, NNT, CI）
- 確率分布 7 種（正規, t, χ², F, 二項, ポアソン, 幾何）
- 多変量解析 5 種（PCA, 因子分析, k-means, 階層クラスタ, 決定木）
- 層別解析 5 種（MH-OR, MH-RR, Breslow-Day, Cochran's Q, 食中毒追跡）
- 生存分析 4 種（KM, Log-rank, Cox PH, Median）
- メタアナリシス 5 種（IV, DL, Forest, Funnel, Egger）
- 統計グラフ 17 種

### 各手法の使い分け

| 目的 | 推奨手法 |
|---|---|
| 2 群比較（正規性なし） | Mann-Whitney U |
| 3 群以上（正規性なし） | Kruskal-Wallis |
| 対応あり（正規性なし） | Wilcoxon |
| リスク要因の評価 | OR, RR |
| 治療効果の実感 | NNT |
| 多次元データの要約 | PCA |
| 類似データのグループ化 | k-means |
| 時間とイベント | KM, Cox PH |
| 複数研究の統合 | メタアナリシス |

### 確認問題

Q9-8: Mann-Whitney U 検定と t 検定の使い分けは？ → 正規性があれば t、なければ U

Q9-9: I² = 75% はどう判断する？ → 異質性が高い → ランダム効果モデル推奨

Q9-10: Cox 回帰の HR = 0.7 の解釈は？ → ハザードが 30% 減少

Q9-11: NNT = 10 の意味は？ → 10 人治療で 1 人救える

Q9-12: PCA の寄与率 60% の意味は？ → その主成分が全体の 60% の情報を説明

Q9-13: メタアナリシスで Forest plot は何を可視化する？ → 各研究と統合効果の 95% CI
