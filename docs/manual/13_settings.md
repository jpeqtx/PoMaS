## 13.1 設定とは
PoMaS の動作をカスタマイズする項目です。
変更した設定は **NVS（不揮発性ストレージ）** に保存され、再起動後も維持されます。
### アクセス方法
**方法 1**: メインメニュー → `6 Tools` → `5 Settings`
**方法 2**: Calculator 画面で `Fn + 1`
### 設定画面
```
┌─────────────────────────────────┐
│▌Settings                        │
├─────────────────────────────────┤
│1 Angle: DEG/RAD/GRAD            │
│2 Display: Norm/Fix/Sci/Eng      │
│3 Display digits                 │
│4 Save settings now              │
│5 Reset all (clear NVS)          │
│6 Back                           │
└─────────────────────────────────┘
```
---
## 13.2 Angle（角度モード）
三角関数の角度単位を選択。
| モード | 単位 | 1 周 | 用途 |
|---|---|---|---|
| **DEG** | 度数法 | 360° | 日常的（デフォルト） |
| **RAD** | 弧度法 | 2π ≈ 6.28 | 数学・物理 |
| **GRAD** | グラジアン | 400 | 測量 |
### 例: sin(30) の結果
| モード | sin(30) |
|---|---|
| DEG | 0.5 |
| RAD | -0.988 |
| GRAD | 0.454 |
### 切り替え手順
```
[1] Settings → 1 (Angle)
[2] DEG / RAD / GRAD を選択
[3] 変更は即座に反映
```
ヘッダのバッジで現在のモードを確認できます。
---
## 13.3 Display（表示形式）
数値の表示形式を選択。
| 形式 | 例 | 説明 |
|---|---|---|
| **Norm** | 1.23456 | 通常（デフォルト） |
| **Fix** | 1.23 | 固定小数点 |
| **Sci** | 1.23e+00 | 科学表記 |
| **Eng** | 1.23k | 工学表記（3 桁区切り） |
### Norm 1 / Norm 2 の違い
現在のバージョンでは、Display が Norm のとき `Norm 1` / `Norm 2` の
閾値設定があります。
| モード | 小さい数の閾値 | 例（0.005） |
|---|---|---|
| Norm 1 | 0.01 未満で指数表示 | 5e-3 |
| Norm 2 | 1e-9 未満で指数表示 | 0.005 |
---
## 13.4 Display digits（表示桁数）
`3 (Display digits)` で 0〜9 の範囲で設定。
| 桁数 | 例（π） |
|---|---|
| 3 | 3.142 |
| 5 | 3.14159 |
| 7 | 3.1415927 |
| 9 | 3.141592654 |
**クイック操作**:
- `Fn + ,` — 1 桁増やす
- `Fn + /` — 1 桁減らす
---
## 13.5 Save settings now（手動保存）
`4 (Save settings now)` で NVS に即時保存。
**自動保存**:
PoMaS は **60 秒ごと** に自動保存も行いますが、
重要な設定変更後は手動保存を推奨。
---
## 13.6 Reset all（NVS クリア）
`5 (Reset all)` で全設定を初期化。
```
[1] Reset all を選択
[2] "Clear NVS settings?" の確認
[3] Y で実行
→ 全設定がデフォルトに戻る
```
⚠️ **確認必須**
誤って実行すると、以下がすべてリセットされます：
- Angle / Display / 桁数
- Wi-Fi の SSID / Pass
- RPN モード / 分数モード
---
## 13.7 NVS とは
**NVS（Non-Volatile Storage）** は、電源を切っても
データが保持されるストレージ領域です。
### NVS の仕組み
```
[1] 設定変更
[2] NVS に書き込み
[3] 電源 OFF
[4] 電源 ON → NVS から読み込み
[5] 設定が復元される
```
### 保存される項目
| キー | 内容 |
|---|---|
| angle | 角度モード |
| disp | 表示形式 |
| digits | 表示桁数 |
| norm | Norm 1/2 |
| rpn | RPN モード |
| frac | 分数モード |
| wifissid | Wi-Fi SSID |
| wifipass | Wi-Fi Pass |
---
## 13.8 この章のまとめ
- 設定は Tools → 5、または Calculator で Fn+1
- 角度モード（DEG/RAD/GRAD）
- 表示形式（Norm/Fix/Sci/Eng）
- 表示桁数（0〜9）
- NVS に永続化、60 秒ごとに自動保存
- Reset all で全設定クリア
### 確認問題

</details>

<details><summary>答え</summary>
Fn + ,（カンマ）
</details>
📝 **Q13-3**: NVS とは何の略？
<details><summary>答え</summary>
Non-Volatile Storage（不揮発性ストレージ）
</details>
