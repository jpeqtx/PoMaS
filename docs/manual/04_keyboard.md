## 4.1 キーボードの全体像
Cardputer-Adv のキーボードは、ノート PC を小型化したような QWERTY 配列です。
物理キーは約 56 個。1 つのキーに複数の役割を持たせることで、
小さな面積に多くの機能を詰め込んでいます。
### キーの種類
```
┌──────────────────────────────────────────┐
│ 特殊キー   : Enter, Del, Fn, Shift, Esc   │
│ 文字キー   : A〜Z, 0〜9                   │
│ 記号キー   : + - * / ( ) , . ; ' `        │
│ 修飾キー   : Fn, Shift                    │
└──────────────────────────────────────────┘
```
### キーボード配置（概念図）
```
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│  1  │  2  │  3  │  4  │  5  │  6  │  7  │  8  │  9  │  0  │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  Q  │  W  │  E  │  R  │  T  │  Y  │  U  │  I  │  O  │  P  │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  A  │  S  │  D  │  F  │  G  │  H  │  J  │  K  │  L  │Enter│
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  Z  │  X  │  C  │  V  │  B  │  N  │  M  │  ,  │  .  │ Del │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│ Fn  │Shift│  ;  │  /  │  `  │Space│ ... │     │     │     │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```
💡 実際のキー配置は個体差があるため、本書では「キーの機能」を中心に解説します。

## 4.2 特殊キー
### Enter（エンター）
**役割**: 決定・実行
| 場面 | 動作 |
|---|---|
| メニュー | 選択中の項目を決定 |
| 数式入力 | 式を評価（計算実行） |
| 入力ダイアログ | 入力を確定 |
| 確認ダイアログ | （Enter は無効。Y/N キーを使用） |
💡 **Enter を押すタイミング**
数式を入力し終えてから Enter。途中で Enter を押すと、
その時点までの式が評価されます。
### Del（デリート）
**役割**: 1 文字削除
| 場面 | 動作 |
|---|---|
| 数式入力 | カーソル位置の 1 文字前を削除 |
| 入力ダイアログ | 同上 |
| メニュー | （無効） |
| リスト編集 | 選択中の要素を削除（確認あり） |
💡 **一気に消すには**
`Fn + Esc` で入力をキャンセルし、最初からやり直すのが早いです。
### Fn（ファンクション）
**役割**: 修飾キー。他のキーと組み合わせて特殊機能を呼び出す
Fn は**押しっぱなし**にしたまま、別のキーを押します。
```
Fn を押しながら 1 を押す → 設定画面
Fn を押しながら Esc を押す → 前の画面に戻る
```
### Shift（シフト）
**役割**: 修飾キー。大文字・記号入力
| 組み合わせ | 入力 |
|---|---|
| Shift + a | `A` |
| Shift + 1 | `!`（記号キーの場合） |
⚠️ **Shift の扱いは要注意**
Cardputer-Adv の Shift は、シンボル入力の優先度が高く、
小文字が入力できない場合があります。本書では小文字入力は
通常の文字キー単独押しを推奨します。
### Esc（エスケープ）
Cardputer-Adv には **Esc 専用キーがありません**。
バッククォート（`` ` ``）キーが Esc の役割をします。
| キー | 役割 |
|---|---|
| `` ` `` 単独 | 前の画面に戻る / 入力をキャンセル |
| `Fn + ` `` | 同上（確実に動作） |
💡 **Esc は「戻る」の共通キー**
どの画面でも `Fn + ` `` で 1 階層戻れます。

## 4.3 文字キー
### 数字キー（0〜9）
**役割**: 数字の入力
| キー | 入力される文字 |
|---|---|
| 0 | `0` |
| 1 | `1` |
| ... | ... |
| 9 | `9` |
**メニューでの役割**
数字キーは、メニュー項目の**直接ジャンプ**にも使えます。
```
メインメニューで 3 を押す → Statistics モードへ
Statistics サブメニューで 2 を押す → Regression へ
```
💡 **9 を超える項目**
10 番目以降の項目は、数字キーでは直接選べません。
`;` `.` で移動して `Enter` します。
### アルファベットキー（A〜Z）
**役割**: 文字の入力
**変数名として**: 大文字 A〜J は変数として使えます。
```
Calculator で A を入力 → 変数 A の値を参照
```
**関数名の一部として**: 小文字と組み合わせて関数名になります。
```
sin, cos, tan, sqrt, log, ...
```
⚠️ **予約された文字**
以下の文字は数式内で特別な意味を持ちます。
| 文字 | 意味 |
|---|---|
| `e` | オイラー数（2.718...） |
| `E` | 変数 E または `1E5` のような指数表記 |
| `pi` | 円周率 |
| `x` | グラフの変数（未定義時は 0） |
| `t` | パラメトリックの媒介変数 |
| `n` | 数列の添字 |

## 4.4 記号キー
### 演算子キー
| キー | 入力 | 意味 |
|---|---|---|
| `+` | `+` | 足し算 |
| `-` | `-` | 引き算 / 負号 |
| `*` | `*` | 掛け算 |
| `/` | `/` | 割り算 |
| `^` | `^` | べき乗 |
💡 **× と ÷ は使えません**
数式内では `*` と `/` を使います。
`3 × 4` ではなく `3 * 4` と入力してください。
### 括弧
| キー | 入力 |
|---|---|
| `(` | 開き括弧 |
| `)` | 閉じ括弧 |
⚠️ **括弧の対応**
開いた括弧と閉じる括弧の数が合わないと、
「`)` expected」エラーが出ます。
### カンマ・ピリオド・セミコロン
| キー | 入力 | 主な用途 |
|---|---|---|
| `,` | `,` | 関数の引数区切り |
| `.` | `.` | 小数点 |
| `;` | `;` | パラメトリックの区切り |
**関数の引数**
```
nCr(5, 2)  → 5 個から 2 個選ぶ組合せ
gcd(12, 18) → 12 と 18 の最大公約数
```
**パラメトリックグラフ**
```
cos(t);sin(t)  → 円の軌跡
```
### 矢印キー（代用）
Cardputer-Adv には矢印キーがありません。
以下のキーが矢印の役割をします。
| キー | 役割 |
|---|---|
| `;` | 上 |
| `.` | 下 |
| `,` | 左 |
| `/` | 右 |
💡 **Fn と組み合わせて矢印として使う**
`Fn + ;`（上）、`Fn + .`（下）などの組み合わせでも同じ動作をします。

Fn を押しながら他のキーを押すと、特殊機能が呼ばれます。
以下は主要な組み合わせです。

## 4.6 日本語入力について
### 日本語は入力できません
PoMaS の数式入力では、**日本語文字は入力できません**。
英数字・記号のみ使用します。
### 日本語表示は可能
画面に日本語を表示することはできます。
- メニュー項目（一部）
- 通知メッセージ（一部）
- 統計のリスト名（英語推奨）
⚠️ **ファイル名やパス**
SD カードに保存するファイル名は、英数字推奨です。
日本語ファイル名は文字化けの原因になります。

## 4.7 キー入力のコツ
### 長い数式を入力するとき
1. 括弧を先に書く: `()` と入力してから中身を埋める
2. 演算子の優先順位を意識: `2+3*4` は `2+(3*4)`
3. 途中経過を確認: 各部分を Enter で評価して Ans を確認
### 誤入力を減らすには
| コツ | 例 |
|---|---|
| 括弧を先に | `sin()` → `sin(30)` |
| 短く区切る | `2+3` → Enter → Ans を使う |
| Del で修正 | 1 文字ずつ戻る |
### よくある入力ミス
| ミス | 症状 | 対処 |
|---|---|---|
| 括弧の閉じ忘れ | `) expected` | `)` を追加 |
| 掛け算を `×` で入力 | エラー or 意図しない結果 | `*` に修正 |
| 全角数字 | 認識されない | 半角で入力 |
| 大文字小文字の混同 | `unbound symbol` | 関数名は小文字 |

## 4.8 特殊な入力
### 16 進数・2 進数・8 進数の入力
Calculator では、基数変換メニュー（Fn+5）を使うと、
16 進数などを直接入力できます。
| 形式 | 例 |
|---|---|
| 16 進数 | `0xFF`（255） |
| 2 進数 | `0b1010`（10） |
| 8 進数 | `0o777`（511） |
💡 **ビット演算（Fn+6）でも使えます**
`0xFF AND 0x0F` のような式が入力できます。
### 指数表記
大きな数字や小さな数字を短く書けます。
| 入力 | 意味 |
|---|---|
| `1E5` | 1 × 10^5 = 100000 |
| `1.5E-3` | 1.5 × 10^-3 = 0.0015 |
### 定数の入力
| 入力 | 値 |
|---|---|
| `pi` | 3.14159... |
| `e` | 2.71828... |
| `euler` | 2.71828... |
| `phi` | 1.61803... |
| `gamma` | 0.57721... |

## 4.12 Shift キーの詳細

### 4.12.1 Shift の機能

- 大文字入力（a → A）
- 記号のシフト（数字キーの記号など）
- Aa モード切替

### 4.12.2 Shift の問題点

Cardputer-Adv の Shift はシンボル入力優先度が高く、小文字が入力できない場合があります。

**推奨**: 小文字入力は **通常の文字キー単独押し** を使う。

### 4.12.3 Aa モード（該当機種）

一部の Cardputer では `Aa` キーで大文字/小文字を切り替えできます。PoMaS は Aa モードの有無に関わらず動作しますが、`-`/`_` の扱いに注意。

### 4.12.4 Caps Lock の代替

専用の Caps Lock キーはありません。Shift + 文字で 1 文字ずつ大文字入力。

## 4.13 キーボードショートカットのコツ

### 4.13.1 Fn 押しっぱなし

Fn は押しっぱなしにしたまま、別のキーを押します:
```
[1] Fn を押す
[2] Fn を離さずに 1 を押す
[3] 両方離す → Fn+1 が発動
```

**注意**: Fn を離してから 1 を押すと、単なる "1" 入力になります。

### 4.13.2 同時押しのタイミング

- Fn 押下 → 200ms 以内に他キー → ショートカット発動
- 200ms 超えると Fn 単独として扱われ、他キーは独立入力

### 4.13.3 誤入力の防止

- Fn と他キーの間に別キーを挟まない
- 入力中は Fn を使わない（誤発動の原因）
- ESC のみ単独押し

## 4.14 キーボードのトラブルシューティング

### 4.14.1 キーが反応しない

| 症状 | 原因 | 対処 |
|---|---|---|
| 全キー無反応 | 減光中 | 任意キー押下 |
| 特定キーのみ | 接触不良 | キー押し直し |
| Fn 効かない | 押し方誤り | 押しっぱなし |
| ESC 効かない | fn+ESC でない | ESC 単独 |

### 4.14.2 入力がおかしい

| 症状 | 原因 | 対処 |
|---|---|---|
| 文字化け | 全角入力 | 半角で再入力 |
| 記号が違う | キーキャップと実装のずれ | `-`/`_` は PoMaS 側で対応済 |
| 数字が入らない | NumLock 状態 | 該当キーは数字のみ |
| 小文字が入らない | Shift 問題 | 通常の文字キー単独 |

### 4.14.3 キーリピート

- `Fn+矢印`、`Del` は押しっぱなしで連続動作
- 初回遅延: 400ms
- リピート間隔: 70ms

**注意**: 数字キー・文字キーはリピートしません（誤入力防止）。

## 4.15 キーボードマトリックスの制約

### 4.15.1 同時押しの制限

Cardputer-Adv のキーボードは TCA8418 で **同時押し 3 キーまで** サポート。4 キー以上は認識しない場合があります。

**影響例**:
- Shift + Fn + 数字 = OK
- Shift + Fn + Alt + 数字 = NG（Alt なし）

### 4.15.2 キーロールオーバー

**2-key rollover**: 2 キーまでの同時押しは確実。
**N-key rollover**: 非対応（特殊な入力パターンで取りこぼし）。

### 4.15.3 キーボードのレスポンス

- スキャンレート: 約 50 Hz（20ms 間隔）
- 押下→認識: 20ms 以内
- 連続押し（チャタリング対策）: デバウンス済

## 4.16 言語・文字コード

### 4.16.1 入力可能な文字

- ASCII 印字可能文字（0x20-0x7E）
- 制御文字は不可

### 4.16.2 日本語入力

- **不可**: 数式入力、変数名、関数名
- **可能**: Notify メッセージ表示（内部埋め込み）
- **推奨**: 英数字のみ

### 4.16.3 ファイル名の推奨

- 英数字・アンダースコア・ハイフン
- 8.3 形式（8 文字.3 拡張子）を推奨
- 日本語ファイル名は文字化け

## 4.17 キーボードのカスタマイズ

### 4.17.1 キーアサインの変更

PoMaS のキーアサインは `DisplayMgr::pollKeys` と各モードの `run()` 内で定義されています。変更するにはソースコード改変が必要。

### 4.17.2 カスタムショートカットの例

```
// CalculatorCore::run() 内
if (st.fn && M5Cardputer.Keyboard.isKeyPressed('x')) {
    // 独自の機能
    DM.notify("Custom shortcut", C_OK);
    continue;
}
```

## 4.18 この章のまとめ

- 完全キーリファレンス: 数字・文字・記号・特殊キー
- Fn 組み合わせ: 全 20 以上のショートカット
- 代替キー: `;` `.` `,` `/` が矢印の代用
- Shift はシンボル優先、小文字は文字キー単独
- Fn 押しっぱなし + 他キーでショートカット
- キーリピート: Fn+矢印、Del のみ
- 同時押し 3 キーまで
- 日本語入力不可、英数字のみ
- カスタマイズはソースコード改変
