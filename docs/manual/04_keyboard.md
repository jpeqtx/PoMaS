## 4.1 キーボードの全体像

Cardputer-Adv のキーボードは、ノート PC を小型化したような QWERTY 配列です。
物理キーは約 56 個。1 つのキーに複数の役割を持たせることで、
小さな面積に多くの機能を詰め込んでいます。

### キーの種類

```
┌──────────────────────────────────────────┐
│ 特殊キー   : Enter, Del, Fn, Shift, Esc   │
│ 文字キー   : A〜Z, 0〜9                   │
│ 記号キー   : + - * / ( ) , . ; ' `        │
│ 修飾キー   : Fn, Shift                    │
└──────────────────────────────────────────┘
```

### キーボード配置（概念図）

```
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│  1  │  2  │  3  │  4  │  5  │  6  │  7  │  8  │  9  │  0  │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  Q  │  W  │  E  │  R  │  T  │  Y  │  U  │  I  │  O  │  P  │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  A  │  S  │  D  │  F  │  G  │  H  │  J  │  K  │  L  │Enter│
```

💡 実際のキー配置は個体差があるため、本書では「キーの機能」を中心に解説します。

## 4.2 特殊キー

### Enter（エンター）

**役割**: 決定・実行

| 場面 | 動作 |
|---|---|
| メニュー | 選択中の項目を決定 |
| 数式入力 | 式を評価（計算実行） |
| 入力ダイアログ | 入力を確定 |
| 確認ダイアログ | （Enter は無効。Y/N キーを使用） |

💡 **Enter を押すタイミング**
数式を入力し終えてから Enter。途中で Enter を押すと、
その時点までの式が評価されます。

### Del（デリート）

**役割**: 1 文字削除

| 場面 | 動作 |
|---|---|
| 数式入力 | カーソル位置の 1 文字前を削除 |
| 入力ダイアログ | 同上 |
| メニュー | （無効） |
| リスト編集 | 選択中の要素を削除（確認あり） |

💡 **一気に消すには**
`Fn + Esc` で入力をキャンセルし、最初からやり直すのが早いです。

### Fn（ファンクション）

**役割**: 修飾キー。他のキーと組み合わせて特殊機能を呼び出す

Fn は**押しっぱなし**にしたまま、別のキーを押します。

```
Fn を押しながら 1 を押す → 設定画面
Fn を押しながら Esc を押す → 前の画面に戻る
```

### Shift（シフト）

**役割**: 修飾キー。大文字・記号入力

| 組み合わせ | 入力 |
|---|---|
| Shift + a | `A` |
| Shift + 1 | `!`（記号キーの場合） |

⚠️ **Shift の扱いは要注意**
Cardputer-Adv の Shift は、シンボル入力の優先度が高く、
小文字が入力できない場合があります。本書では小文字入力は
通常の文字キー単独押しを推奨します。

### Esc（エスケープ）

Cardputer-Adv には **Esc 専用キーがありません**。
バッククォート（`` ` ``）キーが Esc の役割をします。

| キー | 役割 |
|---|---|
| `` ` `` 単独 | 前の画面に戻る / 入力をキャンセル |
| `Fn + ` `` | 同上（確実に動作） |

💡 **Esc は「戻る」の共通キー**
どの画面でも `Fn + ` `` で 1 階層戻れます。

## 4.3 文字キー

### 数字キー（0〜9）

**役割**: 数字の入力

| キー | 入力される文字 |
|---|---|
| 0 | `0` |
| 1 | `1` |
| ... | ... |
| 9 | `9` |

**メニューでの役割**

数字キーは、メニュー項目の**直接ジャンプ**にも使えます。

```
メインメニューで 3 を押す → Statistics モードへ
Statistics サブメニューで 2 を押す → Regression へ
```

💡 **9 を超える項目**
10 番目以降の項目は、数字キーでは直接選べません。
`;` `.` で移動して `Enter` します。

### アルファベットキー（A〜Z）

**役割**: 文字の入力

**変数名として**: 大文字 A〜J は変数として使えます。

```
Calculator で A を入力 → 変数 A の値を参照
```

**関数名の一部として**: 小文字と組み合わせて関数名になります。

```
sin, cos, tan, sqrt, log, ...
```

⚠️ **予約された文字**
以下の文字は数式内で特別な意味を持ちます。

| 文字 | 意味 |
|---|---|
| `e` | オイラー数（2.718...） |
| `E` | 変数 E または `1E5` のような指数表記 |
| `pi` | 円周率 |
| `x` | グラフの変数（未定義時は 0） |
| `t` | パラメトリックの媒介変数 |
| `n` | 数列の添字 |

## 4.4 記号キー

### 演算子キー

| キー | 入力 | 意味 |
|---|---|---|
| `+` | `+` | 足し算 |
| `-` | `-` | 引き算 / 負号 |
| `*` | `*` | 掛け算 |
| `/` | `/` | 割り算 |
| `^` | `^` | べき乗 |

💡 **× と ÷ は使えません**
数式内では `*` と `/` を使います。
`3 × 4` ではなく `3 * 4` と入力してください。

### 括弧

| キー | 入力 |
|---|---|
| `(` | 開き括弧 |
| `)` | 閉じ括弧 |

⚠️ **括弧の対応**
開いた括弧と閉じる括弧の数が合わないと、
「`)` expected」エラーが出ます。

### カンマ・ピリオド・セミコロン

| キー | 入力 | 主な用途 |
|---|---|---|
| `,` | `,` | 関数の引数区切り |
| `.` | `.` | 小数点 |
| `;` | `;` | パラメトリックの区切り |

**関数の引数**

```
nCr(5, 2)  → 5 個から 2 個選ぶ組合せ
gcd(12, 18) → 12 と 18 の最大公約数
```

**パラメトリックグラフ**

```
cos(t);sin(t)  → 円の軌跡
```

### 矢印キー（代用）

Cardputer-Adv には矢印キーがありません。
以下のキーが矢印の役割をします。

| キー | 役割 |
|---|---|
| `;` | 上 |
| `.` | 下 |
| `,` | 左 |
| `/` | 右 |

💡 **Fn と組み合わせて矢印として使う**
`Fn + ;`（上）、`Fn + .`（下）などの組み合わせでも同じ動作をします。

## 4.5 Fn キー組み合わせ一覧

Fn を押しながら他のキーを押すと、特殊機能が呼ばれます。
以下は主要な組み合わせです。

### Calculator モードの Fn 組み合わせ

| 組み合わせ | 機能 |
|---|---|
| `Fn + 1` | 設定画面 |
| `Fn + 2` | 履歴呼び出し |
| `Fn + 3` | メモリ M |
| `Fn + 4` | 変数 A〜J |
| `Fn + 5` | 基数変換 |
| `Fn + 6` | ビット演算 |
| `Fn + 7` | 複素数 |
| `Fn + 8` | 拡張ツール |
| `Fn + 9` | RPN モード切替 |
| `Fn + 0` | ヘルプ |
| `Fn + =` | 分数 ⇄ 小数 |
| `Fn + a` | Ans を式に挿入 |
| `Fn + b` | Ans バンク |
| `Fn + ,` | 表示桁数を増やす |
| `Fn + /` | 表示桁数を減らす |
| `Fn + Esc` | メインメニューへ戻る |

### グラフモードの Fn 組み合わせ

| 組み合わせ | 機能 |
|---|---|
| `Fn + ;` | トレースカーソル上 |
| `Fn + .` | トレースカーソル下 |
| `Fn + ,` | トレースカーソル左 |
| `Fn + /` | トレースカーソル右 |
| `Fn + Esc` | グラフメニューへ戻る |

### 全モード共通

| 組み合わせ | 機能 |
|---|---|
| `Fn + Esc` | 前の画面に戻る |

## 4.6 日本語入力について

### 日本語は入力できません

PoMaS の数式入力では、**日本語文字は入力できません**。
英数字・記号のみ使用します。

### 日本語表示は可能

画面に日本語を表示することはできます。
- メニュー項目（一部）
- 通知メッセージ（一部）
- 統計のリスト名（英語推奨）

⚠️ **ファイル名やパス**
SD カードに保存するファイル名は、英数字推奨です。
日本語ファイル名は文字化けの原因になります。

## 4.7 キー入力のコツ

### 長い数式を入力するとき

1. 括弧を先に書く: `()` と入力してから中身を埋める
2. 演算子の優先順位を意識: `2+3*4` は `2+(3*4)`
3. 途中経過を確認: 各部分を Enter で評価して Ans を確認

### 誤入力を減らすには

| コツ | 例 |
|---|---|
| 括弧を先に | `sin()` → `sin(30)` |
| 短く区切る | `2+3` → Enter → Ans を使う |
| Del で修正 | 1 文字ずつ戻る |

### よくある入力ミス

| ミス | 症状 | 対処 |
|---|---|---|
| 括弧の閉じ忘れ | `) expected` | `)` を追加 |
| 掛け算を `×` で入力 | エラー or 意図しない結果 | `*` に修正 |
| 全角数字 | 認識されない | 半角で入力 |
| 大文字小文字の混同 | `unbound symbol` | 関数名は小文字 |

## 4.8 特殊な入力

### 16 進数・2 進数・8 進数の入力

Calculator では、基数変換メニュー（Fn+5）を使うと、
16 進数などを直接入力できます。

| 形式 | 例 |
|---|---|
| 16 進数 | `0xFF`（255） |
| 2 進数 | `0b1010`（10） |
| 8 進数 | `0o777`（511） |

💡 **ビット演算（Fn+6）でも使えます**
`0xFF AND 0x0F` のような式が入力できます。

### 指数表記

大きな数字や小さな数字を短く書けます。

| 入力 | 意味 |
|---|---|
| `1E5` | 1 × 10^5 = 100000 |
| `1.5E-3` | 1.5 × 10^-3 = 0.0015 |

### 定数の入力

| 入力 | 値 |
|---|---|
| `pi` | 3.14159... |
| `e` | 2.71828... |
| `euler` | 2.71828... |
| `phi` | 1.61803... |
| `gamma` | 0.57721... |

## 4.9 この章のまとめ

- Cardputer-Adv は約 56 キー。ノート PC を小型化した QWERTY 配列
- Enter: 決定・実行、Del: 1 文字削除、Fn: 修飾キー
- Esc はバッククォート（`` ` ``）キー
- `;` `.` `,` `/` が矢印キーの代用
- Fn + 数字で各種ショートカット
- 日本語入力は不可、英数字のみ
- 16 進数は `0x`, 2 進数は `0b`, 8 進数は `0o` の接頭辞

### 確認問題

📝 **Q4-1**: Esc キーはどこにありますか？
<details><summary>答え</summary>
バッククォート（`` ` ``）キーが Esc の役割をします。
`Fn + ` `` の組み合わせが確実です。
</details>

📝 **Q4-2**: メニューの 5 番目の項目を直接選ぶには？
<details><summary>答え</summary>
`5` キーを押します。
</details>

📝 **Q4-3**: `2 × 3` を計算するにはどう入力しますか？
<details><summary>答え</summary>
`2*3` と入力します。`×` 記号は使いません。
</details>

📝 **Q4-4**: 16 進数の 255 を入力するには？
<details><summary>答え</summary>
`0xFF` と入力します。
</details>

📝 **Q4-5**: Calculator モードで履歴を開くショートカットは？
<details><summary>答え</summary>
`Fn + 2`
</details>
