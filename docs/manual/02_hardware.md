## 2.1 Cardputer-Adv とは
PoMaS が動作する **M5Stack Cardputer-Adv** は、
M5Stack 社が販売する手のひらサイズのコンピュータです。
### 主な仕様
| 項目 | 値 |
|---|---|
| CPU | ESP32-S3（デュアルコア 240MHz） |
| Flash メモリ | 8 MB |
| RAM | 512 KB + PSRAM なし |
| 画面 | 240 × 135 ピクセル カラー液晶 |
| キーボード | 物理キーボード（約 56 キー） |
| スピーカー | 内蔵 |
| マイク | 内蔵 |
| SD カード | microSD 対応 |
| Wi-Fi | 2.4GHz 帯 |
| Bluetooth | 対応 |
| バッテリー | 内蔵リチウムイオン電池 |
| サイズ | 約 85 × 55 × 15 mm |
| 重量 | 約 70 g |
**ESP32-S3 とは**
Espressif 社のマイコン（マイクロコントローラ）です。
Wi-Fi と Bluetooth を内蔵し、比較的高速な処理が可能です。

### 主なボタン・端子
| 部位 | 機能 |
|---|---|
| **電源ボタン** | 長押しで ON/OFF |
| **リセットボタン** | 押すと再起動（G0 ボタン兼用） |
| **G0 ボタン** | リセット横の小さなボタン。書き込み時に使用 |
| **USB-C 端子** | 充電・書き込み・シリアル通信 |
| **microSD スロット** | SD カード挿入 |
**G0 ボタンの使い方**
ファームウェアを書き込む際、`Connecting...` で止まる場合は、
G0 ボタンを押しながらリセットボタンを押します。
これでダウンロードモードに入ります。

### M5Stack Launcher によるマルチブート

**M5Stack Launcher** は、サードパーティ製のマルチブートファームウェアです。一度書き込めば、SDカードに複数の`.bin`ファイルを置き、起動時に選択して切り替えられるようになります。

| 項目 | 内容 |
|---|---|
| 公式リポジトリ | https://github.com/bmorcelli/Launcher |
| 対応デバイス | Cardputer / Cardputer-Adv |
| 必要なもの | microSDカード（FAT32、32GB以下推奨） |

#### インストール手順

1. [Releases](https://github.com/bmorcelli/Launcher/releases) から `Launcher-Cardputer.bin` をダウンロード
2. M5Burner または esptool で Launcher を本体に書き込む
3. PoMaSの`.bin`ファイルをSDカードにコピー
4. 電源ON → Launcher画面で `Enter` → SDカード内の`.bin`を選択

#### 注意点

- Launcherを書き込むと、それまでのファームウェアは上書きされます
- Launcher経由でインストールしたファームウェアは、起動時に何も押さなければ自動起動します
- Launcherに戻るには、起動時に `Enter` を押します


## 2.3 電源の入れ方
### 初回起動
1. **USB-C ケーブルで充電**（最初は充電が必要）
2. **電源ボタンを 2 秒以上長押し**
3. 画面に PoMaS のスプラッシュが表示される
4. 約 2.5 秒後、メインメニューが表示される
### 電源の切り方
1. **電源ボタンを 2 秒以上長押し**
2. 画面が暗くなり、電源が切れる
**注意**
- 使用中に電源ボタンを長押しすると、強制終了になります
- データは保存されていない場合があります
- 通常の終了は、メインメニューに戻ってから行ってください
### スリープモード
操作しない状態が **10 分間** 続くと、自動的に電源が切れます
（PoMaS v0.92 の仕様）。
**スリープを防ぐには**
定期的に何かのキーを押してください。
スリープまでの時間は、v0.93 で設定可能になる予定です。

## 2.4 充電
### 充電方法
1. USB-C ケーブルを PC または USB 充電器に接続
2. Cardputer-Adv の USB-C 端子に接続
3. 画面右上に充電アイコンが表示される
### 充電時間
- 空の状態から満充電まで: **約 1.5 〜 2 時間**
- 連続使用時間: **約 4 〜 6 時間**（使い方による）
### バッテリー残量の確認
メインメニュー → **Tools** → **Power / About** で確認できます。
```
Battery: 78% (charging)
PSRAM: none (normal)
SD: OK (16384MB)
Wi-Fi: off
Free heap: 125 KB
```

## 2.5 SD カード
### SD カードの役割
PoMaS では、以下の機能で SD カードを使用します。
| 機能 | 用途 |
|---|---|
| CSV ストリーム統計 | データの読み込み |
| Spreadsheet | データの保存 / 読み込み |
| μLisp | スクリプトの保存 / 読み込み |
| BMP 保存 | スクリーンショット |
### SD カードの仕様
| 項目 | 推奨 |
|---|---|
| 容量 | **32GB 以下**（64GB 以上は不安定） |
| フォーマット | **FAT32**（exFAT 不可） |
| 速度 | Class 10 以上推奨 |
### SD カードの挿入
1. Cardputer-Adv の電源を切る（推奨）
2. 側面の microSD スロットに挿入
3. 「カチッ」と音がするまで押し込む
4. 電源を入れる
5. 起動メッセージに `[SD] OK` が表示されれば成功
### SD カードが認識されない場合
**症状**: `SD: NOT detected` と表示される
**対処**:
1. `Tools → Power → R` でリトライ
2. 一度 SD カードを抜き差しする
3. 別の SD カードで試す
4. SD カードを PC で FAT32 フォーマット
**注意**
- NTFS / exFAT では動作しません
- 64GB 以上のカードは認識しない場合があります

## 2.6 画面
### 画面の仕様
| 項目 | 値 |
|---|---|
| サイズ | 2.0 インチ |
| 解像度 | 240 × 135 ピクセル |
| 色数 | 65,536 色（RGB565） |
| 種類 | ST7789V2 カラー液晶 |
### 画面の構成
PoMaS の画面は、3 つの領域に分かれています。
```
┌─────────────────────────────────┐
│ ヘッダ（16px）                  │  ← タイトル・バッジ
├─────────────────────────────────┤
│                                 │
│                                 │
│ ボディ（105px）                 │  ← メインコンテンツ
│                                 │
│                                 │
├─────────────────────────────────┤
│ フッタ（14px）                  │  ← 操作ヒント
└─────────────────────────────────┘
```
- **ヘッダ**: 現在のモード名 + 設定バッジ（DEG/NRM など）
- **ボディ**: メインコンテンツ（メニュー、数式、グラフなど）
- **フッタ**: 操作のヒント（「ENT:OK」「ESC:back」など）
### Paper UI v2 の配色
PoMaS v0.92 では、目に優しい明るい配色を採用しています。
| 色 | 用途 |
|---|---|
| 淡いミント（背景） | 長時間の作業でも疲れにくい |
| グラファイト（文字） | 高コントラストで読みやすい |
| ミントグリーン（アクセント） | 選択中の項目、強調表示 |
**輝度調整について**
現在のバージョンでは輝度調整機能はありません。
v0.93 で追加予定です。

## 2.7 キーボード
### キーボードの概要
Cardputer-Adv には、**約 56 個の物理キー** があります。
QWERTY 配列と、日本語入力用の特殊キーで構成されています。
### 主なキーの種類
| 種類 | 例 | 役割 |
|---|---|---|
| 文字キー | A〜Z, 0〜9 | 文字・数字入力 |
| 記号キー | + - * / ( ) | 演算子・記号 |
| 修飾キー | Fn, Shift | 組み合わせて特殊機能 |
| 特殊キー | Enter, Del, Esc | 確定・削除・取消 |
| 矢印キー | ; . , / | カーソル移動（代用） |
詳細は [第4章 キーボード詳細](04_keyboard.md) で解説します。

## 2.9 GPIO ピン配置

Cardputer-Adv の主要 GPIO は以下の通りです（PoMaS 内部で使用）。

| 機能 | GPIO | 備考 |
|---|---|---|
| SD_CS | 12 | SD カード チップセレクト |
| SD_MOSI | 14 | SPI データ出力 |
| SD_SCK | 40 | SPI クロック |
| SD_MISO | 39 | SPI データ入力 |
| LCD_SCK | 36 | LCD クロック（内部） |
| LCD_MOSI | 35 | LCD データ |
| LCD_CS | 37 | LCD チップセレクト |
| LCD_DC | 34 | LCD データ/コマンド |
| LCD_RST | 33 | LCD リセット |
| LCD_BL | 38 | LCD バックライト |
| Keyboard I2C SDA | 8 | キーボード I2C データ |
| Keyboard I2C SCL | 9 | キーボード I2C クロック |
| Speaker | 41 | 内蔵スピーカー |
| Mic | 46 | 内蔵マイク |
| Battery ADC | 10 | バッテリー残量検出 |
| G0 | 0 | ダウンロードモード |

**注意**: ピン番号は M5Stack 公式仕様に準拠。改変時は M5Cardputer ライブラリの定義を参照してください。

## 2.10 SD カード詳細

### 2.10.1 SD カード初期化の流れ

PoMaS は起動時に以下のリトライを行います:

```
[1] SD.begin(SD_CS, SPI, 4000000)   ; 4MHz
[2] 失敗なら SD.begin(SD_CS, SPI, 10000000)  ; 10MHz
[3] さらに失敗なら SD.begin(SD_CS, SPI, 25000000)  ; 25MHz
[4] 全失敗 → SD: NOT detected 表示
```

### 2.10.2 SD カードのフォーマット

**推奨**:
- ファイルシステム: **FAT32**
- 容量: 32GB 以下
- クラスタサイズ: 32KB 以下

**非対応**:
- exFAT、NTFS
- 64GB 以上（相性問題）
- SDHC 以上の高速カードで相性問題あり

### 2.10.3 SD カードの書き込み速度

| 速度 | 用途 |
|---|---|
| 4MHz (250KB/s) | 小ファイル・BMP 保存 |
| 10MHz (625KB/s) | CSV・スクリプト |
| 25MHz (1.5MB/s) | 大量データ |

### 2.10.4 SD カードが認識されない場合

**症状**: `SD: NOT detected` 表示

**診断フロー**:
1. SD カードを抜き差し
2. `Tools → 4 (Power/About) → R (retry SD)`
3. 別の SD カードで試す
4. PC で FAT32 フォーマット
5. それでも失敗 → SD スロット故障（要修理）

### 2.10.5 ファイルシステムの制約

- ルートディレクトリ直下に保存（サブフォルダ非対応）
- ファイル名は英数字・アンダースコア・ハイフンのみ推奨
- 日本語ファイル名は文字化けの原因

## 2.11 LCD 仕様詳細

### 2.11.1 画面の物理特性

| 項目 | 値 |
|---|---|
| 型番 | ST7789V2 |
| サイズ | 2.0 インチ（対角） |
| 解像度 | 240 × 135 px |
| 視野角 | 約 160° |
| バックライト | 白色 LED |
| 消費電流 | 約 20 mA（最大輝度） |

### 2.11.2 描画領域

```
┌─────────────────────────────────┐  ← y=0
│ ヘッダ (16px)                   │
├─────────────────────────────────┤  ← y=16
│                                 │
│ ボディ (105px)                  │
│                                 │
├─────────────────────────────────┤  ← y=121
│ フッタ (14px)                   │
└─────────────────────────────────┘  ← y=135
```

### 2.11.3 フォント

| フォント | サイズ | 用途 |
|---|---|---|
| Font0 | 6 × 8 px | メニュー・本文 |
| Font2 | 12 × 16 px | 大きな数値表示 |
| Font4 | 24 × 32 px | タイトル |

**文字数制限**:
- Font0: 40 文字/行、16 行
- Font2: 20 文字/行、8 行
- Font4: 10 文字/行、4 行

### 2.11.4 色深度

- RGB565（16 bit、65,536 色）
- 各ピクセル 2 バイト
- 画面バッファサイズ: 240 × 135 × 2 = 64,800 バイト

### 2.11.5 バックライト制御

- PWM 制御で輝度調整可能
- PoMaS v0.92 は **輝度設定未実装**（既定値固定）
- v0.93 で設定追加予定

## 2.12 キーボードマトリックス

### 2.12.1 キーボードコントローラ

- TCA8418（I2C 接続、アドレス 0x34）
- 8 × 10 マトリックス
- 最大 80 キー同時スキャン
- ハードウェアデバウンス内蔵

### 2.12.2 キーイベント

PoMaS が受信するイベント:
- キー押下（isPressed）
- キー変化（isChange）
- 押しっぱなし（キーリピート）

### 2.12.3 キーリピート設定

- 初回遅延: 400 ms
- リピート間隔: 70 ms
- 対象キー: `Fn + 矢印`、`Del`

### 2.12.4 特殊キーの扱い

| 物理キー | 内部コード | 論理キー |
|---|---|---|
| `` ` `` | 0x60 | ESC |
| `;` | 0x3B | Up |
| `.` | 0x2E | Down |
| `,` | 0x2C | Left |
| `/` | 0x2F | Right |
| `Fn + 数字` | 修飾 | ショートカット |

## 2.13 電源管理

### 2.13.1 バッテリー

| 項目 | 値 |
|---|---|
| 容量 | 約 1,200 mAh |
| 電圧 | 3.7 V (Li-Ion) |
| 充電電圧 | 5 V (USB-C) |
| 充電時間 | 約 1.5〜2 時間 |

### 2.13.2 消費電流

| 状態 | 電流 |
|---|---|
| 起動時（LCD 最大） | 約 180 mA |
| 通常動作 | 約 100 mA |
| 省電力（バックライト暗） | 約 60 mA |
| スリープ | 約 20 mA |
| 電源 OFF | < 1 mA |

### 2.13.3 バッテリー残量の推定

PoMaS は `M5Cardputer.Power.getBatteryLevel()` で残量を取得。電圧からの推定のため、負荷により変動します。

### 2.13.4 自動電源 OFF

- 無操作 10 分で自動 OFF（設定変更可能、`autoOffMin`）
- 0 を設定すると無効
- 最大 600 分（10 時間）

### 2.13.5 減光機能

- 60 秒無操作で自動減光（バックライト輝度 12%）
- 任意キー押下で復帰

### 2.13.6 電池残量の目安

| 残量 | 表示 | 動作時間（目安） |
|---|---|---|
| 100% | 満充電 | 4〜6 時間 |
| 80% | 通常 | 3.5〜5 時間 |
| 50% | やや低下 | 2〜3 時間 |
| 20% | 警告 | 0.5〜1 時間 |
| 5% | 危険 | 数分 |

## 2.14 USB 接続とシリアル通信

### 2.14.1 USB モード

| モード | 用途 |
|---|---|
| Hardware CDC | シリアル通信（既定） |
| USB MSC | SD カードを USB マスストレージ化（未対応） |
| USB DFU | ファームウェア更新（未対応） |

### 2.14.2 シリアル通信

- ボーレート: 115200 bps（既定）
- Arduino IDE のシリアルモニタで確認可能
- `Serial.println()` の出力先

### 2.14.3 USB ケーブルの選定

| 要件 | 推奨 |
|---|---|
| データ通信対応 | 必須（充電専用は不可） |
| USB 2.0 | 十分 |
| 長さ | 1m 以下推奨 |
| コネクタ | USB-C（両端） |

**注意**: 一部の安価な充電専用ケーブルはデータ通信不可。

## 2.15 拡張端子

### 2.15.1 Grove 端子

Cardputer-Adv は Grove 端子を搭載していません（Cardputer 旧版は搭載）。

### 2.15.2 その他の端子

| 端子 | 用途 |
|---|---|
| USB-C | 充電・データ通信 |
| microSD | ストレージ |
| 電源ボタン | 電源 ON/OFF |
| G0 | ダウンロードモード |

### 2.15.3 外部機器接続

現状、PoMaS は外部 GPIO 拡張を前提としていません。I2C/SPI 追加センサーなどは基板改造が必要です。
