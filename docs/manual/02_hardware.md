## 2.1 Cardputer-Adv とは
PoMaS が動作する **M5Stack Cardputer-Adv** は、
M5Stack 社が販売する手のひらサイズのコンピュータです。
### 主な仕様
| 項目 | 値 |
|---|---|
| CPU | ESP32-S3（デュアルコア 240MHz） |
| Flash メモリ | 8 MB |
| RAM | 512 KB + PSRAM なし |
| 画面 | 240 × 135 ピクセル カラー液晶 |
| キーボード | 物理キーボード（約 56 キー） |
| スピーカー | 内蔵 |
| マイク | 内蔵 |
| SD カード | microSD 対応 |
| Wi-Fi | 2.4GHz 帯 |
| Bluetooth | 対応 |
| バッテリー | 内蔵リチウムイオン電池 |
| サイズ | 約 85 × 55 × 15 mm |
| 重量 | 約 70 g |
💡 **ESP32-S3 とは**
Espressif 社のマイコン（マイクロコントローラ）です。
Wi-Fi と Bluetooth を内蔵し、比較的高速な処理が可能です。

### 主なボタン・端子
| 部位 | 機能 |
|---|---|
| **電源ボタン** | 長押しで ON/OFF |
| **リセットボタン** | 押すと再起動（G0 ボタン兼用） |
| **G0 ボタン** | リセット横の小さなボタン。書き込み時に使用 |
| **USB-C 端子** | 充電・書き込み・シリアル通信 |
| **microSD スロット** | SD カード挿入 |
💡 **G0 ボタンの使い方**
ファームウェアを書き込む際、`Connecting...` で止まる場合は、
G0 ボタンを押しながらリセットボタンを押します。
これでダウンロードモードに入ります。

## 2.3 電源の入れ方
### 初回起動
1. **USB-C ケーブルで充電**（最初は充電が必要）
2. **電源ボタンを 2 秒以上長押し**
3. 画面に PoMaS のスプラッシュが表示される
4. 約 2.5 秒後、メインメニューが表示される
### 電源の切り方
1. **電源ボタンを 2 秒以上長押し**
2. 画面が暗くなり、電源が切れる
⚠️ **注意**
- 使用中に電源ボタンを長押しすると、強制終了になります
- データは保存されていない場合があります
- 通常の終了は、メインメニューに戻ってから行ってください
### スリープモード
操作しない状態が **10 分間** 続くと、自動的に電源が切れます
（PoMaS v0.92 の仕様）。
💡 **スリープを防ぐには**
定期的に何かのキーを押してください。
スリープまでの時間は、v0.93 で設定可能になる予定です。
---
## 2.4 充電
### 充電方法
1. USB-C ケーブルを PC または USB 充電器に接続
2. Cardputer-Adv の USB-C 端子に接続
3. 画面右上に充電アイコンが表示される
### 充電時間
- 空の状態から満充電まで: **約 1.5 〜 2 時間**
- 連続使用時間: **約 4 〜 6 時間**（使い方による）
### バッテリー残量の確認
メインメニュー → **Tools** → **Power / About** で確認できます。
```
Battery: 78% (charging)
PSRAM: none (normal)
SD: OK (16384MB)
Wi-Fi: off
Free heap: 125 KB
```

## 2.5 SD カード
### SD カードの役割
PoMaS では、以下の機能で SD カードを使用します。
| 機能 | 用途 |
|---|---|
| CSV ストリーム統計 | データの読み込み |
| Spreadsheet | データの保存 / 読み込み |
| μLisp | スクリプトの保存 / 読み込み |
| BMP 保存 | スクリーンショット |
### SD カードの仕様
| 項目 | 推奨 |
|---|---|
| 容量 | **32GB 以下**（64GB 以上は不安定） |
| フォーマット | **FAT32**（exFAT 不可） |
| 速度 | Class 10 以上推奨 |
### SD カードの挿入
1. Cardputer-Adv の電源を切る（推奨）
2. 側面の microSD スロットに挿入
3. 「カチッ」と音がするまで押し込む
4. 電源を入れる
5. 起動メッセージに `[SD] OK` が表示されれば成功
### SD カードが認識されない場合
**症状**: `SD: NOT detected` と表示される
**対処**:
1. `Tools → Power → R` でリトライ
2. 一度 SD カードを抜き差しする
3. 別の SD カードで試す
4. SD カードを PC で FAT32 フォーマット
⚠️ **注意**
- NTFS / exFAT では動作しません
- 64GB 以上のカードは認識しない場合があります

## 2.6 画面
### 画面の仕様
| 項目 | 値 |
|---|---|
| サイズ | 2.0 インチ |
| 解像度 | 240 × 135 ピクセル |
| 色数 | 65,536 色（RGB565） |
| 種類 | ST7789V2 カラー液晶 |
### 画面の構成
PoMaS の画面は、3 つの領域に分かれています。
```
┌─────────────────────────────────┐
│ ヘッダ（16px）                  │  ← タイトル・バッジ
├─────────────────────────────────┤
│                                 │
│                                 │
│ ボディ（105px）                 │  ← メインコンテンツ
│                                 │
│                                 │
├─────────────────────────────────┤
│ フッタ（14px）                  │  ← 操作ヒント
└─────────────────────────────────┘
```
- **ヘッダ**: 現在のモード名 + 設定バッジ（DEG/NRM など）
- **ボディ**: メインコンテンツ（メニュー、数式、グラフなど）
- **フッタ**: 操作のヒント（「ENT:OK」「ESC:back」など）
### Paper UI v2 の配色
PoMaS v0.92 では、目に優しい明るい配色を採用しています。
| 色 | 用途 |
|---|---|
| 淡いミント（背景） | 長時間の作業でも疲れにくい |
| グラファイト（文字） | 高コントラストで読みやすい |
| ミントグリーン（アクセント） | 選択中の項目、強調表示 |
💡 **輝度調整について**
現在のバージョンでは輝度調整機能はありません。
v0.93 で追加予定です。

## 2.7 キーボード
### キーボードの概要
Cardputer-Adv には、**約 56 個の物理キー** があります。
QWERTY 配列と、日本語入力用の特殊キーで構成されています。
### 主なキーの種類
| 種類 | 例 | 役割 |
|---|---|---|
| 文字キー | A〜Z, 0〜9 | 文字・数字入力 |
| 記号キー | + - * / ( ) | 演算子・記号 |
| 修飾キー | Fn, Shift | 組み合わせて特殊機能 |
| 特殊キー | Enter, Del, Esc | 確定・削除・取消 |
| 矢印キー | ; . , / | カーソル移動（代用） |
詳細は [第4章 キーボード詳細](04_keyboard.md) で解説します。
